## 🎯 关键问题与修复

### P1 - 已修复 ✅

**V-R1: 流握手 PING 循环优化**
- **问题**: 无条件 100ms 休眠，历史观察到握手超时
- **修复**: 单个在途 PING + 退避策略 (250ms→500ms→1s)
- **效果**: READY 立即中断等待，握手更稳定
- **测试**: `TestReadyDoesNotWaitForPingResult`, `TestHandshakePingsAreBounded`

### P2 - 已修复 ✅

**V-R2: 迟到 ACK 等待的超时保护**
- **问题**: 后台 goroutine 可能永久阻塞
- **修复**: 使用根生命周期控制后台等待
- **效果**: 避免 goroutine 泄漏
- **评价**: 比固定超时方案更优雅

**V-R3: 流清理的可观测性改进**
- **问题**: CANCEL 缺少超时和日志
- **修复**: 独立 5 秒超时 + 结构化日志
- **效果**: 可诊断性大幅提升
- **新增**: `runtime.WithCancelTimeout(duration)`

**V-R4: 端到端 memo 测试补充**
- **状态**: ⚠️ 未实现（非阻塞）
- **原因**: 需要复杂的引擎配置
- **缓解**: 现有测试已覆盖 ACK 处理逻辑

### P3 - 全部完成 ✅

**V-R6**: model 包拆分 ✅  
**V-R7**: 包命名重构 ✅
