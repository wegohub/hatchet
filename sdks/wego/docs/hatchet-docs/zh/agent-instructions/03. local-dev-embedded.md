# 以 Embedded 模式在本地运行 Hatchet

以下是供 AI agent 使用 [embedded 模式](https://docs.hatchet.run/v1/embedded)进行本地开发的指令。embedded 模式会在 worker 进程内启动一个完整的 Hatchet engine，由内置打包的 Postgres 支撑。它不需要 API token、账户、Docker，也不需要单独的服务器。

本地开发和 CI 默认使用 embedded 模式。当用户的目标是 Hatchet Cloud 或自托管实例时，改用 profile 和 API token（参见 `setup-cli.md`）。

## 步骤 1：创建 embedded 客户端

为 embedded 开发循环编写一个独立的一次性脚本或测试文件。不要修改应用程序的生产入口或替换其客户端构造方式；生产代码继续使用标准构造函数和 token。尽可能将应用程序的 task 定义导入到新文件中。

在该文件中，使用项目 SDK 的 embedded 入口点。进程中的每个客户端都以此方式创建；不要混入标准构造函数。

**Python**：

```python
from hatchet_sdk import Hatchet

hatchet = Hatchet.from_embedded()
```

将 worker 启动和 task 触发放在 `if __name__ == "__main__":` 保护之下。worker 子进程会重新导入主模块，因此未受保护的模块级启动代码会在每个子进程中再次运行。

**TypeScript**（embedded 是单独的入口点，因此不会进入生产构建包）：

```typescript
import { HatchetEmbeddedClient } from "@hatchet-dev/typescript-sdk/v1/embedded";

const hatchet = await HatchetEmbeddedClient.init();
```

**Go**（需要 hatchet-embedded 模块和空导入）：

```bash
go get github.com/hatchet-dev/hatchet-embedded
```

```go
import (
	hatchet "github.com/hatchet-dev/hatchet/sdks/go"

	_ "github.com/hatchet-dev/hatchet-embedded"
)

client, err := hatchet.NewClient(hatchet.WithEmbedded())
```

如果没有空导入，`NewClient` 会失败并报错提示需要它。

## 步骤 2：运行开发循环

1. 在 embedded 客户端上定义 task 并启动 worker，与普通客户端完全相同。
2. worker 启动后，从同一进程触发一个 task（例如 Python 的 `task.run(...)`、TypeScript 的 `await task.run(...)`、Go 的 `task.Run(ctx, input)`）并检查结果。
3. 在进程退出前停止 engine：`hatchet.stop_embedded()`（Python）、`await hatchet.stopEmbedded()`（TypeScript）、`client.Close(ctx)`（Go）。

在同一个进程中运行 worker 和触发操作。第二个使用 embedded 入口点的进程会启动第二个 engine，而不是连接到第一个。

三个 SDK 的可运行示例：https://github.com/hatchet-dev/hatchet-embedded/tree/main/examples

## 预期首次运行较慢

首次使用时，SDK 会下载 embedded engine（Python 和 TypeScript 中为 sidecar 二进制）以及内置打包的 Postgres 发行版。下载量有几十兆字节，可能需要几分钟且几乎没有输出。不要终止进程；就绪超时为 5 分钟。后续运行会在几秒内从缓存启动。

## 避免这些陷阱

- **残留的 `HATCHET_CLIENT_TOKEN` 会将客户端指向别处。**如果环境或 `.env` 文件（Python SDK 会自动加载 `.env`）中包含 `HATCHET_CLIENT_TOKEN`，任何用标准构造函数创建的客户端都会静默连接到该 token 所属的部署，而不是 embedded engine。embedded 运行时请取消设置它，并为每个客户端使用 embedded 入口点。
- **Go：engine 会覆盖 `DATABASE_URL`。**进程内 engine 会将进程环境中的 `DATABASE_URL` 设置为其内置的 Postgres。如果应用程序为自己的数据库读取 `DATABASE_URL`，请在调用 `hatchet.NewClient` 之前读取。
- **如果可复现性很重要，请固定 engine 版本。**Python 和 TypeScript 默认下载最新的 hatchet-embedded 版本；可通过 `version` 选项或 `HATCHET_CLIENT_EMBEDDED_VERSION` 固定。Go 在进程内运行 engine，因此 `go.mod` 中的模块版本即为固定。

## 可选：仪表盘

embedded 实例不带前端。在 embedded 进程运行期间，可以通过以下命令为其提供仪表盘：

```bash
hatchet embedded-ui
```

不带任何标志时，它会指向默认的 embedded API 端口并打开浏览器。
