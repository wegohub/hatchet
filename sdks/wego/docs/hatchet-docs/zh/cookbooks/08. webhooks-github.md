# GitHub Webhook

GitHub 可以针对仓库事件发送 webhook——推送、pull request、issue、release 等。本指南介绍如何将 GitHub webhook 接入 Hatchet。

## 设置


### 在 Hatchet 中创建 webhook

在 Hatchet 仪表盘中，进入 **Webhooks**，使用以下设置创建新 webhook：

字段，值

**Name**，`github`（或任意你喜欢的名称）
**Source**，GitHub
**Event Key Expression**，`'github:' + headers['x-github-event'] + ':' + input.action`
**Secret**，你自选的密钥字符串（在 GitHub 中将使用同一个）

关于事件键表达式的简要说明：GitHub 在 `x-github-event` 头中发送事件类型（如 `pull_request` 或 `issues`），在 payload 的 `action` 字段中发送具体动作（如 `opened` 或 `closed`）。上面的表达式将它们组合起来，生成类似 `github:pull_request:opened` 的键。

不过，并非所有 GitHub 事件都有 `action` 字段。例如 push 事件就没有。如果你想处理可能没有 `action` 的事件，可以使用更简单的表达式如 `'github:' + headers['x-github-event']`，并在 task 逻辑中处理动作级别的路由。或者也可以创建两个单独的 webhook——一个用于基于动作的事件，一个用于无动作的事件。

创建 webhook 后，复制其 URL。

### 在 GitHub 中配置 webhook

进入你的仓库（或组织）设置，找到 **Webhooks**，添加新 webhook。完整流程请参阅 [GitHub 的 webhook 文档](https://docs.github.com/en/webhooks/using-webhooks/creating-webhooks)。

1. **Payload URL**：粘贴 Hatchet webhook URL。
2. **Content type**：选择 `application/json`。
3. **Secret**：输入与在 Hatchet 中创建 webhook 时相同的密钥。
4. **Events**：选择"Let me select individual events"并勾选你关心的，或者选择"Send me everything"。

> **Warning:** 请确保将 content type 设置为 `application/json`。GitHub 默认为
>   `application/x-www-form-urlencoded`，与 Hatchet 的 JSON payload 解析不兼容。

### 编写监听 GitHub 事件的 task

以下示例在 pull request 被打开时触发：

#### Python

```python
class GitHubPullRequest(BaseModel):
    number: int
    title: str


class GitHubRepository(BaseModel):
    full_name: str


class GitHubPRInput(BaseModel):
    action: str
    pull_request: GitHubPullRequest
    repository: GitHubRepository


class GitHubPROutput(BaseModel):
    repo: str
    pr: int


@hatchet.task(
    input_validator=GitHubPRInput,
    on_events=["github:pull_request:opened"],
)
def handle_github_pr(input: GitHubPRInput, ctx: Context) -> GitHubPROutput:
    repo = input.repository.full_name
    pr_number = input.pull_request.number
    title = input.pull_request.title
    print(f"PR #{pr_number} opened on {repo}: {title}")
    return GitHubPROutput(repo=repo, pr=pr_number)
```

#### Typescript

```typescript
type GitHubPRInput = {
  action: string;
  pull_request: {
    number: number;
    title: string;
  };
  repository: {
    full_name: string;
  };
};

export const handleGitHubPR = hatchet.task({
  name: 'handle-github-pr',
  on: {
    event: 'github:pull_request:opened',
  },
  fn: async (input: GitHubPRInput, ctx) => {
    const repo = input.repository.full_name;
    const prNumber = input.pull_request.number;
    const { title } = input.pull_request;
    ctx.logger.info(`PR #${prNumber} opened on ${repo}: ${title}`);
    return { repo, pr: prNumber };
  },
});
```

#### Go

```go
type GitHubPRInput struct {
	Action      string `json:"action"`
	PullRequest struct {
		Number int    `json:"number"`
		Title  string `json:"title"`
	} `json:"pull_request"`
	Repository struct {
		FullName string `json:"full_name"`
	} `json:"repository"`
}

githubPR := client.NewStandaloneTask(
	"handle-github-pr",
	func(ctx hatchet.Context, input GitHubPRInput) (*struct {
		Repo string `json:"repo"`
		PR   int    `json:"pr"`
	}, error) {
		fmt.Printf("PR #%d opened on %s: %s\n", input.PullRequest.Number, input.Repository.FullName, input.PullRequest.Title)
		return &struct {
			Repo string `json:"repo"`
			PR   int    `json:"pr"`
		}{
			Repo: input.Repository.FullName,
			PR:   input.PullRequest.Number,
		}, nil
	},
	hatchet.WithWorkflowEvents("github:pull_request:opened"),
)
```

#### Ruby

```ruby
HANDLE_GITHUB_PR = HATCHET.task(
  name: "handle-github-pr",
  on_events: ["github:pull_request:opened"]
) do |input, ctx|
  repo = input["repository"]["full_name"]
  pr_number = input["pull_request"]["number"]
  title = input["pull_request"]["title"]
  puts "PR ##{pr_number} opened on #{repo}: #{title}"
  { "repo" => repo, "pr" => pr_number }
end
```

### 测试

在 GitHub 中保存 webhook 后，GitHub 会发送一个 `ping` 事件来验证连接。你也可以使用 GitHub webhook 设置中的"Redeliver"按钮重放过去的事件，或者直接打开一个 PR 触发真实事件。
