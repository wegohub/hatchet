# Cookbooks（实用指南）

我们的 cookbook 是帮你解决常见问题的指南，这些问题用 Hatchet 很容易处理。

## Webhook

接收外部服务的 webhook 并用它们触发 Hatchet 中的 task。每篇指南都端到端讲解——在 Hatchet 中创建 webhook、接入来源、编写处理传入事件的 task。


  
    处理支付事件、订阅变更和其他 Stripe webhook。
  
  
    响应 push、pull request、issue 等 GitHub 事件。
  
  
    响应消息、表情回应和斜杠命令等 Slack 事件。
  


## Workflow 模式

用 Hatchet 的 durable execution、事件处理和 task 编排原语构建实用的端到端 workflow。


  
    构建一个 durable 支持工作流：分流工单、等待客户回复、超时升级。
  
  
    注册后发送欢迎邮件，等待 onboarding 完成，仅在用户未按时完成时发送跟进邮件。
  
  
    构建 DAG workflow：从 PDF 提取文本、分类并总结内容。
  
  
    为 Amazon S3 构建高度并行的对象处理器。
  


## Agent 模式

通过 MCP 和 agent SDK 将 Hatchet workflow 和 task 暴露为 AI agent 的工具。


  
    将 Hatchet workflow 和 task 暴露为兼容 MCP 的 agent 工具，
    每次工具调用背后都有 durable execution、重试和可观测性。
  
  
    在可信环境中将 Claude Agent SDK 与 Hatchet 支持的 MCP 工具结合使用。
  
  
    在可信环境中将 OpenAI Agents SDK 与 Hatchet 支持的工具结合使用。
