# Stripe Webhook

Stripe 会针对各种事件发送 webhook，例如支付成功、订阅取消、发票创建等。本指南介绍如何设置从 Stripe 到 Hatchet 的 webhook，以直接在 Hatchet 中触发事件。

## 设置


### 获取你的 Stripe webhook 签名密钥

在 [Stripe Dashboard](https://dashboard.stripe.com/webhooks) 中，你将创建一个新的 webhook 端点。暂时不要填写 URL——下一步你会从 Hatchet 获得它。设置细节请参阅 [Stripe 的 webhook 指南](https://docs.stripe.com/webhooks)。

现在，记下 Stripe 为你生成的 **签名密钥**（以 `whsec_` 开头）。你需要用它告诉 Hatchet 如何验证传入请求。

### 在 Hatchet 中创建 webhook

在 Hatchet 仪表盘中，进入 **Webhooks**，使用以下设置创建新 webhook：

字段，值

**Name**，`stripe`（或任意你喜欢的名称）
**Source**，Stripe
**Event Key Expression**，`'stripe:' + input.type`
**Secret**，你的 `whsec_...` 签名密钥

这里的事件键表达式从 Stripe 的 payload 中取出 `type` 字段（形如 `payment_intent.created`），并加上 `stripe:` 前缀，使你的事件键有命名空间。当 Stripe 的 webhook 以 `input.type` 为 `payment_intent.created` 被摄取时，Hatchet 会创建一个键为 `stripe:payment_intent.created` 的对应事件。

创建 webhook 后，复制 Hatchet 生成的 URL。

### 将 URL 添加到 Stripe

回到第 1 步在 Stripe Dashboard 中创建的 webhook，粘贴 Hatchet webhook URL。选择你想要监听的事件（或者全部选择——Hatchet 只会触发与事件键匹配的 workflow）。

### 编写监听 Stripe 事件的 task

现在你只需要一个带有匹配 `on_events` 触发器的 task。例如，处理支付成功：

#### Python

```python
class StripeObject(BaseModel):
    customer: str
    amount: int


class StripeData(BaseModel):
    object: StripeObject


class StripePaymentInput(BaseModel):
    type: str
    data: StripeData


class StripePaymentOutput(BaseModel):
    customer: str
    amount: int


@hatchet.task(
    input_validator=StripePaymentInput,
    on_events=["stripe:payment_intent.succeeded"],
)
def handle_stripe_payment(
    input: StripePaymentInput, ctx: Context
) -> StripePaymentOutput:
    customer = input.data.object.customer
    amount = input.data.object.amount
    print(f"Payment of {amount} from {customer}")
    return StripePaymentOutput(customer=customer, amount=amount)
```

#### Typescript

```typescript
type StripePaymentInput = {
  type: string;
  data: {
    object: {
      customer: string;
      amount: number;
    };
  };
};

export const handleStripePayment = hatchet.task({
  name: 'handle-stripe-payment',
  on: {
    event: 'stripe:payment_intent.succeeded',
  },
  fn: async (input: StripePaymentInput, ctx) => {
    const { customer, amount } = input.data.object;
    ctx.logger.info(`Payment of ${amount} from ${customer}`);
    return { customer, amount };
  },
});
```

#### Go

```go
type StripePaymentInput struct {
	Type string `json:"type"`
	Data struct {
		Object struct {
			Customer string `json:"customer"`
			Amount   int    `json:"amount"`
		} `json:"object"`
	} `json:"data"`
}

stripePayment := client.NewStandaloneTask(
	"handle-stripe-payment",
	func(ctx hatchet.Context, input StripePaymentInput) (*struct {
		Customer string `json:"customer"`
		Amount   int    `json:"amount"`
	}, error) {
		fmt.Printf("Payment of %d from %s\n", input.Data.Object.Amount, input.Data.Object.Customer)
		return &struct {
			Customer string `json:"customer"`
			Amount   int    `json:"amount"`
		}{
			Customer: input.Data.Object.Customer,
			Amount:   input.Data.Object.Amount,
		}, nil
	},
	hatchet.WithWorkflowEvents("stripe:payment_intent.succeeded"),
)
```

#### Ruby

```ruby
HANDLE_STRIPE_PAYMENT = HATCHET.task(
  name: "handle-stripe-payment",
  on_events: ["stripe:payment_intent.succeeded"]
) do |input, ctx|
  customer = input["data"]["object"]["customer"]
  amount = input["data"]["object"]["amount"]
  puts "Payment of #{amount} from #{customer}"
  { "customer" => customer, "amount" => amount }
end
```

### 测试

你可以使用 Stripe 仪表盘中的"Send test webhook"功能，或在测试模式下触发真实事件。你应该会在 Hatchet 仪表盘中看到相应的 task run。
