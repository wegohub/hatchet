### Metrics Client

Metrics 客户端用于从 Hatchet 的指标 API 读取指标。

#### 方法：

<a id="getqueuemetrics"></a>

##### `getQueueMetrics()`

返回当前租户的队列指标。

参数：

参数, 类型, 描述

`opts?`, `RequestParams`, 请求的选项。

返回值：

`Promise`\<`TenantStepRunQueueMetrics`\>

当前租户的队列指标。

<a id="gettaskstats"></a>

##### `getTaskStats()`

获取租户的任务统计信息。

返回值：

`Promise`\<`TaskStats`\>

一个将任务名称映射到其统计信息的记录。

<a id="gettaskstatusmetrics"></a>

##### `getTaskStatusMetrics()`

返回按状态（排队中、运行中、已完成、失败、已取消）分组的任务运行计数聚合结果。

参数：

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| `query` | \{ `additional_metadata?`: `string`[]; `parent_task_external_id?`: `string`; `since`: `string`; `triggering_event_external_id?`: `string`; `until?`: `string`; `workflow_ids?`: `string`[]; \} | 指标查询的过滤条件（例如 `since`、`until`、`workflow_ids`）。 |
| `query.additional_metadata?` | `string`[] | 用于筛选的附加元数据键值对 |
| `query.parent_task_external_id?` | `string` | 父任务的外部 ID **Format** uuid **Min Length** 36 **Max Length** 36 |
| `query.since?` | `string` | 获取指标的起始时间 **Format** date-time |
| `query.triggering_event_external_id?` | `string` | 触发该任务的事件 ID **Format** uuid **Min Length** 36 **Max Length** 36 |
| `query.until?` | `string` | 获取指标的结束时间 **Format** date-time |
| `query.workflow_ids?` | `string`[] | 用于查找运行记录的工作流 ID |
| `requestParams?` | `RequestParams` | 可选的请求级覆盖项（headers、signal 等）。 |

返回值：

`Promise`\<`TaskStatusMetrics`\>

匹配的任务运行按状态统计的计数。

<a id="scrapeprometheusmetrics"></a>

##### `scrapePrometheusMetrics()`

抓取租户的 Prometheus 指标。

返回值：

`Promise`\<`string`\>

Prometheus 文本格式的指标。
