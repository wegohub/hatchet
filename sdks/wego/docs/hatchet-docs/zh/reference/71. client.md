# Hatchet Ruby SDK 参考文档

这是 Ruby SDK 参考文档，记录了与 Hatchet 资源交互时可用的方法。请查看[用户指南](<../v1/01. get-started（入门）/01. index.md>)，了解如何运行你的第一批任务。

## Hatchet Ruby 客户端

与 Hatchet 服务交互的主客户端。

```ruby
hatchet = Hatchet::Client.new()
```

```ruby
hatchet = Hatchet::Client.new(
  token: "your-jwt-token",
  namespace: "production"
)
```

```ruby
wf = hatchet.workflow(name: "MyWorkflow")
step1 = wf.task(:step1) { |input, ctx| { "result" => 42 } }
```

```ruby
my_task = hatchet.task(name: "my_task") { |input, ctx| { "result" => "done" } }
```

构造函数接受关键字选项。未显式传入的内容将从 `HATCHET_CLIENT_*` 环境变量中读取。

选项：

| Name | Type | Description |
| --- | --- | --- |
| `debug` | `Boolean` | 启用调试日志（默认：false） |
| `token` | `String` | 用于身份验证的 JWT token（必需） |
| `tenant_id` | `String` | 覆盖租户 ID（如未提供，则从 JWT token 的 'sub' 字段中提取） |
| `host_port` | `String` | gRPC 服务器的主机和端口（默认："localhost:7070"） |
| `server_url` | `String` | 用于 HTTP 请求的服务器 URL。 |
| `namespace` | `String` | 资源名称的命名空间前缀（默认：""） |
| `logger` | `Logger` | 自定义 logger 实例。 |
| `worker_preset_labels` | `Hash` | 应用于所有 worker 的默认标签。 |

方法：

| Name | Description |
| --- | --- |
| `worker` | 创建一个用于运行工作流的 Hatchet worker。 |
| `workflow` | 定义一个 Hatchet 工作流，随后可以在其中声明任务，并对其进行运行、调度等操作。 |
| `task` | 创建一个独立的 Hatchet 任务。 |
| `durable_task` | 创建一个独立的_持久化_（durable）Hatchet 任务，基于 Hatchet 的持久化执行能力工作。 |
| `batch_task` | 创建一个独立的批量任务（自动包装为单任务工作流）。 |

### Attributes

#### `cel`

CEL 客户端用于在 Hatchet 中调试 CEL 表达式。参见 [CEL 客户端](<74. cel.md>)。

#### `config`

此客户端使用的配置对象。

#### `cron`

cron 客户端用于管理 Hatchet 中的 cron 工作流触发器。参见 [Cron 客户端](<75. cron.md>)。

#### `events`

events 客户端可用于向 Hatchet 推送事件，以触发事件驱动的工作流。参见 [Events 客户端](<76. events.md>)。

#### `filters`

filters 客户端用于管理 Hatchet 中的过滤器，过滤器通过 CEL 表达式限定事件触发到工作流的范围。参见 [Filters 客户端](<77. filters.md>)。

#### `logger`

logger 的便捷访问器。

#### `logs`

logs 客户端用于与 Hatchet 的日志 API 交互。参见 [Logs 客户端](<78. logs.md>)。

#### `metrics`

metrics 客户端用于从 Hatchet 的指标 API 读取指标。参见 [Metrics 客户端](<79. metrics.md>)。

#### `rate_limits`

rate limits 客户端是 Hatchet gRPC API 的封装，让在 Hatchet 中使用速率限制更加方便。参见 [Rate Limits 客户端](<80. rate_limits.md>)。

#### `runs`

runs 客户端用于与 Hatchet 中的任务运行和工作流运行交互。参见 [Runs 客户端](<81. runs.md>)。

#### `scheduled`

scheduled 客户端用于管理 Hatchet 中的计划工作流运行。参见 [Scheduled 客户端](<82. scheduled.md>)。

#### `tenant`

tenant 客户端用于读取你所处租户的相关信息。参见 [Tenant 客户端](<83. tenant.md>)。

#### `tenant_id`

租户 ID。

#### `workers`

workers 客户端用于在 Hatchet 中以编程方式管理 worker。参见 [Workers 客户端](<85. workers.md>)。

#### `workflows`

workflows 客户端用于在 Hatchet 中以编程方式管理工作流声明。注意，工作流是声明本身，而_不是_单次运行；如果你要查找运行记录，请改用 runs 客户端。参见 [Workflows 客户端](<86. workflows.md>)。

### Functions

#### `worker`

创建一个用于运行工作流的 Hatchet worker。

```ruby
worker = hatchet.worker("my-worker", workflows: [wf], slots: 10)
worker.start
```

参数：

| Name | Type | Description | Default |
| --- | --- | --- | --- |
| `name` | `String` | worker 的名称。 | _required_ |
| `workflows` | `Array` | 要注册到该 worker 上的工作流（或独立任务）列表。 | `[]` |
| `slots` | `Integer` | 标准任务的槽位数量，即该 worker 可以并发运行的任务数。 | `10` |
| `durable_slots` | `Integer \| nil` | 持久化任务的槽位数量；如未提供则默认为 `slots`。 | `nil` |
| `labels` | `Hash` | 分配给该 worker 的标签哈希，用于 worker 亲和性；会与客户端的 `worker_preset_labels` 合并。 | `{}` |

返回：

Type, Description

`Hatchet::Worker`, 创建的 worker 对象，它提供实例方法 `start`（调用后启动 worker，阻塞直至关闭）和 `stop`（请求优雅关闭）。

#### `workflow`

定义一个 Hatchet 工作流，随后可以在其中声明任务，并对其进行运行、调度等操作。

```ruby
wf = hatchet.workflow(name: "MyWorkflow")
wf.task(:step1) { |input, ctx| { "value" => 42 } }
```

参数：

| Name | Type | Description | Default |
| --- | --- | --- | --- |
| `name` | `String` | 工作流的名称。 | _required_ |
| `on_events` | `Array` | 工作流的事件触发器列表——即触发该工作流运行的事件。 | `[]` |
| `on_crons` | `Array` | 工作流的 cron 触发器列表。 | `[]` |
| `concurrency` | `ConcurrencyExpression \| Array \| nil` | 控制此工作流并发设置的并发对象（或其列表）。 | `nil` |
| `default_priority` | `Integer \| nil` | 工作流的默认优先级。值越高，该工作流的运行在调度时越优先于其他较低优先级的运行。 | `nil` |
| `task_defaults` | `Hash \| nil` | 此工作流的默认任务设置。 | `nil` |
| `default_filters` | `Array` | 创建工作流时要创建的过滤器列表。 | `[]` |
| `sticky` | `Symbol \| nil` | 工作流的粘性策略，可以是 `:soft` 或 `:hard`。 | `nil` |
| `idempotency` | `TTLBasedIdempotencyConfig \| StatusBasedIdempotencyConfig \| nil` | 工作流的幂等性配置。 | `nil` |

返回：

Type, Description

`Hatchet::Workflow`, 创建的工作流对象，可用于声明任务、运行工作流等。

#### `task`

创建一个独立的 Hatchet 任务。该任务会自动包装为单任务工作流，因此可以像工作流一样被运行、调度并注册到 worker 上。代码块接收本次运行的输入和一个 `Context` 对象。

```ruby
my_task = hatchet.task(name: "my_task") { |input, ctx| { "result" => "done" } }
```

参数：

| Name | Type | Description | Default |
| --- | --- | --- | --- |
| `name` | `String` | 任务的名称。 | _required_ |
| `on_events` | `Array` | 任务的事件触发器列表——即触发该任务运行的事件。 | `[]` |
| `default_filters` | `Array` | 创建任务时要创建的过滤器列表。 | `[]` |
| `idempotency` | `TTLBasedIdempotencyConfig \| StatusBasedIdempotencyConfig \| nil` | 任务的幂等性配置。 | `nil` |

返回：

Type, Description

`Hatchet::Task`, 创建的任务对象，可以被运行、调度并注册到 worker 上。

#### `durable_task`

创建一个独立的_持久化_（durable）Hatchet 任务，基于 Hatchet 的持久化执行能力工作。持久化任务会接收一个 `DurableContext`，其中包含 `sleep_for` 和 `wait_for` 等额外方法。

参数：

| Name | Type | Description | Default |
| --- | --- | --- | --- |
| `name` | `String` | 任务的名称。 | _required_ |
| `eviction_policy` | `Hatchet::EvictionPolicy \| nil` | 此持久化任务的淘汰策略。默认为 `Hatchet::DEFAULT_DURABLE_TASK_EVICTION_POLICY`（15 分钟 TTL，启用容量淘汰）。传入 `nil` 可完全禁用此任务的淘汰。 | `Hatchet::DEFAULT_DURABLE_TASK_EVICTION_POLICY` |
| `**opts` | `Hash` | 其他关键字参数（`retries:`、`execution_timeout:` 等）会被转发到任务声明——完整列表请参见 `Workflow#task`。 | `{}` |

返回：

Type, Description

`Hatchet::Task`, 创建的持久化任务对象。

#### `batch_task`

创建一个独立的批量任务（自动包装为单任务工作流）。

批量任务会缓冲并发运行，直到 Hatchet 刷新该批次（达到大小上限或到达刷新间隔），然后以所有缓冲输入（按每次运行的任务运行外部 ID 作为键）调用一次代码块。代码块必须返回一个将每个 ID 映射到其输出的 Hash，或者在批量配置上使用 `broadcast_output` 将相同结果返回给所有调用方。批量任务的 retries 始终强制为 0。

预览：批量任务目前处于 beta 阶段，在未来的版本中可能会发生变化。

```ruby
batch = hatchet.batch_task(name: "my_batch", batch: Hatchet::BatchTaskConfig.new(max_size: 3)) do |inputs, ctx|
  inputs.transform_values { |input| { "result" => input["message"].upcase } }
end
```

参数：

| Name | Type | Description | Default |
| --- | --- | --- | --- |
| `name` | `String` | 任务的名称。 | _required_ |
| `batch` | `Hatchet::BatchTaskConfig` | 批量配置（`max_size`、刷新间隔、`broadcast_output`） | _required_ |
| `**opts` | `Hash` | 其他关键字参数（`on_events:`、`idempotency:` 等）会被转发到 `task`。 | `{}` |

返回：

Type, Description

`Hatchet::Task`, 创建的批量任务对象。
