# Hatchet CLI 安装与设置

Hatchet CLI 是一个命令行工具，提供在本地运行 worker、与运行中的 Hatchet 部署交互，以及为开发环境运行本地 Hatchet 实例等实用功能。

## 功能

- **快速入门**：[`hatchet quickstart`](/cli/quickstarts) 命令可以基于模板生成一个 worker 项目，帮助你快速上手。

- **本地 worker 热重载**：[`hatchet worker dev`](/cli/running-workers-locally) 命令让你可以在本地运行 worker，并在检测到代码变更时自动重载。

- **完整的内置 TUI**：[`hatchet tui`](/cli/tui) 命令让你通过终端用户界面（TUI）与你的 Hatchet 部署交互，对任务、工作流、worker 等提供实时可观测性。

- **Profiles**：[`hatchet profile`](/cli/profiles) 系列命令允许你使用命名 profile 管理多个 Hatchet 实例和租户，方便在不同环境之间切换。

## 安装

推荐通过我们的安装脚本或 Homebrew 安装 Hatchet CLI：

#### 原生安装（推荐）

**MacOS、Linux、WSL**

```sh
    curl -fsSL https://install.hatchet.run/install.sh | bash
```

要安装特定版本，可以向安装脚本传递 release 标签：

```sh
    curl -fsSL https://install.hatchet.run/install.sh | bash -s -- vX.Y.Z
```

#### Homebrew

**MacOS**

```sh
    brew install hatchet-dev/hatchet/hatchet --cask
```

## 验证安装

安装完成后，通过查看版本号来验证 Hatchet CLI 是否安装正确：

```sh
hatchet --version
```

## 匿名遥测

CLI 会发送匿名的使用遥测数据，帮助我们了解哪些版本和平台在使用，以便安排工作优先级。不会收集任何个人数据：每次上报仅包含 CLI 版本、操作系统和 CPU 架构，并以存储在 `~/.hatchet/telemetry_id` 中的随机生成的安装标识符作为键。该标识符并非从你的机器、用户或网络身份派生。

遥测默认启用。要禁用它，请在 `~/.hatchet/config.yaml` 中设置：

```yaml
telemetry:
  enabled: false
```

或设置环境变量：

```sh
export HATCHET_CLI_TELEMETRY_ENABLED=false
```
