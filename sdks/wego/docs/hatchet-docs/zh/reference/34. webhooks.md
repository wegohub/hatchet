# Webhooks Client

继承自：`BaseRestClient`

webhooks 客户端提供在 Hatchet 中管理传入（incoming）webhook 的方法。

Webhook 允许外部系统通过向专用端点发送 HTTP 请求来触发 Hatchet 工作流，
从而可以与 GitHub、Stripe、Slack 等第三方服务或任何能发送 webhook 事件的系统
实现实时集成。

方法：

| 名称 | 描述 |
| --- | --- |
| `aio_create` | 创建一个新 webhook。 |
| `aio_delete` | 按名称删除 webhook。 |
| `aio_get` | 按名称获取 webhook。 |
| `aio_list` | 列出给定租户的 webhook。 |
| `aio_update` | 按名称更新 webhook。 |
| `create` | 创建一个新 webhook。 |
| `delete` | 按名称删除 webhook。 |
| `get` | 按名称获取 webhook。 |
| `list` | 列出给定租户的 webhook。 |
| `update` | 按名称更新 webhook。 |

### Functions

#### `aio_create`

创建一个新 webhook。

参数：

| 名称 | 类型 | 描述 | 默认值 |
| --- | --- | --- | --- |
| `source_name` | `V1WebhookSourceName` | 标识发送 webhook 事件的外部系统的源名称。 | _必填_ |
| `name` | `str` | webhook 的名称。 | _必填_ |
| `event_key_expression` | `str` | 用于从传入 payload 中提取事件键的 CEL 表达式。 | _必填_ |
| `auth` | `V1WebhookBasicAuth \| V1WebhookAPIKeyAuth \| V1WebhookHMACAuth` | webhook 的认证配置（basic auth、API key 或 HMAC）。 | _必填_ |
| `scope_expression` | `str \| None` | 可选的 CEL 表达式，用于从传入 payload 中提取作用域。 | `None` |
| `static_payload` | `dict[str, Any] \| None` | 可选的静态 payload，会合并到每个被触发的事件中。 | `None` |
| `return_event_as_response_payload` | `bool` | 是否将被触发的事件作为 webhook 请求的响应 payload 返回。 | `True` |

返回：

类型, 描述

`V1Webhook`, 创建的 webhook。

#### `aio_delete`

按名称删除 webhook。

参数：

名称, 类型, 描述, 默认值

`webhook_name`, `str`, 要删除的 webhook 名称。, _必填_

返回：

类型, 描述

`V1Webhook`, 被删除的 webhook。

#### `aio_get`

按名称获取 webhook。

参数：

名称, 类型, 描述, 默认值

`webhook_name`, `str`, 要获取的 webhook 名称。, _必填_

返回：

类型, 描述

`V1Webhook`, 具有指定名称的 webhook。

#### `aio_list`

列出给定租户的 webhook。

参数：

| 名称 | 类型 | 描述 | 默认值 |
| --- | --- | --- | --- |
| `limit` | `int \| None` | 返回 webhook 的最大数量。 | `None` |
| `offset` | `int \| None` | 开始收集结果集之前跳过的 webhook 数量。 | `None` |
| `webhook_names` | `list[str] \| None` | 用于过滤的 webhook 名称列表。 | `None` |
| `source_names` | `list[V1WebhookSourceName] \| None` | 用于过滤的源名称列表。 | `None` |

返回：

类型, 描述

`V1WebhookList`, 符合指定条件的 webhook 列表。

| `static_payload` | `dict[str, Any] \| None` | 更新后的静态 payload，会合并到每个被触发的事件中。 | `None` |
| `return_event_as_response_payload` | `bool \| None` | 是否将被触发的事件作为 webhook 请求的响应 payload 返回。 | `None` |

返回：

类型, 描述
