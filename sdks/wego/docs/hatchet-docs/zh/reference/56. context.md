# Context

Hatchet 的 `Context` 在运行时为任务提供辅助方法和有用的数据。它作为第一个参数传递给所有任务函数。

你会遇到两种上下文类型：

- `hatchet.Context` - 常规任务的标准上下文，提供日志记录、父任务输出获取、流式传输等方法。它内嵌了 Go 的 `context.Context`，因此可以传递到任何期望标准上下文的地方（包括在任务内部启动子工作流时作为 run 方法的 `ctx` 参数）。
- `hatchet.DurableContext` - 面向持久化任务的扩展上下文，增加了 `SleepFor`、`WaitForEvent`、`Memo` 等持久化执行方法。持久化等待是"全局"的：它们按真实时间等待，并且能够在 worker 重启等瞬时故障后继续存活。

持久化等待的结果（`*SingleWaitResult`、`*WaitResult`）提供 `Unmarshal` 方法来解码匹配到的负载；`hatchet.EventInto(event, &dest)` 是单事件场景下的便捷封装。

## DurableContext

方法：

| 名称 | 描述 |
| --- | --- |
| `SleepFor` | SleepFor 暂停执行指定的时长，该时间过去后返回。 |
| `WaitForEvent` | WaitForEvent 暂停执行，直到收到指定的用户事件。 |
| `WaitFor` | WaitFor 暂停执行，直到满足指定条件。 |
| `Memo` | Memo 执行 fn，将结果进行 JSON 序列化，并通过引擎的持久化事件日志保存。 |
| `Now` | Now 返回当前时间，通过 Memo 进行记忆化，因此重放时返回相同的值。 |

| `SleepUntil` | SleepUntil 睡眠到指定的绝对时间。 |

### 函数

#### `SleepFor`

SleepFor 暂停执行指定的时长，该时间过去后返回。时长是"全局"的，意味着即使发生 worker 重启等瞬时故障，它也会按真实时间等待。

```go
func SleepFor(duration time.Duration) (*SingleWaitResult, error)
```

参数：

名称, 类型

`duration`, `time.Duration`

返回值：

类型

`*SingleWaitResult`
`error`

#### `WaitForEvent`

WaitForEvent 暂停执行，直到收到指定的用户事件。可以使用 condition.WithEventScope 和 condition.WithConsiderEventsSince 等选项来限定等待范围，并匹配在等待开始之前推送的事件。

```go
func WaitForEvent(eventKey, expression string, opts ...condition.UserEventConditionOpt) (*SingleWaitResult, error)
```

参数：

| 名称 | 类型 |
| --- | --- |
| `eventKey` | `string` |
| `expression` | `string` |
| `opts` | `...condition.UserEventConditionOpt` |

返回值：

类型

`*SingleWaitResult`
`error`

#### `WaitFor`

WaitFor 暂停执行，直到满足指定条件。条件是"全局"的，意味着即使发生 worker 重启等瞬时故障，它们也会按真实时间等待。

```go
func WaitFor(conditions condition.Condition) (*WaitResult, error)
```

参数：

名称, 类型

`conditions`, `condition.Condition`

返回值：

类型

`*WaitResult`
`error`

#### `Memo`

Memo 执行 fn，将结果进行 JSON 序列化，并通过引擎的持久化事件日志保存。重放时会直接返回缓存的负载，而不会重新执行 fn。调用方应使用 json.Unmarshal 将返回的字节解码到具体类型。如果引擎不支持持久化记忆化，则会执行 fn，且结果仅在进程内缓存（不会在重放后保留）。key 必须在任务内唯一。

```go
func Memo(key string, fn func() (any, error)) (json.RawMessage, error)
```

参数：

名称, 类型

`key`, `string`
`fn`, `func() (any, error)`

返回值：

类型

`json.RawMessage`
`error`

#### `Now`

Now 返回当前时间，通过 Memo 进行记忆化，因此重放时返回相同的值。

```go
func Now() (time.Time, error)
```

返回值：

类型

`time.Time`
`error`
