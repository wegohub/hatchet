# Context

Hatchet 的 Context 类在运行时为任务提供辅助方法和有用的数据。

- 对于**任务**和**持久化任务（durable task）**，它作为第二个参数传入（`fn(input, ctx)`）。
- 对于**批量任务（batch task）**，它与每个输入组成元组传入（`fn(tasks)`，其中 `tasks: list[tuple[input, Context]]`）。

你会遇到两种上下文类：

- `Context` - 普通任务的标准上下文，提供日志、任务输出获取、取消等方法
- `DurableContext` - 持久化任务的扩展上下文，包含 `aio_wait_for` 和 `aio_sleep_for` 等用于持久化执行的额外方法

## Context

方法：

| 名称 | 描述 |
| --- | --- |
| `was_skipped` | 检查给定任务是否被跳过。相关说明见[文档](<../v1/06. durable-execution（持久化执行）/06. directed-acyclic-graphs.md#checking-if-a-parent-was-skipped>)。 |
| `task_output` | 获取 DAG 中父任务的输出。 |
| `cancel` | 取消当前任务运行。会调用 Hatchet API 取消该 step run 并将退出标志设为 True。 |
| `aio_cancel` | 取消当前任务运行。会调用 Hatchet API 取消该 step run 并将退出标志设为 True。 |
| `done` | 检查当前任务运行是否已被取消。 |
| `log` | 向 Hatchet API 写入一行日志。会将该日志行发送到 Hatchet API 并立即返回。 |
| `release_slot` | 手动释放当前 step run 占用的槽位，以释放 worker 上的一个槽位。注意这是一项高级功能，应谨慎使用。 |
| `put_stream` | 向 Hatchet API 发送一个流事件。会将数据发送到 Hatchet API 并立即返回。之后可以从单独的消费者订阅该流。 |
| `refresh_timeout` | 刷新当前任务运行的超时时间。相关说明见[文档](<../v1/04. reliability（可靠性）/02. timeouts.md#refreshing-timeouts>)。 |
| `fetch_task_run_error` | **已弃用**：请改用 `get_task_run_error`。 |

### Attributes

#### `was_triggered_by_event`

一个属性，指示工作流是否由事件触发。

返回：

类型, 描述

`bool`, 如果工作流由事件触发则为 True，否则为 False。

#### `workflow_input`

工作流的输入，以字典形式提供。建议使用任务的 `input` 参数（运行时传入任务的第一个参数），而不是该属性。

返回：

类型, 描述

`JSONSerializableMapping`, 工作流的输入。

#### `lifespan`

worker 的 lifespan（如果存在）。相关说明见[文档](<20. lifespans.md>)。

**注意：你需要将该属性的返回类型转换（cast）为你的 lifespan 生成器所返回的类型。**

#### `workflow_run_id`

当前工作流运行的 id。

返回：

类型, 描述

`str`, 当前工作流运行的 id。

#### `retry_count`

当前任务运行的重试次数，对应任务已被重试的次数。

返回：

类型, 描述

`int`, 当前任务运行的重试次数。

#### `attempt_number`

当前任务运行的尝试次数，对应任务已被尝试的次数（包括首次尝试）。该值比重试次数多 1。

返回：

类型, 描述

`int`, 当前任务运行的尝试次数。

#### `additional_metadata`

随当前任务运行一起发送的附加元数据。

返回：

类型, 描述

`JSONSerializableMapping`, 随当前任务运行发送的附加元数据，如果未发送则为 None。

#### `parent_workflow_run_id`

当前任务运行的父工作流运行 id（如果存在）。可用于了解哪个工作流运行将本次运行为子运行派生出来。

返回：

类型, 描述

`str \, None`, 当前任务运行的父工作流运行 id，如果不存在则为 None。

#### `priority`

当前任务运行时所使用的优先级。

返回：

类型, 描述

`int \, None`, 当前任务运行的优先级，如果未设置则为 None。

#### `workflow_id`

该任务所属工作流的 id。

返回：

类型, 描述

`str \, None`, 该任务所属工作流的 id。

#### `workflow_version_id`

该任务所属工作流版本的 id。

返回：

类型, 描述

`str \, None`, 该任务所属工作流版本的 id。

#### `task_run_errors`

一个辅助方法，适用于在 on-failure 步骤中获取上游任务运行中发生的错误。

返回：

类型, 描述

`dict[str, str]`, 一个将任务名称映射到其错误消息的字典。

### Functions

#### `was_skipped`

检查给定任务是否被跳过。相关说明见[文档](<../v1/06. durable-execution（持久化执行）/06. directed-acyclic-graphs.md#checking-if-a-parent-was-skipped>)。

参数：

名称, 类型, 描述, 默认值

`task`, `Task[TWorkflowInput, R]`, 要检查状态（是否被跳过）的任务。, _必填_

返回：

类型, 描述

`bool`, 如果任务被跳过则为 True，否则为 False。

#### `task_output`

获取 DAG 中父任务的输出。

参数：

名称, 类型, 描述, 默认值

`task`, `Task[TWorkflowInput, R]`, 要获取其输出的任务。, _必填_

返回：

类型, 描述

`R`, 父任务的输出，会使用该任务的校验器进行校验。

异常：

类型, 描述

`ValueError`, 如果任务被跳过，或未找到该任务的 step 输出。

#### `cancel`

取消当前任务运行。会调用 Hatchet API 取消该 step run 并将退出标志设为 True。

返回：

类型, 描述

`None`, None

#### `aio_cancel`

取消当前任务运行。会调用 Hatchet API 取消该 step run 并将退出标志设为 True。

返回：

类型, 描述

`None`, None

#### `done`

检查当前任务运行是否已被取消。

返回：

类型, 描述

`bool`, 如果任务运行已被取消则为 True，否则为 False。

#### `log`

向 Hatchet API 写入一行日志。会将该日志行发送到 Hatchet API 并立即返回。

参数：

名称, 类型, 描述, 默认值

`line`, `str \, JSONSerializableMapping`, 要记录的日志行。可以是字符串或 JSON 可序列化的映射。, _必填_
`raise_on_error`, `bool`, 如果为 True，在日志失败时会抛出异常。默认为 False。, `False`

返回：

类型, 描述

`None`, None

#### `release_slot`

手动释放当前 step run 占用的槽位，以释放 worker 上的一个槽位。注意这是一项高级功能，应谨慎使用。

返回：

类型, 描述

`None`, None

#### `put_stream`

向 Hatchet API 发送一个流事件。会将数据发送到 Hatchet API 并立即返回。之后可以从单独的消费者订阅该流。

参数：

名称, 类型, 描述, 默认值

`data`, `str \, bytes`, 要发送到 Hatchet API 的数据。可以是字符串或字节。, _必填_

返回：

类型, 描述

`None`, None

#### `refresh_timeout`

刷新当前任务运行的超时时间。相关说明见[文档](<../v1/04. reliability（可靠性）/02. timeouts.md#refreshing-timeouts>)。

参数：

名称, 类型, 描述, 默认值

`increment_by`, `Duration`, 超时时间增加的量。可以是字符串（如 "5m"）或 timedelta 对象。, _必填_

返回：

类型, 描述

`None`, None

#### `fetch_task_run_error`

**已弃用**：请改用 `get_task_run_error`。

一个辅助方法，适用于在 on-failure 步骤中获取特定上游任务运行中发生的错误。

参数：

名称, 类型, 描述, 默认值

`task`, `Task[TWorkflowInput, R]`, 要获取其错误的任务。, _必填_

返回：

类型, 描述

`str \, None`, 任务运行的错误消息，如果没有发生错误则为 None。

## DurableContext

继承自：`Context`

方法：

名称, 描述

`aio_wait_for`, 以持久化方式等待 sleep 或事件。
`aio_sleep_for`, 持久化 sleep 的轻量封装。在指定 sleep 条件时可以简写为 `ctx.aio_wait_for`。

### Functions

#### `aio_wait_for`

以持久化方式等待 sleep 或事件。

参数：

| 名称 | 类型 | 描述 | 默认值 |
| --- | --- | --- | --- |
| `signal_key` | `str` | 用于持久化事件的键。用于在 Hatchet API 中标识该事件。 | _必填_ |
| `*conditions` | `SleepCondition \| UserEventCondition \| OrGroup` | 要等待的条件。可以是 SleepCondition 或 UserEventCondition。 | `()` |
| `label` | `str \| None` | 附加到本次等待的可选标签。对调试和可观测性很有用，并会传播到仪表盘上的事件日志。 | `None` |

返回：

类型, 描述

`dict[str, Any]`, 包含等待结果的字典。

异常：

类型, 描述

`ValueError`, 持久化任务客户端不可用时抛出。
`TypeError`, 持久化事件监听器类型不是 DurableEventListener 或 PreEvictionDurableEventListener 时抛出。

#### `aio_sleep_for`

持久化 sleep 的轻量封装。在指定 sleep 条件时可以简写为 `ctx.aio_wait_for`。

对于更复杂的条件，请直接使用 `ctx.aio_wait_for`。

参数：

名称, 类型, 描述, 默认值

`duration`, `Duration`, sleep 的时长。应为 timedelta 对象。, _必填_
`label`, `str \, None`, 附加到本次 sleep 的可选标签。对调试和可观测性很有用，并会传播到仪表盘上的事件日志。, `None`

返回：

类型, 描述

`SleepResult`, 一个 SleepResult 对象，包含实际 sleep 的时长；在发生持久化驱逐（eviction）并恢复的情况下，可能与请求的时长不同。
