# Dataclass 支持

在本系列文档中，几乎所有 Python 示例都使用 Pydantic 模型来校验任务的输入和输出。这是推荐的做法，因为在你编写任务时它能提供很多安全性保证。话虽如此，Hatchet 也支持使用 `dataclasses` 作为任务的输入和输出类型。**Dataclass 支持是在 SDK 1.21.0 版本中加入的。**

> **警告：** dataclass 在实例化时不会像 Pydantic 模型那样执行任何类型校验。

### 用法

要使用 dataclass 代替 Pydantic 模型，你需要：

1. 为你的 `workflow` 或 `task`（使用 `hatchet.task` 定义独立任务时）提供 `input_validator` 参数。
2. 为你的 `tasks` 添加返回类型注解。

### 使用示例

在 Hatchet 中，`dataclass` 校验器的用法与 Pydantic 模型完全一致。首先，创建这些类：

```python
@dataclass
class Input:
    name: str


@dataclass
class Output:
    message: str
```

然后将这些类提供给你的 workflow 或 task：

```python
@hatchet.task(input_validator=Input)
def say_hello(input: Input, ctx: Context) -> Output:
    return Output(message=f"Hello, {input.name}!")
```

最后，触发方式也是一样的——只需提供 dataclass 实例作为输入：

```python
say_hello.run(input=Input(name="Hatchet"))
```
