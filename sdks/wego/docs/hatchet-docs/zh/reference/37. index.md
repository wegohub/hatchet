# TypeScript SDK

这是 Hatchet TypeScript SDK 的自动生成 API 参考。概念与指南请参见[用户指南](<../v1/01. get-started（入门）/01. index.md>)。

## 核心页面

- [Client](<38. client.md>)：Hatchet 主客户端、其配置以及各 feature client 访问器
- [Context](<39. context.md>)：运行时传递给任务的上下文对象
- [Embedded](<41. embedded.md>)：在进程内运行完整的 Hatchet 引擎用于本地开发
- [Runnables](<40. runnables.md>)：任务与工作流，即你在 worker 上注册并运行的对象

## Feature clients
