# Filters Client

通过 [Hatchet 客户端](<55. client.md>)上的 `client.Filters()` 访问。

## FiltersClient

FiltersClient 提供用于与过滤器交互的方法

方法：

| 名称 | 描述 |
| --- | --- |
| `Create` | Create 创建一个新的过滤器。 |
| `Delete` | Delete 根据其 ID 删除过滤器。 |
| `Get` | Get 根据其 ID 获取过滤器。 |
| `List` | List 列出给定租户的过滤器。 |
| `Update` | Update 根据其 ID 更新过滤器。 |

### 函数

#### `Create`

Create 创建一个新的过滤器。

```go
func (c *FiltersClient) Create(ctx context.Context, opts rest.V1CreateFilterRequest) (*rest.V1Filter, error)
```
