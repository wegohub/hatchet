# Context

Hatchet 的 Context 类为任务在运行时提供辅助方法和有用数据。它作为第二个参数传递给所有任务代码块。

你会遇到两类上下文：

- `Hatchet::Context` - 常规任务的标准上下文，提供日志、任务输出获取、取消等功能。
- `Hatchet::DurableContext` - 持久化任务的扩展上下文，包含 `sleep_for` 和 `wait_for` 等持久化执行的额外方法。

## Context

传递给任务执行代码块的上下文对象。

提供对工作流运行元数据、父任务输出、日志、取消及其他运行时能力的访问。

```ruby
workflow.task(:step2, parents: [step1]) do |input, ctx|
  parent_result = ctx.task_output(step1)
  { "sum" => parent_result["value"] + 1 }
end
```

### Methods

| Name | Description |
| --- | --- |

| `was_skipped?` | 检查父任务是否被跳过。 |
| `log` | 通过 Hatchet 日志系统记录一条消息。 |
| `cancel` | 取消当前工作流运行。 |
| `cancelled?` | 检查任务是否已被取消。 |
| `refresh_timeout` | 刷新此任务的执行超时。 |
| `release_slot` | 在任务完成之前释放 worker 槽位。 |
| `put_stream` | 输出一个流数据块，用于实时流式输出。 |

| `get_task_run_error` | 获取特定上游任务的错误（用于 on_failure 任务） |
| `worker` | 访问 worker 上下文以进行 worker 级别的操作。 |

### Functions

#### `task_output`

获取父任务的输出。

参数：

Name, Type, Description, Default

`task_ref`, `Task \, Symbol \, String`, 对父任务的引用。, _required_

返回：

Type, Description

`Hash \, nil`, 父任务的输出。

#### `was_skipped?`

检查父任务是否被跳过。

参数：

Name, Type, Description, Default

`task_ref`, `Task \, Symbol \, String`, 对父任务的引用。, _required_

返回：

Type, Description

`Boolean`, 如果任务被跳过则为 true。

#### `log`

通过 Hatchet 日志系统记录一条消息。如果有可用的 event 客户端，会通过 gRPC 将日志发送到服务器。

参数：

Name, Type, Description, Default

`message`, `String \, Hash`, 要记录的消息。, _required_

#### `cancel`

取消当前工作流运行。

批量任务在所有缓冲成员之间共享同一个上下文，因此没有可以被取消的单个任务运行；此方法会发送一个覆盖批次中所有成员的批量 CANCELLED 事件。

#### `cancelled?`

检查任务是否已被取消。

返回：

Type, Description

`Boolean`, 如果已请求取消则为 true。

#### `refresh_timeout`

刷新此任务的执行超时。

参数：

Name, Type, Description, Default

`duration`, `Integer \, String`, 新的超时秒数，或时长字符串。, _required_

#### `release_slot`

在任务完成之前释放 worker 槽位。适用于先经历资源密集阶段、后经历轻量阶段的任务。

#### `put_stream`

输出一个流数据块，用于实时流式输出。

参数：

Name, Type, Description, Default

`data`, `String`, 要流式输出的数据块。, _required_

#### `task_run_errors`

获取上游任务运行的错误（用于 on_failure 任务）

返回：

Type, Description

`Array`, 任务运行错误。

#### `get_task_run_error`

获取特定上游任务的错误（用于 on_failure 任务）

参数：

Name, Type, Description, Default

`task_ref`, `Task \, Symbol \, String`, 对失败任务的引用。, _required_

返回：

Type, Description

`TaskRunError \, nil`, 任务运行错误，或 nil。

#### `worker`

访问 worker 上下文以进行 worker 级别的操作。返回的 `WorkerContext` 提供 `id`（worker ID）、`labels`（当前 worker 标签），以及 `upsert_labels`（用于在运行时向服务器添加或更新 worker 标签）。

返回：

Type, Description

`WorkerContext \, nil`, worker 上下文（如果已附加）。

## DurableContext

Bases: `Hatchet::Context`

持久化任务的扩展上下文，支持跨任务挂起的休眠和事件等待。`Context` 的所有方法和属性同样可用。

持久化任务可以被 Hatchet 引擎挂起和恢复，从而支持能够跨越进程重启的长时间运行工作流。

```ruby
hatchet.durable_task(name: "my_task") do |input, ctx|
  ctx.sleep_for(duration: 60) # sleep for 60 seconds
end
```

```ruby
hatchet.durable_task(name: "my_task") do |input, ctx|
  result = ctx.wait_for("event", Hatchet::UserEventCondition.new(event_key: "user:update"))
end
```

### Methods

Name, Description

`sleep_for`, 休眠指定的时长。
`wait_for`, 等待某个条件满足（事件或休眠）。

### Functions

#### `sleep_for`

休眠指定的时长。任务会被引擎挂起，时长到期后由引擎恢复，因此休眠期间不会阻塞 worker 槽位（受任务的淘汰策略约束）。

参数：

Name, Type, Description, Default

`duration`, `Integer \, String`, 时长秒数，或时长字符串（例如 "60s"）, _required_
`label`, `String \, nil`, 可选的等待标签，会显示在持久化事件日志中。, `nil`

返回：

Type, Description

`Hash \, nil`, 休眠事件的结果。

#### `wait_for`

等待某个条件满足（事件或休眠）。任务会被挂起，条件满足后恢复。

参数：

| Name | Type | Description | Default |
| --- | --- | --- | --- |
| `key` | `String` | 此等待操作的唯一键。 | _required_ |
| `condition` | `UserEventCondition \| SleepCondition \| OrCondition` | 要等待的条件。 | _required_ |
| `label` | `String \| nil` | 可选的等待标签，会显示在持久化事件日志中。 | `nil` |

返回：

Type, Description

`Hash`, 等待的结果，包括哪个条件被满足。
