### Filters Client

Filters 客户端用于与 Hatchet 的过滤器 API 交互。

#### 方法：

<a id="create"></a>

##### `create()`

创建一个新的过滤器。

参数：

参数, 类型, 描述

`opts`, `V1CreateFilterRequest`, 创建操作的选项。

返回值：

`Promise`\<`V1Filter`\>

一个 Promise，解析为创建的过滤器。

<a id="delete"></a>

##### `delete()`

根据 ID 删除过滤器。

参数：

参数, 类型, 描述

`filterId`, `string`, 要删除的过滤器 ID。

返回值：

`Promise`\<`V1Filter`\>

一个 Promise，解析为被删除的过滤器。

<a id="get"></a>

##### `get()`

根据 ID 获取过滤器。

参数：

参数, 类型, 描述

`filterId`, `string`, 要获取的过滤器 ID。

返回值：

`Promise`\<`V1Filter`\>

一个 Promise，解析为该过滤器。

<a id="list"></a>

##### `list()`

列出所有过滤器。

参数：

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| `opts?` | \{ `limit?`: `number`; `offset?`: `number`; `scopes?`: ...[]; `workflowIds?`: ...[]; \} | 列表操作的选项。 |
| `opts.limit?` | `number` | 要返回的过滤器数量。 |
| `opts.offset?` | `number` | 返回结果集之前要跳过的过滤器数量。 |
| `opts.scopes?` | ...[] | 用于筛选的范围列表。 |
| `opts.workflowIds?` | ...[] | 用于筛选的工作流 ID 列表。 |

返回值：

`Promise`\<`V1FilterList`\>

一个 Promise，解析为过滤器列表。

<a id="update"></a>

##### `update()`

根据 ID 更新过滤器。

参数：

参数, 类型, 描述

`filterId`, `string`, 要更新的过滤器 ID。
`updates`, `V1UpdateFilterRequest`, 要应用到该过滤器的更新内容。

返回值：

`Promise`\<`V1Filter`\>

一个 Promise，解析为更新后的过滤器。
