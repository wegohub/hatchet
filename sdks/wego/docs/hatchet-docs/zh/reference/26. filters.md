# Filters Client

继承自：`BaseRestClient`

filters 客户端用于与 Hatchet 的过滤器 API 交互。

方法：

| 名称 | 描述 |
| --- | --- |
| `aio_create` | 创建一个新过滤器。 |
| `aio_delete` | 按 ID 删除过滤器。 |
| `aio_get` | 按 ID 获取过滤器。 |
| `aio_list` | 列出给定租户的过滤器。 |
| `aio_update` | 按 ID 更新过滤器。 |
| `create` | 创建一个新过滤器。 |
| `delete` | 按 ID 删除过滤器。 |
| `get` | 按 ID 获取过滤器。 |
| `list` | 列出给定租户的过滤器。 |
| `update` | 按 ID 更新过滤器。 |

### Functions

#### `aio_create`

创建一个新过滤器。

参数：

| 名称 | 类型 | 描述 | 默认值 |
| --- | --- | --- | --- |
| `workflow_id` | `str` | 与过滤器关联的工作流 ID。 | _必填_ |
| `expression` | `str` | 过滤器要计算的表达式。 | _必填_ |
| `scope` | `str` | 过滤器的作用域。 | _必填_ |
| `payload` | `JSONSerializableMapping \| None` | 随过滤器发送的 payload。 | `None` |

返回：

类型, 描述

`V1Filter`, 创建的过滤器。

#### `aio_delete`

按 ID 删除过滤器。

参数：

名称, 类型, 描述, 默认值

`filter_id`, `str`, 要删除的过滤器 ID。, _必填_

返回：

类型, 描述

`V1Filter`, 被删除的过滤器。

#### `aio_get`

按 ID 获取过滤器。

参数：

名称, 类型, 描述, 默认值

`filter_id`, `str`, 要获取的过滤器 ID。, _必填_

返回：

类型, 描述

`V1Filter`, 具有指定 ID 的过滤器。

#### `aio_list`

列出给定租户的过滤器。

参数：

| 名称 | 类型 | 描述 | 默认值 |
| --- | --- | --- | --- |
| `limit` | `int \| None` | 返回过滤器的最大数量。 | `None` |
| `offset` | `int \| None` | 开始收集结果集之前跳过的过滤器数量。 | `None` |
| `workflow_ids` | `list[str] \| None` | 用于过滤的工作流 ID 列表。 | `None` |
| `scopes` | `list[str] \| None` | 用于过滤的作用域列表。 | `None` |

返回：

类型, 描述

`V1FilterList`, 符合指定条件的过滤器列表。

#### `aio_update`

按 ID 更新过滤器。

参数：

名称, 类型, 描述, 默认值

`filter_id`, `str`, 要删除的过滤器 ID。, _必填_
`updates`, `V1UpdateFilterRequest`, 要应用到过滤器上的更新。, _必填_

返回：

类型, 描述

`V1Filter`, 更新后的过滤器。
