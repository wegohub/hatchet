# Embedded

嵌入式模式将一个完整的本地 Hatchet 引擎作为由你的应用程序管理的 sidecar 进程运行。
它不需要 API token、不需要 Docker，也不需要外部服务（默认情况下 sidecar 会启动一个
内置的 Postgres），因此非常适合本地开发和 CI。

```typescript
import { HatchetEmbeddedClient } from "@hatchet-dev/typescript-sdk/v1/embedded";

const hatchet = await HatchetEmbeddedClient.init();
// ... 像往常一样注册 worker 并运行任务 ...
await hatchet.stopEmbedded();
```

安装和配置详情请参见[嵌入式模式指南](https://docs.hatchet.run/v1/embedded)。

<a id="hatchetembeddedclient"></a>

### Hatchet Embedded Client

嵌入式模式的入口点。`init()` 会启动一个完整的本地 Hatchet 引擎，
并返回连接到它的常规 Hatchet 客户端。无需 API token 或 Docker。
参见[嵌入式模式指南](https://docs.hatchet.run/v1/embedded)。

#### 方法

<a id="init"></a>

##### `init()`

通过 hatchet-embedded sidecar（首次使用时下载）在本地运行一个完整的
Hatchet 引擎，并返回连接到它的客户端。无需 API token 或 Docker，
因此非常适合本地开发和 CI。默认情况下 sidecar 会启动一个内置的
Postgres；传入 `databaseUrl` 可以改为指向你自己的数据库。

参见[嵌入式模式指南](https://docs.hatchet.run/v1/embedded)。

参数

| Parameter | Type | Description |
| --- | --- | --- |
| `embeddedOpts?` | [`EmbeddedOptions`](#embeddedoptions) | 嵌入式引擎的选项（版本、端口、数据库等）。 |
| `config?` | `Omit`\<`Partial`\<`ClientConfig`\>, `"middleware"`\> | 客户端的可选配置覆盖。 |
| `options?` | `HatchetClientOptions` | 可选的客户端选项。 |
| `axiosConfig?` | `AxiosRequestConfig`\<`any`\> | HTTP 请求的可选 Axios 配置。 |

返回值

`Promise`\<[`EmbeddedClient`](#embeddedclient)\<`T`, `U`\>\>

连接到嵌入式引擎的新 Hatchet 客户端实例。

## 接口

<a id="embeddedoptions"></a>

### EmbeddedOptions

嵌入式引擎 sidecar 的选项。所有字段均为可选；默认情况下会下载并启动
最新版 hatchet-embedded，并附带一个内置 Postgres。

属性

| Property | Type | Description |
| --- | --- | --- |
| <a id="apiport"></a> `apiPort?` | `number` | 将 REST API 服务器绑定到该端口 |
| <a id="binarypath"></a> `binaryPath?` | `string` | 已有 sidecar 二进制文件的路径，设置后跳过下载（或使用 HATCHET_CLIENT_EMBEDDED_BINARY_PATH） |
| <a id="checksum"></a> `checksum?` | `string` | sidecar 二进制文件预期的 sha256 十六进制摘要。设置后，它将取代发布版的 checksums.txt 作为信任锚点，因此即使发布渠道被攻破也无法替换二进制文件。请与 `version` 一起固定。 |
| <a id="databaseurl"></a> `databaseUrl?` | `string` | 使用已有的 Postgres，而非内置实例 |
| <a id="grpcport"></a> `grpcPort?` | `number` | 将引擎的 gRPC 服务器绑定到该端口 |
| <a id="loglevel"></a> `logLevel?` | `string` | 引擎输出的日志级别 |
| <a id="postgresdatadir"></a> `postgresDataDir?` | `string` | 将内置 Postgres 的运行时和数据存储在该目录下 |
| <a id="rabbitmqurl"></a> `rabbitmqUrl?` | `string` | 使用 RabbitMQ 代替 Postgres 消息队列 |
| <a id="readytimeoutms"></a> `readyTimeoutMs?` | `number` | 等待引擎就绪的时长，单位毫秒（默认 300000） |
| <a id="runmigrations"></a> `runMigrations?` | `boolean` | 设为 false 可跳过启动时的迁移 |
| <a id="startapi"></a> `startApi?` | `boolean` | 设为 false 可只启动引擎 + gRPC，不启动 REST API |
| <a id="version"></a> `version?` | `string` | 要下载的 hatchet-embedded 发布标签（默认为 HATCHET_CLIENT_EMBEDDED_VERSION 或 latest）。标签与 sidecar 中内置的 Hatchet 引擎版本对应，因此固定此值即固定了引擎。 |

<a id="embeddedsidecar"></a>

### EmbeddedSidecar

一个正在运行的嵌入式引擎 sidecar 及其连接信息，由 `startEmbeddedSidecar` 返回。

属性

| Property | Type | Description |
| --- | --- | --- |
| <a id="apiurl"></a> `apiUrl` | `string` | REST API 的 base URL（`startApi` 为 false 时为空） |
| <a id="grpcaddress"></a> `grpcAddress` | `string` | 引擎 gRPC 服务器的 host:port |
| <a id="stop"></a> `stop` | () => `Promise`\<`void`\> | 优雅地停止 sidecar，并在其完全退出后 resolve |
| <a id="tenantid"></a> `tenantId` | `string` | sidecar 默认租户的 ID |
| <a id="token"></a> `token` | `string` | sidecar 默认租户的 API token |

## 类型别名

<a id="embeddedclient"></a>

### Embedded Client

```ts
type EmbeddedClient = HatchetClient & object;
```

一个连接到嵌入式引擎的 `HatchetClient`，扩展了 `stopEmbedded`。
由 [HatchetEmbeddedClient.init](#init) 返回。

#### 类型声明

Name, Type, Description

`stopEmbedded()`, () => `Promise`\<...\>, 优雅地停止嵌入式引擎 sidecar，并在其（包括内置 Postgres）完全退出后 resolve。请在进程退出前调用它，以免引擎的关闭输出在你的程序返回之后才打印。

## 函数

<a id="startembeddedsidecar"></a>

### `startEmbeddedSidecar()`

下载（并缓存）hatchet-embedded sidecar 二进制文件，启动它，并等待嵌入式引擎
就绪。当进程退出时 sidecar 会随之关闭。除非你需要原始的连接信息，
否则请使用 [HatchetEmbeddedClient.init](#init)。

参数

Parameter, Type

`opts`, [`EmbeddedOptions`](#embeddedoptions)

返回值

`Promise`\<[`EmbeddedSidecar`](#embeddedsidecar)\>

---

<a id="stopembeddedsidecar"></a>

### `stopEmbeddedSidecar()`

优雅地停止本进程中由 `HatchetEmbeddedClient.init()`（或
`startEmbeddedSidecar`）启动的所有 sidecar，并在它们（包括其内置
Postgres）完全退出后 resolve。请在进程退出前调用它，以免引擎的关闭
输出在你的程序返回之后才打印。

返回值

`Promise`\<`void`\>
