# Metrics 客户端

通过 [Hatchet 客户端](<55. client.md>)上的 `client.Metrics()` 访问。

## MetricsClient

MetricsClient 提供获取工作流、任务以及租户队列指标的方法

方法：

| 名称 | 描述 |
| --- | --- |
| `GetQueueMetrics` | GetQueueMetrics 获取租户级别的队列指标。 |
| `GetTaskQueueMetrics` | GetTaskQueueMetrics 获取租户级别的步骤运行队列指标。 |
| `GetWorkflowMetrics` | GetWorkflowMetrics 获取特定工作流的指标。 |

### 函数

#### `GetQueueMetrics`

GetQueueMetrics 获取租户级别的队列指标。

```go
func (m *MetricsClient) GetQueueMetrics(ctx context.Context, opts *rest.TenantGetQueueMetricsParams) (*rest.TenantQueueMetrics, error)
```

参数：

名称, 类型

`ctx`, `context.Context`
`opts`, `*rest.TenantGetQueueMetricsParams`

返回值：

类型

`*rest.TenantQueueMetrics`
`error`

#### `GetTaskQueueMetrics`

GetTaskQueueMetrics 获取租户级别的步骤运行队列指标。

```go
func (m *MetricsClient) GetTaskQueueMetrics(ctx context.Context) (*rest.TenantStepRunQueueMetrics, error)
```

参数：

名称, 类型

`ctx`, `context.Context`

返回值：

类型

`*rest.TenantStepRunQueueMetrics`
`error`

#### `GetWorkflowMetrics`

GetWorkflowMetrics 获取特定工作流的指标。

```go
func (m *MetricsClient) GetWorkflowMetrics(ctx context.Context, workflowName string, opts *rest.WorkflowGetMetricsParams) (*rest.WorkflowMetrics, error)
```

参数：

| 名称 | 类型 |
| --- | --- |
| `ctx` | `context.Context` |
| `workflowName` | `string` |
| `opts` | `*rest.WorkflowGetMetricsParams` |

返回值：

类型

`*rest.WorkflowMetrics`
`error`
