# Runs Client

继承自：`BaseRestClient`

runs 客户端用于与 Hatchet 中的任务运行和工作流运行交互。

方法：

| 名称 | 描述 |
| --- | --- |
| `get` | 获取给定工作流运行 ID 的工作流运行详情。 |
| `aio_get` | 获取给定工作流运行 ID 的工作流运行详情。 |
| `get_status` | 获取给定工作流运行 ID 的工作流运行状态。 |
| `aio_get_status` | 获取给定工作流运行 ID 的工作流运行状态。 |

| `replay` | 重放一次任务或工作流运行。 |

| `bulk_replay` | 按一组过滤条件批量重放任务或工作流运行。 |

#### `list`

按一组过滤条件列出任务运行。

参数：

| 名称 | 类型 | 描述 | 默认值 |
| --- | --- | --- | --- |
| `since` | `datetime \| None` | 过滤任务运行的起始时间。 | `None` |
| `only_tasks` | `bool` | 是否只列出任务运行。 | `False` |
| `offset` | `int \| None` | 分页偏移量。 | `None` |
| `limit` | `int \| None` | 返回任务运行的最大数量。 | `None` |
| `statuses` | `list[V1TaskStatus] \| None` | 用于过滤任务运行的状态列表。 | `None` |
| `until` | `datetime \| None` | 过滤任务运行的结束时间。 | `None` |
| `additional_metadata` | `dict[str, str] \| None` | 用于过滤任务运行的附加元数据。 | `None` |
| `workflow_ids` | `list[str] \| None` | 用于过滤任务运行的工作流 ID 列表。 | `None` |
| `worker_id` | `str \| None` | 用于过滤任务运行的 worker ID。 | `None` |
| `parent_task_external_id` | `str \| None` | 用于过滤任务运行的父任务外部 ID。 | `None` |
| `triggering_event_external_id` | `str \| None` | 触发该任务运行的事件 ID。 | `None` |
| `include_payloads` | `bool` | 响应中是否包含 payload。 | `True` |

返回：

类型, 描述

`V1TaskSummaryList`, 符合指定过滤条件的任务运行列表。

#### `create`

触发一个新的工作流运行。

重要提示：如果可以，建议优先使用 `Workflow.run`（及类似方法）来触发工作流。此方法定位为逃生通道（escape hatch）。更多细节见[文档](<17. runnables.md#workflow>)。

参数：

| 名称 | 类型 | 描述 | 默认值 |
| --- | --- | --- | --- |
| `workflow_name` | `str` | 要触发的工作流名称。 | _必填_ |
| `input` | `JSONSerializableMapping` | 工作流运行的输入数据。 | _必填_ |
| `additional_metadata` | `JSONSerializableMapping \| None` | 与工作流运行关联的附加元数据。 | `None` |
| `priority` | `int \| Priority \| None` | 工作流运行的优先级。 | `None` |

返回：

类型, 描述

`V1WorkflowRunDetails`, 被触发的工作流运行的详情。

#### `bulk_cancel_by_filters_with_pagination`

分批（chunk）取消符合指定过滤条件的运行。

此方法的目的是提供一种简便方式，按过滤条件对超出 API 正常处理能力的更多运行执行批量操作，并通过自动分页和分块来限制对 API 的压力。

该方法先从 API 拉取运行的 ID，然后分块回传给 API。

参数：

| 名称 | 类型 | 描述 | 默认值 |
| --- | --- | --- | --- |
| `sleep_time` | `int` | 处理各块之间的 sleep 时间（秒）。 | `3` |
| `chunk_size` | `int` | 每块处理运行 ID 的最大数量。 | `500` |
| `since` | `datetime \| None` | 过滤运行的起始时间。 | `None` |
| `until` | `datetime \| None` | 过滤运行的结束时间。 | `None` |
| `statuses` | `list[V1TaskStatus] \| None` | 用于过滤运行的状态列表。 | `None` |
| `additional_metadata` | `dict[str, str] \| None` | 用于过滤运行的附加元数据。 | `None` |
| `workflow_ids` | `list[str] \| None` | 用于过滤运行的工作流 ID 列表。 | `None` |
