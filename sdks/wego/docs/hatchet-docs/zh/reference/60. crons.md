# Crons Client

通过 [Hatchet 客户端](<55. client.md>)上的 `client.Crons()` 访问。

## CronsClient

CronsClient 提供用于与 cron 工作流触发器交互的方法

方法：

| 名称 | 描述 |
| --- | --- |
| `Create` | Create 创建一个新的 cron 工作流触发器。 |
| `Delete` | Delete 删除一个 cron 工作流触发器。 |
| `Get` | Get 根据其 ID 获取特定的 cron 工作流触发器。 |
| `List` | List 根据提供的参数获取一组 cron 工作流触发器。 |

## 相关类型

### RunPriority

RunPriority 是工作流运行的优先级。

```go
const (
	// RunPriorityLow is the lowest priority for a workflow run.
	RunPriorityLow	RunPriority	= 1
	// RunPriorityMedium is the medium priority for a workflow run.
	RunPriorityMedium	RunPriority	= 2
	// RunPriorityHigh is the highest priority for a workflow run.
	RunPriorityHigh	RunPriority	= 3
)
```

### CreateCronTrigger

CreateCronTrigger 包含创建 cron 触发器的配置。

字段：

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| `Name` | `string` | Name 是 cron 触发器的唯一标识符。 |
| `Expression` | `string` | Expression 是定义调度计划的 cron 表达式。 |
| `Input` | `map[string]interface{}` | （可选）Input 是工作流的输入数据。 |
| `AdditionalMetadata` | `map[string]interface{}` | （可选）AdditionalMetadata 是要关联到该 cron 触发器的元数据。 |
| `Priority` | `*RunPriority` | （可选）Priority 是该 cron 触发的运行的优先级。 |

### `IsValidCronExpression`

IsValidCronExpression 验证一个字符串是否为有效的 cron 表达式。
