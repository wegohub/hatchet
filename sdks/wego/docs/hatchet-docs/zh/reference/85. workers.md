# Workers Client

用于在 Hatchet 中以编程方式管理 worker 的 workers 客户端。

此类为在 Hatchet 系统中获取、列出和更新 worker 提供了高层接口。

```ruby
worker = hatchet.workers.get("worker-id")
```

```ruby
workers = hatchet.workers.list
```

它在主客户端上以 `hatchet.workers` 的形式提供。

方法：

| Name | Description |
| --- | --- |
| `get` | 按 ID 获取 worker。 |
| `list` | 列出租户中的所有 worker。 |
| `update` | 按 ID 更新 worker。 |

### Functions

#### `get`

按 ID 获取 worker。

```ruby
worker = hatchet.workers.get("worker-123")
```

参数：

Name, Type, Description, Default

`worker_id`, `String`, 要获取的 worker 的 ID。, _required_

返回：

Type, Description

`Object`, worker 详细信息。

抛出：

Type, Description

`HatchetSdkRest::ApiError`, 如果 API 请求失败。

#### `list`

列出租户中的所有 worker。

```ruby
workers = hatchet.workers.list
```

返回：

Type, Description

`Object`, worker 列表。

抛出：

Type, Description

`HatchetSdkRest::ApiError`, 如果 API 请求失败。

#### `update`

按 ID 更新 worker。

```ruby
updated = hatchet.workers.update("worker-123", { is_paused: true })
```

参数：

Name, Type, Description, Default

`worker_id`, `String`, 要更新的 worker 的 ID。, _required_
`opts`, `Hash`, 更新选项。, _required_

返回：

Type, Description

`Object`, 更新后的 worker。

抛出：

Type, Description

`HatchetSdkRest::ApiError`, 如果 API 请求失败。
