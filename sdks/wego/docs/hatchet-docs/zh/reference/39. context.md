# Context

Hatchet 的 Context 类在运行时为任务提供辅助方法和有用的数据。它作为第二个参数传递给所有任务和持久化任务。

你会遇到两种上下文类：

- Context - 常规任务的标准上下文，提供日志记录、任务输出获取、取消等方法。
- DurableContext - 面向持久化任务的扩展上下文，包含额外的持久化执行方法。

### `computeMemoKey()`

为某个任务运行及其依赖值派生 memo key：将任务运行 ID 与 JSON 序列化的依赖值
拼接后计算 SHA-256，基于 WebCrypto 实现，因此在所有运行时中都能工作。
其字节与之前的 Node `createHash` 版本完全一致，因此旧版 SDK 记录的事件日志
仍可继续重放。

参数

Parameter, Type

`taskRunExternalId`, `string`
`args`, readonly `unknown`[]

返回值

`Promise`\<`Uint8Array`\<`ArrayBufferLike`\>\>
