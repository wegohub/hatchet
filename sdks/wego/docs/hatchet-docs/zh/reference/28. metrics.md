# Metrics Client

继承自：`BaseRestClient`

metrics 客户端用于从 Hatchet 的指标 API 读取指标。

方法：

| 名称 | 描述 |
| --- | --- |
| `aio_get_queue_metrics` | 获取租户当前的队列指标。 |
| `aio_get_task_metrics` | 获取任务指标，按状态分组（queued、running、completed、failed、cancelled）。 |
| `aio_get_task_stats` | 获取租户的任务统计信息。 |
| `aio_scrape_tenant_prometheus_metrics` | 抓取租户的 Prometheus 指标。以 Prometheus 文本格式返回指标。 |
| `get_queue_metrics` | 获取租户当前的队列指标。 |
| `get_task_metrics` | 获取任务指标，按状态分组（queued、running、completed、failed、cancelled）。 |
| `get_task_stats` | 获取租户的任务统计信息。 |
| `scrape_tenant_prometheus_metrics` | 抓取租户的 Prometheus 指标。以 Prometheus 文本格式返回指标。 |

### Functions

#### `aio_get_queue_metrics`

获取租户当前的队列指标。

返回：

类型, 描述

`dict[str, Any]`, 当前队列指标

#### `aio_get_task_metrics`

获取任务指标，按状态分组（queued、running、completed、failed、cancelled）。

参数：

| 名称 | 类型 | 描述 | 默认值 |
| --- | --- | --- | --- |
| `since` | `datetime \| None` | 指标查询的起始时间（未设置时默认为过去一天） | `None` |
| `until` | `datetime \| None` | 指标查询的结束时间 | `None` |
| `workflow_ids` | `list[str] \| None` | 用于过滤指标的工作流 ID 列表 | `None` |
| `parent_task_external_id` | `str \| None` | 用于过滤的父任务 ID（注意这里的父任务指将本任务作为子任务派生出来的那个任务） | `None` |
| `triggering_event_external_id` | `str \| None` | 用于过滤的触发事件 ID | `None` |

返回：

类型, 描述

`TaskMetrics`, 任务指标

#### `aio_get_task_stats`

获取租户的任务统计信息。

返回：

类型, 描述

`dict[str, TaskStat]`, 一个将任务名称映射到其统计信息的字典。

#### `aio_scrape_tenant_prometheus_metrics`

抓取租户的 Prometheus 指标。以 Prometheus 文本格式返回指标。

返回：

类型, 描述

`str`, 以 Prometheus 文本格式返回的指标
