# CEL Client

通过 [Hatchet 客户端](<55. client.md>)上的 `client.CEL()` 访问。

## CELClient

CELClient 提供用于求值 CEL 表达式的方法

### 函数

#### `Debug`

Debug 使用提供的输入、过滤器负载和可选元数据对 CEL 表达式求值。适用于测试和验证 CEL 表达式，以及调试生产环境中的问题。

```go
func (c *CELClient) Debug(ctx context.Context, expression string, input map[string]any, additionalMetadata, filterPayload *map[string]any) (*rest.V1CELDebugResponse, error)
```

参数：

| 名称 | 类型 |
| --- | --- |
| `ctx` | `context.Context` |
| `expression` | `string` |
| `input` | `map[string]any` |
| `additionalMetadata` | `*map[string]any` |
| `filterPayload` | `*map[string]any` |

返回值：

类型

`*rest.V1CELDebugResponse`
`error`
