# Metrics Client

用于从 Hatchet 指标 API 读取指标的 metrics 客户端。

此类为从 Hatchet 系统获取队列指标、Prometheus 指标、任务统计和任务指标提供了高层接口。

```ruby
metrics = hatchet.metrics.get_queue_metrics
```

```ruby
task_metrics = hatchet.metrics.get_task_metrics(
  since: Time.now - 86400,
  workflow_ids: ["wf-1"]
)
```

它在主客户端上以 `hatchet.metrics` 的形式提供。

方法：

| Name | Description |
| --- | --- |
| `get_queue_metrics` | 获取租户当前的队列指标。 |
| `scrape_tenant_prometheus_metrics` | 抓取租户的 Prometheus 指标。 |
| `get_task_stats` | 获取租户的任务统计。 |
| `get_task_metrics` | 获取按状态分组（queued、running、completed、failed、cancelled）的任务指标 |

### Functions

#### `get_queue_metrics`

获取租户当前的队列指标。

```ruby
queues = hatchet.metrics.get_queue_metrics
```

返回：

Type, Description

`Hash`, 当前的队列指标。

抛出：

Type, Description

`HatchetSdkRest::ApiError`, 如果 API 请求失败。

#### `scrape_tenant_prometheus_metrics`

抓取租户的 Prometheus 指标。

```ruby
prometheus_text = hatchet.metrics.scrape_tenant_prometheus_metrics
```

返回：

Type, Description

`String`, Prometheus 文本格式的指标。

抛出：

Type, Description

`HatchetSdkRest::ApiError`, 如果 API 请求失败。

#### `get_task_stats`

获取租户的任务统计。

```ruby
stats = hatchet.metrics.get_task_stats
```

返回：

Type, Description

`Object`, 任务统计。

抛出：

Type, Description

`HatchetSdkRest::ApiError`, 如果 API 请求失败。

#### `get_task_metrics`

获取按状态分组（queued、running、completed、failed、cancelled）的任务指标

```ruby
metrics = hatchet.metrics.get_task_metrics(
  since: Time.now - 86400,
  workflow_ids: ["wf-1"]
)
puts "Completed: #{metrics.completed}, Failed: #{metrics.failed}"
```

参数：

| Name | Type | Description | Default |
| --- | --- | --- | --- |
| `since` | `Time \| nil` | 指标查询的起始时间（未设置时默认为过去一天） | `nil` |
| `until_time` | `Time \| nil` | 指标查询的结束时间。 | `nil` |
| `workflow_ids` | `Array \| nil` | 用于过滤指标的工作流 ID 列表。 | `nil` |
| `parent_task_external_id` | `String \| nil` | 用于过滤的父任务 ID。 | `nil` |
| `triggering_event_external_id` | `String \| nil` | 用于过滤的触发事件 ID。 | `nil` |

返回：

Type, Description

`TaskMetrics`, 按状态统计计数的任务指标。

抛出：

Type, Description

`HatchetSdkRest::ApiError`, 如果 API 请求失败。
