<a id="scheduleclient"></a>

### Schedule Client

Schedule 客户端用于管理 Hatchet 中的定时工作流。

#### 方法：

<a id="bulkdelete"></a>

##### `bulkDelete()`

批量删除定时运行（通过显式 ID 和/或过滤器）。

参数：

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| `opts` | \{ `filter?`: `ScheduledWorkflowsBulkDeleteFilter`; `scheduledRuns?`: (... \| ...)[]; \} | `scheduledRuns`（ID/对象）和/或服务端过滤器。 |
| `opts.filter?` | `ScheduledWorkflowsBulkDeleteFilter` | - |
| `opts.scheduledRuns?` | (... \| ...)[] | - |

返回值：

`Promise`\<`ScheduledWorkflowsBulkDeleteResponse`\>

一个 Promise，解析为已删除的 ID 以及每个 ID 对应的错误。

<a id="bulkupdate"></a>

##### `bulkUpdate()`

批量更新（重新调度）定时运行。

参数：

参数, 类型, 描述

`updates`, `object`[], ID/对象与新 triggerAt 的列表。

返回值：

`Promise`\<`ScheduledWorkflowsBulkUpdateResponse`\>

一个 Promise，解析为已更新的 ID 以及每个 ID 对应的错误。

<a id="create"></a>

##### `create()`

创建一个新的定时运行（Scheduled Run）。

参数：

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| `workflow` | `string` \| `Workflow` | 工作流名称或 Workflow 对象。 |
| `cron` | \{ `additionalMetadata?`: `Record`\<`string`, `string`\>; `input?`: `Record`\<`any`, `any`\>; `priority?`: `number`; `triggerAt`: `Date`; \} | - |
| `cron.additionalMetadata?` | `Record`\<`string`, `string`\> | - |
| `cron.input?` | `Record`\<`any`, `any`\> | - |
| `cron.priority?` | `number` | - |
| `cron.triggerAt` | `Date` | - |

返回值：

`Promise`\<`ScheduledWorkflows`\>

一个 Promise，解析为创建的 ScheduledWorkflows 对象。

抛出：

如果输入无效或 API 调用失败，将抛出错误。

###### Important

此方法由 HatchetInstrumentor.\_patchScheduleCreate 进行插桩。
请保持其签名与 instrumentor 包装器同步。

<a id="delete"></a>

##### `delete()`

删除一个已有的定时运行。

参数：

参数, 类型, 描述

`scheduledRun`, `string` \, `ScheduledWorkflows`, 定时运行 ID（字符串）或 ScheduledWorkflows 对象。

返回值：

`Promise`\<`void`\>

定时运行删除完成后解析的 Promise。

<a id="get"></a>

##### `get()`

根据 ID 获取指定的定时运行。

参数：

参数, 类型, 描述

`scheduledRun`, `string` \, `ScheduledWorkflows`, 定时运行 ID（字符串）或 ScheduledWorkflows 对象。

返回值：

`Promise`\<`ScheduledWorkflows`\>

一个 Promise，解析为 ScheduledWorkflows 对象。

<a id="list"></a>

##### `list()`

根据提供的查询参数列出所有定时运行。

参数：

参数, 类型, 描述

`query`, `object` & `object`, 列出定时运行的查询参数。

返回值：

`Promise`\<`ScheduledWorkflowsList`\>

一个 Promise，解析为 ScheduledWorkflowsList 对象。

<a id="update"></a>

##### `update()`

更新（重新调度）一个已有的定时运行。

参数：

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| `scheduledRun` | `string` \| `ScheduledWorkflows` | 定时运行 ID（字符串）或 ScheduledWorkflows 对象。 |
| `update` | \{ `triggerAt`: `Date`; \} | 更新载荷（目前仅支持 triggerAt）。 |
| `update.triggerAt` | `Date` | - |

返回值：

`Promise`\<`ScheduledWorkflows`\>

一个 Promise，解析为更新后的 ScheduledWorkflows 对象。
