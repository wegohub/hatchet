# Logs Client

用于与 Hatchet 日志 API 交互的 logs 客户端。

此类为列出 Hatchet 系统中与任务运行关联的日志行提供了高层接口。

```ruby
logs = hatchet.logs.list("task-run-id", limit: 100)
```

它在主客户端上以 `hatchet.logs` 的形式提供。

方法：

Name, Description

`list`, 列出给定任务运行的日志行。

### Functions

#### `list`

列出给定任务运行的日志行。

```ruby
logs = hatchet.logs.list("task-run-123", limit: 500, since: Time.now - 3600)
```

参数：

| Name | Type | Description | Default |
| --- | --- | --- | --- |
| `task_run_id` | `String` | 要列出日志的任务运行的 ID。 | _required_ |
| `limit` | `Integer` | 返回的最大日志行数（默认：1000） | `1000` |
| `since` | `Time \| nil` | 获取日志的起始时间。 | `nil` |
| `until_time` | `Time \| nil` | 获取日志的结束时间。 | `nil` |

返回：

Type, Description

`Object`, 指定任务运行的日志行列表。

抛出：

Type, Description

`HatchetSdkRest::ApiError`, 如果 API 请求失败。
