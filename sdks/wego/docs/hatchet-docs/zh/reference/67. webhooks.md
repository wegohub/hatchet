# Webhooks 客户端

通过 [Hatchet 客户端](<55. client.md>)上的 `client.Webhooks()` 访问。

## WebhooksClient

WebhooksClient 提供管理 webhook 配置的方法

方法：

| 名称 | 描述 |
| --- | --- |
| `Create` | Create 创建新的 webhook 配置。 |
| `Delete` | Delete 删除 webhook 配置。 |
| `Get` | Get 根据名称获取特定的 webhook。 |
| `List` | List 根据提供的参数获取 webhook 的集合。 |
| `Update` | Update 更新现有的 webhook 配置。 |

### 函数

#### `Create`

Create 创建新的 webhook 配置。

```go
func (c *WebhooksClient) Create(ctx context.Context, opts CreateWebhookOpts) (*rest.V1Webhook, error)
```

参数：

名称, 类型

`ctx`, `context.Context`
`opts`, `CreateWebhookOpts`

返回值：

类型

`*rest.V1Webhook`
`error`
