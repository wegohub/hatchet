# Tenant Client

用于与当前 Hatchet 租户交互的 tenant 客户端。

此类为从 Hatchet 系统获取租户信息提供了高层接口。

```ruby
tenant_info = hatchet.tenant.get
```

它在主客户端上以 `hatchet.tenant` 的形式提供。

方法：

Name, Description

`get`, 获取当前租户。

### Functions

#### `get`

获取当前租户。

```ruby
tenant = hatchet.tenant.get
```

返回：

Type, Description

`Object`, 租户详细信息。

抛出：

Type, Description

`HatchetSdkRest::ApiError`, 如果 API 请求失败。
