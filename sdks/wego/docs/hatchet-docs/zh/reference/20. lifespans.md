# Lifespans


  Lifespan 是 Hatchet 的一项**实验性功能**，未来可能发生变化。


Hatchet 的 Python SDK 允许你定义一个 **_lifespan_**，它是一个异步生成器：在 worker 启动时运行，在退出时执行清理，从而让你可以在该 worker 上运行的所有任务之间共享状态。其行为与 [FastAPI 的 lifespans](https://fastapi.tiangolo.com/advanced/events/) 几乎完全一致，使用方式也相同。Lifespan 适合用于在单个 worker 上的所有任务之间共享连接池之类的状态，也非常适合在 worker 启动前将开销较大的机器学习模型加载到内存中。


  我们建议只使用 lifespan 存储**_不可变（immutable）_**状态，以便在
  worker 上运行的任务之间共享。其用途并不包括例如存储一个
  worker 已运行任务数的计数器并在每次任务运行时递增——由于
  Hatchet 的并发机制，这样做容易出现意外行为。


## 用法

要使用 Hatchet 的 `lifespan` 功能，定义一个异步生成器并传给 `worker`：

```python
class Lifespan(BaseModel):
    model_config = ConfigDict(arbitrary_types_allowed=True)

    foo: str
    pool: ConnectionPool


async def lifespan() -> AsyncGenerator[Lifespan, None]:
    print("Running lifespan!")
    with ConnectionPool("postgres://hatchet:hatchet@localhost:5431/hatchet") as pool:
        yield Lifespan(
            foo="bar",
            pool=pool,
        )

    print("Cleaning up lifespan!")


worker = hatchet.worker(
    "test-worker", slots=1, workflows=[lifespan_workflow], lifespan=lifespan
)
```

worker 启动时会运行 lifespan 直到 `yield` 处。然后在 worker 关闭时，通过运行 `yield` 之后的全部内容来完成清理（与其他生成器一样）。


  你的 lifespan 只能 `yield` **_一次_**。


之后，要在任务中使用 lifespan，可以通过 `Context.lifespan` 从上下文中提取。

```python
class TaskOutput(BaseModel):
    num_rows: int
    external_ids: list[UUID]


lifespan_workflow = hatchet.workflow(name="LifespanWorkflow")


@lifespan_workflow.task()
def sync_lifespan_task(input: EmptyModel, ctx: Context) -> TaskOutput:
    pool = cast(Lifespan, ctx.lifespan).pool

    with pool.connection() as conn:
        query = conn.execute("SELECT * FROM v1_lookup_table_olap LIMIT 5;")
        rows = query.fetchall()

        for row in rows:
            print(row)

        print("executed sync task with lifespan", ctx.lifespan)

        return TaskOutput(
            num_rows=len(rows),
            external_ids=[cast(UUID, row[0]) for row in rows],
        )
```


  为了类型检查，请将 `Context.lifespan` 转换（cast）为你的 lifespan
  生成器所 yield 的类型。


就是这样！现在，任何运行在提供了 lifespan 的 worker 上的任务都可以访问该 lifespan 数据。
