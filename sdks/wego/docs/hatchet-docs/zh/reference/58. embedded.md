# Embedded

嵌入式模式在进程内运行完整的 Hatchet 引擎和 Postgres 实例，用于本地开发，无需账户、API token 或 Docker。它需要空白导入 [github.com/hatchet-dev/hatchet-embedded](https://github.com/hatchet-dev/hatchet-embedded)，该包会注册引擎后端。指南请参见 [Embedded Mode](<../v1/01. get-started（入门）/05. embedded.md>)。

## `WithEmbedded`

WithEmbedded 在进程内运行完整的 Hatchet 引擎用于本地开发，无需 API token 或 Docker。默认情况下它会启动一个内置的 Postgres；传入 WithEmbeddedDatabaseURL 可以改为指向你自己的数据库。

需要空白导入 hatchet-embedded 包（github.com/hatchet-dev/hatchet-embedded），该包会注册引擎后端。用法请参见[嵌入式模式指南](https://docs.hatchet.run/v1/embedded)。

```go
func WithEmbedded(opts ...EmbeddedOption) client.ClientOpt
```

参数：

名称, 类型

`opts`, `...EmbeddedOption`

返回值：

类型

`client.ClientOpt`

## Embedded 选项

`WithEmbedded` 的选项：

| 名称 | 签名 | 描述 |
| --- | --- | --- |
| `WithEmbeddedAPIPort` | `WithEmbeddedAPIPort(port int)` | WithEmbeddedAPIPort 覆盖嵌入式 API 服务器监听的端口。 |
| `WithEmbeddedDatabaseURL` | `WithEmbeddedDatabaseURL(url string)` | WithEmbeddedDatabaseURL 让嵌入式模式指向已有的 Postgres，而非内置实例。 |
| `WithEmbeddedGRPCPort` | `WithEmbeddedGRPCPort(port int)` | WithEmbeddedGRPCPort 覆盖嵌入式引擎 gRPC 服务器监听的端口。 |
| `WithEmbeddedLogLevel` | `WithEmbeddedLogLevel(level string)` | WithEmbeddedLogLevel 设置嵌入式引擎的日志级别。 |
| `WithEmbeddedRabbitMQ` | `WithEmbeddedRabbitMQ(url string)` | WithEmbeddedRabbitMQ 让引擎的消息队列指向一个 RabbitMQ 实例。 |
| `WithoutEmbeddedAPI` | `WithoutEmbeddedAPI()` | WithoutEmbeddedAPI 禁用嵌入式 API 服务器。 |
| `WithoutEmbeddedMigrations` | `WithoutEmbeddedMigrations()` | WithoutEmbeddedMigrations 禁用引擎启动时的数据库迁移。 |

## EmbeddedConfig

EmbeddedConfig 用于配置由 WithEmbedded 启动的嵌入式引擎。WithEmbedded\* 系列选项会设置这些字段。

字段：

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| `GRPCPort` | `*int` | GRPCPort 覆盖嵌入式引擎 gRPC 服务器监听的端口。 |
| `APIPort` | `*int` | APIPort 覆盖嵌入式 API 服务器监听的端口。 |
| `StartAPI` | `*bool` | StartAPI 控制是否启动嵌入式 API 服务器。默认为 true。 |
| `RunMigrations` | `*bool` | RunMigrations 控制引擎是否在启动时执行数据库迁移。默认为 true。 |
| `RabbitMQURL` | `*string` | RabbitMQURL 让引擎的消息队列指向一个 RabbitMQ 实例。 |
| `LogLevel` | `*string` | LogLevel 设置嵌入式引擎的日志级别。 |
| `DatabaseURL` | `string` | DatabaseURL 让引擎指向已有的 Postgres 数据库，而非内置实例。 |

## EmbeddedBackend

EmbeddedBackend 启动嵌入式引擎并返回一个关闭函数。hatchet-embedded 包提供其实现，并在被导入时通过 RegisterEmbeddedBackend 注册。

## `RegisterEmbeddedBackend`

RegisterEmbeddedBackend 注册启动嵌入式引擎的函数。hatchet-embedded 包会在 init 函数中调用它，因此应用程序只需空白导入该包即可。

```go
func RegisterEmbeddedBackend(b EmbeddedBackend)
```

参数：

名称, 类型

`b`, `EmbeddedBackend`
