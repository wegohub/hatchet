# Logs 客户端

通过 [Hatchet 客户端](<55. client.md>)上的 `client.Logs()` 访问。

## LogsClient

LogsClient 提供与 Hatchet 日志 API 交互的方法。若要在任务内部写入日志，请改用任务上下文的 Log 方法。

### 函数

#### `List`

List 获取给定任务运行的日志行。

```go
func (l *LogsClient) List(ctx context.Context, taskRunId uuid.UUID, opts *rest.V1LogLineListParams) (*rest.V1LogLineList, error)
```

参数：

| 名称 | 类型 |
| --- | --- |
| `ctx` | `context.Context` |
| `taskRunId` | `uuid.UUID` |
| `opts` | `*rest.V1LogLineListParams` |

返回值：

类型

`*rest.V1LogLineList`
`error`
