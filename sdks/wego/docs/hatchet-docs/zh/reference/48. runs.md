### Runs Client

Runs 客户端用于与 Hatchet 中的任务运行和工作流运行交互。

#### 方法：

<a id="branchdurabletask"></a>

##### `branchDurableTask()`

从指定节点分叉（重置）一个持久任务，触发从该点重新执行。

参数：

| 参数 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `taskExternalId` | `string` | `undefined` | 要重置的持久任务的外部 ID。 |
| `nodeId` | `number` | `undefined` | 要从中重放的节点 ID。 |
| `branchId` | `number` | `0` | - |

返回值：

`Promise`\<`AxiosResponse`\<`V1BranchDurableTaskResponse`, `any`, \{
\}\>\>

<a id="cancel"></a>

##### `cancel()`

根据 ID 取消一个任务或工作流运行。

参数：

参数, 类型, 描述

`opts`, `CancelRunOpts`, 取消操作的选项。

返回值：

`Promise`\<`AxiosResponse`\<`V1CancelledTasks`, `any`, \{
\}\>\>

一个 Promise，解析为被取消的运行。

<a id="get"></a>

##### `get()`

根据 ID 获取一个任务或工作流运行。

参数：

参数, 类型, 描述

`run`, `string` \, `WorkflowRunRef`\<`T`\>, 要获取的运行 ID。

返回值：

`Promise`\<`V1WorkflowRunDetails`\>

一个 Promise，解析为该运行。

<a id="get_status"></a>

##### `get_status()`

根据 ID 获取一个任务或工作流运行的状态。

参数：

参数, 类型, 描述

`run`, `string` \, `WorkflowRunRef`\<`T`\>, 要获取状态的运行 ID。

返回值：

`Promise`\<`V1TaskStatus`\>

一个 Promise，解析为该运行的状态。

<a id="getdetails"></a>

##### `getDetails()`

获取运行详情。

参数：

参数, 类型, 描述

`run`, `string` \, `WorkflowRunRef`\<`T`\>, 工作流运行 ID（字符串）或 WorkflowRunRef。

返回值：

`Promise`\<`RunDetail`\>

一个 Promise，解析为包含任务运行状态和输出的 GetRunDetailsResponse。

<a id="gettaskexternalid"></a>

##### `getTaskExternalId()`

解析工作流运行对应的任务外部 ID。对于包含多个任务的运行，
返回第一个任务的外部 ID。

参数：

参数, 类型, 描述

`workflowRunId`, `string`, 要查找的工作流运行 ID。

返回值：

`Promise`\<`string`\>

任务外部 ID。

<a id="list"></a>

##### `list()`

列出当前租户的所有任务运行和工作流运行。

参数：

参数, 类型, 描述

`opts?`, `Partial`\<`ListRunsOpts`\>, 列表操作的选项。

返回值：

`Promise`\<`V1TaskSummaryList`\>

一个 Promise，解析为运行列表。

<a id="replay"></a>

##### `replay()`

根据 ID 重放一个任务或工作流运行。

参数：

参数, 类型, 描述

`opts`, `ReplayRunOpts`, 重放操作的选项。

返回值：

`Promise`\<`AxiosResponse`\<`V1ReplayedTasks`, `any`, \{
\}\>\>

一个 Promise，解析为被重放的运行。

<a id="restoretask"></a>

##### `restoreTask()`

恢复一个已被逐出的持久任务，使其可以继续执行。

参数：

参数, 类型, 描述

`taskExternalId`, `string`, 被逐出任务的外部 ID。

返回值：

`Promise`\<`AxiosResponse`\<`V1RestoreTaskResponse`, `any`, \{
\}\>\>

<a id="subscribetostream"></a>

##### `subscribeToStream()`

根据 ID 订阅一个任务或工作流运行的事件流。

参数：

参数, 类型, 描述

`workflowRunId`, `string`, 要订阅的运行 ID。

返回值：

`AsyncIterableIterator`\<`string`\>

一个 Promise，解析为事件流。
