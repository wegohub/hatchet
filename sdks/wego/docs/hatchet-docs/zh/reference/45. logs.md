### Logs Client

Logs 客户端用于与 Hatchet 的日志 API 交互。

#### 方法：

<a id="list"></a>

##### `list()`

列出指定任务运行的日志。

参数：

参数, 类型, 描述

`taskRunId`, `string`, 要列出日志的任务运行 ID。
`opts?`, [`ListLogsOpts`](#listlogsopts), 列表操作的过滤选项。

返回值：

`Promise`\<`V1LogLineList`\>

一个 Promise，解析为日志列表。

## Type Aliases

<a id="listlogsopts"></a>

### ListLogsOpts

```ts
type ListLogsOpts = object;
```

列出日志操作的选项。

属性

| 属性 | 类型 | 描述 |
| --- | --- | --- |
| <a id="attempt"></a> `attempt?` | `number` | 按尝试次数过滤日志。 |
| <a id="levels"></a> `levels?` | `V1LogLineLevel`[] | 按日志级别过滤日志。 |
| <a id="limit"></a> `limit?` | `number` | 要返回的最大日志行数。 |
| <a id="orderbydirection"></a> `orderByDirection?` | `V1LogLineOrderByDirection` | 日志的排序方向。 |
| <a id="search"></a> `search?` | `string` | 按搜索字符串过滤日志。 |
| <a id="since"></a> `since?` | `Date` | 仅返回此日期之后的日志。 |
| <a id="until"></a> `until?` | `Date` | 仅返回此日期之前的日志。 |
