### Ratelimits Client

Rate limits 客户端是 Hatchet gRPC API 的封装，让你更方便地在 Hatchet 中使用速率限制。

#### 方法：

<a id="list"></a>

##### `list()`

列出当前租户的所有速率限制。

参数：

参数, 类型, 描述

`opts`, \, \{ `limit?`: `number`; `offset?`: `number`; `orderByDirection?`: `RateLimitOrderByDirection`; `orderByField?`: `RateLimitOrderByField`; `search?`: `string`; \} \, `undefined`, 列表操作的选项。

返回值：

`Promise`\<`RateLimitList`\>

一个 Promise，解析为速率限制列表。

<a id="upsert"></a>

##### `upsert()`

为当前租户 upsert（插入或更新）一个速率限制。

参数：

参数, 类型, 描述

`opts`, `CreateRateLimitOpts`, upsert 操作的选项。

返回值：

`Promise`\<`string`\>

一个 Promise，解析为被 upsert 的速率限制的 key。
