# Workflows Client

继承自：`BaseRestClient`

workflows 客户端用于在 Hatchet 中以编程方式管理工作流。

注意，workflow 是声明，而_不是_具体的运行。如果你要查找的是运行（run），请改用 `RunsClient`。

方法：

| 名称 | 描述 |
| --- | --- |
| `aio_delete` | 永久删除一个工作流。 |
| `aio_get` | 按 ID 获取工作流。 |
| `aio_get_version` | 按工作流 ID 和可选的版本号获取工作流版本。 |
| `aio_list` | 列出由客户端配置确定的租户中符合可选过滤条件的所有工作流。 |
| `aio_pause` | 暂停一个工作流。 |
| `aio_unpause` | 恢复（取消暂停）一个工作流。 |
| `delete` | 永久删除一个工作流。 |
| `get` | 按 ID 获取工作流。 |
| `get_version` | 按工作流 ID 和可选的版本号获取工作流版本。 |
| `list` | 列出由客户端配置确定的租户中符合可选过滤条件的所有工作流。 |
| `pause` | 暂停一个工作流。 |
| `unpause` | 恢复（取消暂停）一个工作流。 |

### Functions

#### `aio_delete`

永久删除一个工作流。

**危险操作：这将删除该工作流及其全部数据**

参数：

名称, 类型, 描述, 默认值

`workflow_id`, `str`, 要删除的工作流 ID。, _必填_

返回：

类型, 描述

`None`, None

#### `aio_get`

按 ID 获取工作流。

参数：

名称, 类型, 描述, 默认值

`workflow_id`, `str`, 要获取的工作流 ID。, _必填_

返回：

类型, 描述

`Workflow`, 该工作流。

#### `aio_get_version`

按工作流 ID 和可选的版本号获取工作流版本。

参数：

名称, 类型, 描述, 默认值

`workflow_id`, `str`, 要获取其版本的工作流 ID。, _必填_
`version`, `str \, None`, 要获取的工作流版本。如果为 None，则返回最新版本。, `None`

返回：

类型, 描述

`WorkflowVersion`, 工作流版本。

#### `aio_list`

列出由客户端配置确定的租户中符合可选过滤条件的所有工作流。

参数：

| 名称 | 类型 | 描述 | 默认值 |
| --- | --- | --- | --- |
| `workflow_name` | `str \| None` | 用于过滤的工作流名称。 | `None` |
| `limit` | `int \| None` | 返回的最大条目数。 | `None` |
| `offset` | `int \| None` | 列表的起始偏移量。 | `None` |

返回：

类型, 描述

`WorkflowList`, 工作流列表。

#### `aio_pause`

暂停一个工作流。

参数：

| 名称 | 类型 | 描述 | 默认值 |
| --- | --- | --- | --- |
| `workflow_id` | `str` | 要暂停的工作流 ID。 | _必填_ |
| `queue_ttl` | `timedelta` | 工作流暂停期间排队运行的 TTL，超过后这些运行将被丢弃。 | _必填_ |
| `paused_workflow_cron_run_queue_behavior` | `Literal['DROP', 'QUEUE']` | 工作流暂停期间触发的 cron 运行的处理行为。 | `'QUEUE'` |
| `paused_workflow_scheduled_run_queue_behavior` | `Literal['DROP', 'QUEUE']` | 工作流暂停期间触发的计划运行的处理行为。 | `'QUEUE'` |

返回：

类型, 描述

`Workflow`, 更新后的工作流。

#### `aio_unpause`

恢复（取消暂停）一个工作流。

参数：

名称, 类型, 描述, 默认值

`workflow_id`, `str`, 要恢复的工作流 ID。, _必填_

返回：

类型, 描述
