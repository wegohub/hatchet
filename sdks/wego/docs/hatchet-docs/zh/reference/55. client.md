# Hatchet Go SDK 参考

这是 Go SDK 参考文档，介绍了与 Hatchet 资源交互的可用方法。请查看[用户指南](<../v1/01. get-started（入门）/01. index.md>)了解如何运行你的首批任务。完整的自动生成 API 文档请参阅 [pkg.go.dev 上的 Go 包文档](https://pkg.go.dev/github.com/hatchet-dev/hatchet/sdks/go)。

默认情况下，客户端从 `HATCHET_CLIENT_*` 环境变量读取配置（token、host、TLS 设置等）。可以通过客户端选项覆盖配置，例如 `hatchet.WithToken`、`hatchet.WithHostPort` 和 `hatchet.WithNamespace`。

## Client

Client 提供与 Hatchet 交互的主要接口。

方法：

| 名称 | 描述 |
| --- | --- |
| `Close` | Close 用于关闭客户端。 |
| `Events` | Events 返回一个用于发送和管理事件的客户端。 |
| `GetEngineVersion` | GetEngineVersion 从服务器获取引擎版本。 |
| `NewStandaloneBatchTask` | NewStandaloneBatchTask 创建一个可以独立触发的独立批处理任务。 |
| `NewStandaloneDurableTask` | NewStandaloneDurableTask 创建一个可以独立触发的独立持久化任务。 |
| `NewStandaloneTask` | NewStandaloneTask 创建一个可以独立触发的独立任务。 |
| `NewWorker` | NewWorker 创建一个可以执行工作流的 worker。 |
| `NewWorkflow` | NewWorkflow 创建一个新的工作流定义。 |
| `Run` | Run 使用给定输入执行工作流并等待完成。 |
| `RunMany` | RunMany 使用不同输入执行多个工作流实例。 |
| `RunNoWait` | RunNoWait 使用给定输入执行工作流，但不等待完成。 |

### 函数

```go
func NewClient(opts ...ClientOpt) (*Client, error)
```

参数：

名称, 类型

`opts`, `...ClientOpt`

返回值：

类型

`*Client`
`error`

#### `Close`

Close 用于关闭客户端。除非客户端运行在嵌入式模式下，否则它是一个空操作；在嵌入式模式下，它会关闭进程内引擎。

```go
func (c *Client) Close(ctx context.Context) error
```

参数：

名称, 类型

`ctx`, `context.Context`

返回值：

类型

`error`

#### `NewStandaloneBatchTask`

NewStandaloneBatchTask 创建一个可以独立触发的独立批处理任务。这是一个只包含一个批处理任务的专用工作流，让你无需工作流样板代码即可创建简单的单任务工作流。

函数参数必须具有以下签名：

```go
func(ctx hatchet.Context, input map[string]T) (map[string]R, error)
```

或者，当 batch.BroadcastOutput 为 true 时：

```go
func(ctx hatchet.Context, input map[string]T) (R, error)
```

函数签名会在运行时通过反射进行校验。

选项可以是 WorkflowOption 和 TaskOption 的任意组合。

预览：批处理任务目前处于 beta 阶段，在未来版本中可能发生变化。

```go
func (c *Client) NewStandaloneBatchTask(name string, fn any, batch BatchConfig, options ...StandaloneTaskOption) *StandaloneTask
```

参数：

| 名称 | 类型 |
| --- | --- |
| `name` | `string` |
| `fn` | `any` |
| `batch` | `BatchConfig` |
| `options` | `...StandaloneTaskOption` |

返回值：

类型

`*StandaloneTask`

#### `NewStandaloneDurableTask`

## Worker

Worker 表示一个可以执行工作流的 worker。

方法：

| 名称 | 描述 |
| --- | --- |
| `Start` | 启动 worker 实例并返回一个清理函数。 |
| `StartBlocking` | StartBlocking 启动 worker 并阻塞直到其运行完成。 |
| `Use` | Use 在 worker 上注册中间件函数。 |

### 函数

#### `Start`

启动 worker 实例并返回一个清理函数。

```go
func (w *Worker) Start() (func() error, error)
```

返回值：

类型

`func() error`
`error`

#### `StartBlocking`

StartBlocking 启动 worker 并阻塞直到其运行完成。这是一个针对常见使用模式的便捷方法。

```go
func (w *Worker) StartBlocking(ctx context.Context) error
```

参数：

名称, 类型

`ctx`, `context.Context`

返回值：

类型

`error`

#### `Use`

Use 在 worker 上注册中间件函数。中间件函数会按顺序在每次 step run 执行时被调用。

```go
func (w *Worker) Use(mws ...MiddlewareFunc)
```

参数：

名称, 类型

`mws`, `...MiddlewareFunc`

## Worker 选项

`Client.NewWorker` 的选项：

| 名称 | 签名 | 描述 |
| --- | --- | --- |
| `WithDurableSlots` | `WithDurableSlots(durableSlots int)` | WithDurableSlots 设置持久化任务的最大并发运行数。 |
| `WithLabels` | `WithLabels(labels map[string]any)` | WithLabels 为 worker 分配用于任务路由的标签。 |
| `WithLogger` | `WithLogger(logger *zerolog.Logger)` | WithLogger 为 worker 设置自定义日志记录器。 |
| `WithPanicHandler` | `WithPanicHandler(panicHandler func(ctx Context, recovered any))` | WithPanicHandler 为 worker 设置自定义 panic 处理器。 |
| `WithSlots` | `WithSlots(slots int)` | WithSlots 设置工作流的最大并发运行数。 |
| `WithWorkflows` | `WithWorkflows(workflows ...WorkflowBase)` | WithWorkflows 向 worker 注册工作流和独立任务。 |
