# Profiles

Hatchet CLI 支持使用命名 profile 管理多个 Hatchet 实例和租户。此功能让你可以轻松地在开发、预发布和生产等不同环境之间切换。

## 创建 Profile

你可以使用 `hatchet profile add` 命令创建新的 profile。你需要为该 profile 提供一个 Hatchet API token。

```sh
hatchet profile add
```

此命令会提示你先输入 API token，再输入 profile 名称。你也可以通过参数直接提供：

```sh
hatchet profile add --name [name] --token [token]
```

## 列出 Profiles

你可以使用 `hatchet profile list` 命令列出所有已配置的 profile：

```sh
hatchet profile list
```

这会显示所有已配置的 profile，如果设置了默认 profile，则会用 `(default)` 标记。

## 设置默认 Profile

你可以使用 `hatchet profile set-default` 命令将某个 profile 设为默认。未通过 `--profile` 参数指定 profile 时，会自动使用默认 profile。

如果未配置默认 profile，`hatchet server start` 会将其创建的 profile 设为默认。接受 `--profile` 参数的命令也会直接使用唯一已配置的 profile，而不会提示。

```sh
# 交互式设置默认 profile（提示选择）
hatchet profile set-default

# 将特定 profile 设为默认
hatchet profile set-default --name [name]
```

设置默认 profile 后，你可以直接运行命令而无需指定 `--profile` 参数：

```sh
# 使用默认 profile
hatchet worker dev
```

取消默认 profile：

```sh
hatchet profile unset-default
```

## 使用 Profile

要让 Hatchet CLI 命令使用特定 profile，可以通过 `--profile` 参数指定 profile 名称。如果已设置默认 profile，这会覆盖默认值。

```sh
hatchet worker dev --profile [name]
```

> **提示：** 在没有终端的会话中（例如 CI），命令无法提示选择
>   profile，如果尝试这样做会报错失败。请先传递 `--profile` 或设置默认
>   profile。

## 更新 Profile

你可以使用 `hatchet profile update` 命令更新现有 profile。这允许你更改与 profile 关联的 API token。

```sh
hatchet profile update
```

## 删除 Profile

你可以使用 `hatchet profile remove` 命令删除一个 profile：

```sh
hatchet profile remove
```

如果你删除的是被设为默认的 profile，默认 profile 设置会被自动清除。
