### Workers Client

Workers 客户端用于在 Hatchet 中以编程方式管理 worker。

#### 方法：

<a id="get"></a>

##### `get()`

根据 ID 获取一个 worker。

参数：

参数, 类型, 描述

`workerId`, `string`, 要获取的 worker ID。

返回值：

`Promise`\<`Worker`\>

一个 Promise，解析为该 worker。

<a id="ispaused"></a>

##### `isPaused()`

检查一个 worker 是否已暂停。

参数：

参数, 类型, 描述

`workerId`, `string`, 要检查的 worker ID。

返回值：

`Promise`\<`boolean`\>

一个 Promise，如果 worker 已暂停则解析为 true，否则为 false。

<a id="list"></a>

##### `list()`

列出租户中的所有 worker。

返回值：

`Promise`\<`WorkerList`\>

一个 Promise，解析为 worker 列表。

<a id="pause"></a>

##### `pause()`

暂停一个 worker。

参数：

参数, 类型, 描述

`workerId`, `string`, 要暂停的 worker ID。

返回值：

`Promise`\<`Worker`\>

一个 Promise，解析为被暂停的 worker。

<a id="unpause"></a>

##### `unpause()`

恢复（取消暂停）一个 worker。

参数：

参数, 类型, 描述

`workerId`, `string`, 要恢复的 worker ID。

返回值：

`Promise`\<`Worker`\>

一个 Promise，解析为被恢复的 worker。
