# Runnables

Hatchet TypeScript SDK 中的 `Runnables` 是可以运行的对象，即任务和工作流。你会遇到的两种主要 runnable 类型是：

- `WorkflowDeclaration`，由 `hatchet.workflow(...)` 返回，允许你定义任务并调用 `run()`、`schedule()`、`cron()` 等。
- `TaskWorkflowDeclaration`，由 `hatchet.task(...)` 返回，是一个独立的单个任务，提供与工作流相同的执行辅助方法。

<a id="taskworkflowdeclaration"></a>

### TaskWorkflowDeclaration

一个可以像工作流一样运行的独立任务声明。

`TaskWorkflowDeclaration` 由 `hatchet.task(...)` 返回，封装单个任务定义，
同时提供与工作流相同的执行辅助方法，例如 `run()`、`runNoWait()`、
`schedule()` 和 `cron()`（继承自 `BaseWorkflowDeclaration`）。

示例：

```typescript
const greet = hatchet.task<{ name: string }, { message: string }>({
  name: "greet",
  fn: async (input) => ({ message: `Hello, ${input.name}!` }),
});

await greet.run({ name: "World" });
const ref = await greet.runNoWait({ name: "World" });
```

#### 模板

**MiddlewareBefore**

由前置中间件钩子添加到任务 fn 输入中的额外字段。

##### `cron()`

为该任务创建一个 cron 计划。

参数

| Parameter | Type | Description |
| --- | --- | --- |
| `name` | `string` | cron 计划的名称。 |

<a id="workflowdeclaration"></a>

### WorkflowDeclaration

一个 Hatchet 工作流，允许你定义任务并对工作流执行操作。

Hatchet 中的工作流表示可以被触发、调度或按 cron 计划运行的协调工作单元。
每个工作流可以包含多个任务，这些任务可以按依赖关系（DAG）组织，并可自定义
重试行为、超时、并发控制等。

示例：

```typescript
import { hatchet } from "./hatchet-client";

type MyInput = { name: string };

const workflow = hatchet.workflow({
  name: "my-workflow",
});

workflow.task({
  name: "greet",
  fn: async (input) => {
    return { message: `Hello, ${input.name}!` };
  },
});

// Run the workflow
await workflow.run({ name: "World" });
```

工作流支持多种执行模式，包括：

- 使用 `run()` 和 `runNoWait()` 的一次性执行
- 使用 `schedule()` 的定时执行
- 使用 `cron()` 的基于 cron 的周期性执行
- 向 `run()` 和 `runNoWait()` 传入数组输入进行的批量执行
- 使用 `runMany()` 和 `runManyNoWait()` 的每次运行级批量执行选项

工作流内的任务可以通过 `workflow.task()` 或 `workflow.durableTask()` 定义，
并组织成复杂的依赖模式。

#### 方法

<a id="batchtask"></a>

##### `batchTask()`

向工作流添加一个批处理任务。批处理任务会缓冲并发运行，直到 Hatchet
刷新该批次（达到大小上限或刷新间隔），然后以所有缓冲输入为参数调用一次处理函数，
输入以每个运行的任务运行外部 ID 为键。处理函数必须返回一个将每个 ID 映射到其输出的
Record，或者设置 `batch.broadcastOutput` 以向所有调用方返回相同结果。
批处理任务的 retries 始终被强制为 0。

预览：批处理任务目前处于 beta 阶段，在未来版本中可能发生变化。

参数

Parameter, Type, Description

`options`, `object` & `Omit`\<[`CreateBatchTaskWorkflowOpts`](#createbatchtaskworkflowopts)\<`TI`, `TO`\>, `"name"` \, `"batch"` \, `"fn"`\> & `object`, 批处理任务配置选项。

返回值

`CreateWorkflowTaskOpts`\<`TI`, `TO`\>

被添加的任务选项。

## 类型别名

<a id="createbatchtaskworkflowopts"></a>

### CreateBatchTaskWorkflowOpts

```ts
type CreateBatchTaskWorkflowOpts = CreateBaseWorkflowOpts &
  CreateBaseTaskOpts> &
  object;
```

创建批处理任务工作流的选项。批处理任务会缓冲并发运行，
并将它们作为单次执行一起分发；fn 接收一个 Record，
以每个缓冲运行的任务运行外部 ID 为键。

预览：批处理任务目前处于 beta 阶段，在未来版本中可能发生变化。

Name, Type

`batch`, `BatchTaskConfig`
