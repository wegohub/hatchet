# 使用 Hatchet TUI

Hatchet CLI 内置了终端用户界面（TUI），让你可以直接从终端与你的 Hatchet 部署交互。TUI 为任务、工作流、worker 等提供实时可观测性：

```sh
hatchet tui
```

# 功能

> **提示：** 在 TUI 中按 `h` 键可以查看帮助文档。它会显示可用命令
>   及其说明的列表。
