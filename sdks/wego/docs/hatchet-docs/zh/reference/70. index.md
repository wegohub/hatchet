# Ruby SDK

## 核心页面

- [Client](<71. client.md>)：Hatchet 主客户端、其配置以及各功能客户端访问器
- [Context](<72. context.md>)：运行时传递给任务的上下文对象
- [Runnables](<73. runnables.md>)：任务和工作流——注册到 worker 上并运行的对象
