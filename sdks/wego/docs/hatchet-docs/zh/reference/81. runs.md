# Runs Client

用于与 Hatchet 工作流运行管理 API 交互的 runs 客户端。

此类为在 Hatchet 系统中创建和管理工作流运行提供了高层接口。它以更便捷的 Ruby 接口包装了自动生成的 REST API 客户端。

```ruby
response = hatchet.runs.create(
  name: "my-workflow",
  input: { key: "value" },
  additional_metadata: { source: "api" }
)
```

它在主客户端上以 `hatchet.runs` 的形式提供。

方法：

| Name | Description |
| --- | --- |
| `get_task_run` | 按任务运行 ID 获取任务运行详情。 |
| `get` | 按 ID 获取工作流运行。 |
| `get_details` | 按工作流运行 ID 获取完整的工作流运行详情。 |
| `get_status` | 按工作流运行 ID 获取工作流运行状态。 |
| `list_with_pagination` | 按一组过滤条件列出任务运行，并按天分页。 |
| `list` | 按一组过滤条件列出任务运行。 |
| `create` | 在 Hatchet 系统中创建一个新的工作流运行。 |
| `replay` | 重放一个任务或工作流运行。 |
| `bulk_replay` | 按一组过滤条件批量重放任务或工作流运行。 |
| `cancel` | 取消一个任务或工作流运行。 |
| `bulk_cancel` | 按一组过滤条件批量取消任务或工作流运行。 |
| `get_result` | 按外部 ID 获取工作流运行的结果。 |
| `bulk_replay_by_filters_with_pagination` | 分块重放符合指定过滤条件的运行。 |
| `bulk_cancel_by_filters_with_pagination` | 分块取消符合指定过滤条件的运行。 |
| `get_run_ref` | 获取工作流运行的引用。 |
| `poll` | 以可配置的间隔和超时轮询工作流运行的完成情况。 |
| `subscribe_to_stream` | 订阅工作流运行的流事件。 |

#### `create`

在 Hatchet 系统中创建一个新的工作流运行。

此方法使用提供的输入数据为指定工作流触发一次新的工作流或任务运行。工作流运行将按照工作流定义排队到可用的 worker 上。

重要：如果可能，优先使用 `Workflow.run`（及类似方法）来触发工作流。此方法仅作为兜底手段。

```ruby
response = hatchet.runs.create(
  name: "simple-workflow",
  input: { user_id: 123, action: "process_data" },
  additional_metadata: { source: "api", priority: "high" }
)
```

参数：

| Name | Type | Description | Default |
| --- | --- | --- | --- |
| `name` | `String` | 要触发的工作流的名称。 | _required_ |
| `input` | `Hash` | 工作流运行的输入数据。 | _required_ |
| `additional_metadata` | `Hash \| nil` | 与工作流运行关联的额外元数据。 | `nil` |
| `priority` | `Integer \| nil` | 工作流运行的优先级。 | `nil` |

返回：

Type, Description

`HatchetSdkRest::V1WorkflowRunDetails`, 已触发的工作流运行的详情。

抛出：

Type, Description

`ArgumentError`, 如果 workflow_name 或 input 参数为 nil 或无效。
`Hatchet::Error`, 如果 API 请求失败或返回错误。

#### `poll`

以可配置的间隔和超时轮询工作流运行的完成情况。

此方法反复调用 `get`，直到工作流运行到达终态（succeeded、failed 或 cancelled）或超时。

```ruby
result = hatchet.runs.poll("workflow-run-123")
```

```ruby
result = hatchet.runs.poll("workflow-run-123", interval: 2.0, timeout: 30.0)
```

参数：

| Name | Type | Description | Default |
| --- | --- | --- | --- |
| `workflow_run_id` | `String` | 要轮询的工作流运行 ID。 | _required_ |
| `interval` | `Numeric` | 轮询间隔，单位为秒（默认：1.0） | `1.0` |
| `timeout` | `Numeric \| nil` | 最长轮询时间，单位为秒（默认：无超时） | `nil` |

返回：

Type, Description

`HatchetSdkRest::V1WorkflowRunDetails`, 最终的工作流运行详情。

抛出：

Type, Description

`Timeout::Error`, 如果在完成前达到超时。
`Hatchet::Error`, 如果 API 请求失败或返回错误。

参数：

Name, Type, Description, Default

`workflow_run_id`, `String`, 要订阅的工作流运行 ID。, _required_

抛出：

Type, Description

`Hatchet::Error`, 如果订阅失败。
