# Workers Client

继承自：`BaseRestClient`

workers 客户端用于在 Hatchet 中以编程方式管理 worker。

方法：

| 名称 | 描述 |
| --- | --- |
| `aio_get` | 按 ID 获取 worker。 |
| `aio_list` | 列出由客户端配置确定的租户中的所有 worker。 |
| `aio_pause` | 按 ID 暂停 worker。 |
| `aio_unpause` | 按 ID 恢复（取消暂停）worker。 |
| `aio_update` | 按 ID 更新 worker。 |
| `get` | 按 ID 获取 worker。 |
| `list` | 列出由客户端配置确定的租户中的所有 worker。 |
| `pause` | 按 ID 暂停 worker。 |
| `unpause` | 按 ID 恢复（取消暂停）worker。 |
| `update` | 按 ID 更新 worker。 |

### Functions

#### `aio_get`

按 ID 获取 worker。

参数：

名称, 类型, 描述, 默认值

`worker_id`, `str`, 要获取的 worker ID。, _必填_

返回：

类型, 描述

`Worker`, 该 worker。

#### `aio_list`

列出由客户端配置确定的租户中的所有 worker。

返回：

类型, 描述

`WorkerList`, worker 列表。

#### `aio_pause`

按 ID 暂停 worker。

参数：

名称, 类型, 描述, 默认值

`worker_id`, `str`, 要暂停的 worker ID。, _必填_

返回：

类型, 描述

`Worker`, 已暂停的 worker。

#### `aio_unpause`

按 ID 恢复（取消暂停）worker。

参数：

名称, 类型, 描述, 默认值

`worker_id`, `str`, 要恢复的 worker ID。, _必填_

返回：

类型, 描述

`Worker`, 已恢复的 worker。

#### `aio_update`

按 ID 更新 worker。

参数：

名称, 类型, 描述, 默认值

`worker_id`, `str`, 要更新的 worker ID。, _必填_
`opts`, `UpdateWorkerRequest`, 更新选项。, _必填_

返回：

类型, 描述

`Worker`, 更新后的 worker。
