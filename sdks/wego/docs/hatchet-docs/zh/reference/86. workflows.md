# Workflows Client

用于管理 Hatchet 中工作流定义的 workflows 客户端。

注意，工作流是声明本身，而_不是_单次运行。如果你要查找运行记录，请改用 Runs 客户端。

```ruby
workflow = hatchet.workflows.get("workflow-id")
```

```ruby
workflows = hatchet.workflows.list(workflow_name: "my-workflow", limit: 10)
```

它在主客户端上以 `hatchet.workflows` 的形式提供。

方法：

| Name | Description |
| --- | --- |
| `get` | 按 ID 获取工作流。 |
| `list` | 列出租户中符合可选过滤条件的所有工作流。 |
| `get_version` | 按工作流 ID 和可选的版本号获取工作流版本。 |
| `delete` | 永久删除一个工作流。 |

### Functions

#### `get`

按 ID 获取工作流。

```ruby
workflow = hatchet.workflows.get("workflow-123")
```

参数：

Name, Type, Description, Default

`workflow_id`, `String`, 要获取的工作流的 ID。, _required_

返回：

Type, Description

`Object`, 工作流详细信息。

抛出：

Type, Description

`HatchetSdkRest::ApiError`, 如果 API 请求失败。

#### `list`

列出租户中符合可选过滤条件的所有工作流。

```ruby
workflows = hatchet.workflows.list(workflow_name: "my-workflow", limit: 10, offset: 0)
```

参数：

| Name | Type | Description | Default |
| --- | --- | --- | --- |
| `workflow_name` | `String \| nil` | 用于过滤的工作流名称（会应用命名空间） | `nil` |
| `limit` | `Integer \| nil` | 返回的最大条目数。 | `nil` |
| `offset` | `Integer \| nil` | 列表的起始偏移量。 | `nil` |

返回：

Type, Description

`Object`, 工作流列表。

抛出：

Type, Description

`HatchetSdkRest::ApiError`, 如果 API 请求失败。

#### `get_version`

按工作流 ID 和可选的版本号获取工作流版本。

```ruby
version = hatchet.workflows.get_version("workflow-123", version: "v2")
```

参数：

Name, Type, Description, Default

`workflow_id`, `String`, 要获取版本的工作流的 ID。, _required_
`version`, `String \, nil`, 要获取的版本。如果为 nil，则返回最新版本。, `nil`

返回：

Type, Description

`Object`, 工作流版本。

抛出：

Type, Description

`HatchetSdkRest::ApiError`, 如果 API 请求失败。

#### `delete`

永久删除一个工作流。

**危险操作：这会删除工作流及其所有数据**。

```ruby
hatchet.workflows.delete("workflow-123")
```

参数：

Name, Type, Description, Default

`workflow_id`, `String`, 要删除的工作流的 ID。, _required_

抛出：

Type, Description

`HatchetSdkRest::ApiError`, 如果 API 请求失败。
