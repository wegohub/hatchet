# Scheduled Client

继承自：`BaseRestClient`

scheduled 客户端用于在 Hatchet 中管理计划（scheduled）工作流。

方法：

| 名称 | 描述 |
| --- | --- |
| `aio_bulk_delete` | 批量删除计划工作流运行。 |
| `aio_bulk_update` | 批量重新安排计划工作流运行的时间。 |
| `aio_create` | 创建一个新的计划工作流运行。 |
| `aio_delete` | 按 ID 删除计划工作流运行。 |
| `aio_get` | 按计划运行触发器 ID 获取特定的计划工作流。 |
| `aio_list` | 根据提供的过滤条件获取计划工作流列表。 |
| `aio_update` | 按 ID 重新安排计划工作流运行的时间。 |
| `bulk_delete` | 批量删除计划工作流运行。 |
| `bulk_update` | 批量重新安排计划工作流运行的时间。 |
| `create` | 创建一个新的计划工作流运行。 |
| `delete` | 按 ID 删除计划工作流运行。 |
| `get` | 按计划运行触发器 ID 获取特定的计划工作流。 |
| `list` | 根据提供的过滤条件获取计划工作流列表。 |
| `update` | 按 ID 重新安排计划工作流运行的时间。 |

### Functions

#### `aio_bulk_delete`

批量删除计划工作流运行。

参数：

| 名称 | 类型 | 描述 | 默认值 |
| --- | --- | --- | --- |
| `scheduled_ids` | `list[str] \| None` | 要删除的计划工作流运行 ID 的显式列表。 | `None` |
| `workflow_id` | `str \| None` | 按工作流 ID 过滤。 | `None` |
| `parent_workflow_run_id` | `str \| None` | 按父工作流运行 ID 过滤。 | `None` |
| `parent_step_run_id` | `str \| None` | 按父 step run ID 过滤。 | `None` |
| `statuses` | `list[ScheduledRunStatus] \| None` | 按计划运行状态过滤。 | `None` |
| `additional_metadata` | `JSONSerializableMapping \| None` | 按附加元数据键值对过滤。 | `None` |

返回：

类型, 描述

`ScheduledWorkflowsBulkDeleteResponse`, 批量删除响应，包含已删除的 ID 和逐条错误信息。

异常：

类型, 描述

`ValueError`, 既未提供 `scheduled_ids` 也未提供任何过滤字段时抛出。

#### `aio_bulk_update`

批量重新安排计划工作流运行的时间。

参数详情见 `bulk_update`。

#### `aio_create`

创建一个新的计划工作流运行。

重要提示：如果可以，建议优先使用 `Workflow.run`（及类似方法）来触发工作流。此方法定位为逃生通道（escape hatch）。更多细节见[文档](<17. runnables.md#workflow>)。

参数：

| 名称 | 类型 | 描述 | 默认值 |
| --- | --- | --- | --- |
| `workflow_name` | `str` | 要计划的工作流名称。 | _必填_ |
| `trigger_at` | `datetime` | 运行应被触发的日期时间。 | _必填_ |
| `input` | `JSONSerializableMapping` | 计划工作流的输入数据。 | _必填_ |
| `additional_metadata` | `JSONSerializableMapping` | 以键值对形式与未来运行关联的附加元数据。 | _必填_ |

返回：

类型, 描述

`ScheduledWorkflows`, 创建的计划工作流实例。

#### `aio_delete`

按 ID 删除计划工作流运行。

参数：

名称, 类型, 描述, 默认值

`scheduled_id`, `str`, 要删除的计划工作流运行 ID。, _必填_

返回：

类型, 描述

`None`, None

#### `aio_get`

按计划运行触发器 ID 获取特定的计划工作流。

参数：

名称, 类型, 描述, 默认值

`scheduled_id`, `str`, 要获取的计划工作流触发器 ID。, _必填_

返回：

类型, 描述

`ScheduledWorkflows`, 所请求的计划工作流实例。

#### `aio_list`

根据提供的过滤条件获取计划工作流列表。

参数：

| 名称 | 类型 | 描述 | 默认值 |
| --- | --- | --- | --- |
| `offset` | `int \| None` | 分页使用的偏移量。 | `None` |
| `limit` | `int \| None` | 返回计划工作流的最大数量。 | `None` |
| `workflow_id` | `str \| None` | 用于过滤的工作流 ID。 | `None` |
| `parent_workflow_run_id` | `str \| None` | 用于过滤的父工作流运行 ID。 | `None` |
| `statuses` | `list[ScheduledRunStatus] \| None` | 用于过滤的状态列表。 | `None` |
| `additional_metadata` | `JSONSerializableMapping \| None` | 用于过滤的附加元数据。 | `None` |
| `order_by_field` | `ScheduledWorkflowsOrderByField \| None` | 结果排序所依据的字段。 | `None` |
| `order_by_direction` | `WorkflowRunOrderByDirection \| None` | 结果排序方向。 | `None` |

返回：

类型, 描述

`ScheduledWorkflowsList`, 符合所提供过滤条件的计划工作流列表。

#### `aio_update`

按 ID 重新安排计划工作流运行的时间。

参数：

名称, 类型, 描述, 默认值

`scheduled_id`, `str`, 要重新安排的计划工作流运行 ID。, _必填_
`trigger_at`, `datetime`, 运行应被触发的日期时间。, _必填_

返回：

类型, 描述

`ScheduledWorkflows`, 更新后的计划工作流实例。

#### `bulk_delete`

批量删除计划工作流运行。

请提供以下二者之一：

- `scheduled_ids`（计划运行 ID 的显式列表），或
- 一个或多个过滤字段（`workflow_id`、`parent_workflow_run_id`、`parent_step_run_id`、
  `statuses`、`additional_metadata`）

参数：

| 名称 | 类型 | 描述 | 默认值 |
| --- | --- | --- | --- |
| `scheduled_ids` | `list[str] \| None` | 要删除的计划工作流运行 ID 的显式列表。 | `None` |
| `workflow_id` | `str \| None` | 按工作流 ID 过滤。 | `None` |
| `parent_workflow_run_id` | `str \| None` | 按父工作流运行 ID 过滤。 | `None` |
| `parent_step_run_id` | `str \| None` | 按父 step run ID 过滤。 | `None` |
| `statuses` | `list[ScheduledRunStatus] \| None` | 按计划运行状态过滤。 | `None` |
| `additional_metadata` | `JSONSerializableMapping \| None` | 按附加元数据键值对过滤。 | `None` |

返回：

类型, 描述

`ScheduledWorkflowsBulkDeleteResponse`, 批量删除响应，包含已删除的 ID 和逐条错误信息。

异常：

类型, 描述

`ValueError`, 既未提供 `scheduled_ids` 也未提供任何过滤字段时抛出。

#### `bulk_update`

批量重新安排计划工作流运行的时间。

参数：

名称, 类型, 描述, 默认值

`updates`, `list[ScheduledWorkflowsBulkUpdateItem] \, list[tuple[str, datetime]]`, 二选一：- `(scheduled_id, trigger_at)` 元组的列表，或 - `ScheduledWorkflowsBulkUpdateItem` 对象的列表, _必填_

返回：

类型, 描述

`ScheduledWorkflowsBulkUpdateResponse`, 批量更新响应，包含已更新的 ID 和逐条错误信息。

#### `update`

按 ID 重新安排计划工作流运行的时间。

注意：如果计划运行已被触发，或它是通过代码定义（而非通过 API）创建的，服务器可能会拒绝重新安排。
