# Workflows 客户端

通过 [Hatchet 客户端](<55. client.md>)上的 `client.Workflows()` 访问。

## WorkflowsClient

WorkflowsClient 提供与工作流交互的方法

方法：

| 名称 | 描述 |
| --- | --- |
| `Delete` | Delete 根据 ID 或名称删除工作流。 |
| `Get` | Get 根据 ID 或名称获取工作流。 |
| `GetId` | GetId 根据名称获取工作流。 |
| `List` | List 获取租户的所有工作流，支持可选的过滤参数。 |

### 函数

#### `Delete`

Delete 根据 ID 或名称删除工作流。

```go
func (w *WorkflowsClient) Delete(ctx context.Context, workflowName string) (*rest.WorkflowDeleteResponse, error)
```

参数：

名称, 类型

`ctx`, `context.Context`
`workflowName`, `string`

返回值：

类型

`*rest.WorkflowDeleteResponse`
`error`
