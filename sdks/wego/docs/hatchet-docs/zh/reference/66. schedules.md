# Schedules 客户端

通过 [Hatchet 客户端](<55. client.md>)上的 `client.Schedules()` 访问。

## SchedulesClient

SchedulesClient 提供与工作流调度交互的方法

方法：

| 名称 | 描述 |
| --- | --- |
| `Create` | Create 创建新的计划工作流运行。 |
| `Delete` | Delete 删除计划工作流运行。 |
| `Get` | Get 根据 ID 获取特定的计划工作流运行。 |
| `List` | List 根据提供的参数获取计划工作流运行的集合。 |

### 函数

#### `Create`

Create 创建新的计划工作流运行。

```go
func (s *SchedulesClient) Create(ctx context.Context, workflowName string, trigger CreateScheduledRunTrigger) (*rest.ScheduledWorkflows, error)
```

参数：

| 名称 | 类型 |
| --- | --- |
| `ctx` | `context.Context` |
| `workflowName` | `string` |
| `trigger` | `CreateScheduledRunTrigger` |

返回值：

类型

`*rest.ScheduledWorkflows`
`error`

#### `Delete`

Delete 删除计划工作流运行。

func (s *SchedulesClient) Delete(ctx context.Context, scheduledRunId string) error

## 相关类型

### CreateScheduledRunTrigger

CreateScheduledRunTrigger 包含创建计划运行触发器的配置。

字段：

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| `TriggerAt` | `time.Time` | TriggerAt 指定工作流应被触发的时间。 |
| `Input` | `map[string]interface{}` | Input 是工作流的可选输入数据。 |
| `AdditionalMetadata` | `map[string]interface{}` | AdditionalMetadata 是与计划运行关联的可选元数据。 |
| `Priority` | `*RunPriority` |  |
