# Cron Client

用于管理 Hatchet 中 cron 工作流触发器的 cron 客户端。

此类为创建、删除、列出和获取 cron 工作流触发器提供了高层接口。

```ruby
cron = hatchet.cron.create(
  workflow_name: "my-workflow",
  cron_name: "daily-run",
  expression: "0 0 * * *",
  input: { key: "value" },
  additional_metadata: { source: "api" }
)
```

它在主客户端上以 `hatchet.cron` 的形式提供。

方法：

| Name | Description |
| --- | --- |
| `create` | 创建一个新的工作流 cron 触发器。 |
| `delete` | 删除一个工作流 cron 触发器。 |
| `list` | 列出符合指定条件的 cron 工作流触发器。 |
| `get` | 按 ID 获取特定的工作流 cron 触发器。 |

### Functions

#### `create`

创建一个新的工作流 cron 触发器。

```ruby
cron = hatchet.cron.create(
  workflow_name: "my-workflow",
  cron_name: "hourly-run",
  expression: "0 * * * *",
  input: { key: "value" },
  additional_metadata: { source: "api" }
)
```

参数：

| Name | Type | Description | Default |
| --- | --- | --- | --- |
| `workflow_name` | `String` | 要触发的工作流的名称（会应用命名空间） | _required_ |
| `cron_name` | `String` | cron 触发器的名称。 | _required_ |
| `expression` | `String` | 定义调度计划的 cron 表达式。 | _required_ |
| `input` | `Hash` | cron 工作流的输入数据。 | `{}` |
| `additional_metadata` | `Hash` | 与 cron 触发器关联的额外元数据。 | `{}` |
| `priority` | `Integer \| nil` | cron 工作流触发器的优先级。 | `nil` |

返回：

Type, Description

`Object`, 创建的 cron 工作流实例。

抛出：

Type, Description

`ArgumentError`, 如果 cron 表达式无效。
`HatchetSdkRest::ApiError`, 如果 API 请求失败。

#### `delete`

删除一个工作流 cron 触发器。

```ruby
hatchet.cron.delete("cron-123")
```

参数：

Name, Type, Description, Default

`cron_id`, `String`, 要删除的 cron 触发器的 ID。, _required_

抛出：

Type, Description

`HatchetSdkRest::ApiError`, 如果 API 请求失败。

#### `list`

列出符合指定条件的 cron 工作流触发器。

```ruby
crons = hatchet.cron.list(limit: 10, workflow_name: "my-workflow")
```

参数：

| Name | Type | Description | Default |
| --- | --- | --- | --- |
| `offset` | `Integer \| nil` | 列表的起始偏移量。 | `nil` |
| `limit` | `Integer \| nil` | 返回的最大条目数。 | `nil` |
| `workflow_id` | `String \| nil` | 用于过滤的工作流 ID。 | `nil` |
| `additional_metadata` | `Hash \| nil` | 按额外元数据键过滤。 | `nil` |
| `order_by_field` | `String \| nil` | 列表排序所依据的字段。 | `nil` |
| `order_by_direction` | `String \| nil` | 列表排序的方向。 | `nil` |
| `workflow_name` | `String \| nil` | 用于过滤的工作流名称。 | `nil` |
| `cron_name` | `String \| nil` | 用于过滤的 cron 触发器名称。 | `nil` |

返回：

Type, Description

`Object`, cron 工作流列表。

抛出：

Type, Description

`HatchetSdkRest::ApiError`, 如果 API 请求失败。

#### `get`

按 ID 获取特定的工作流 cron 触发器。

```ruby
cron = hatchet.cron.get("cron-123")
```

参数：

Name, Type, Description, Default

`cron_id`, `String`, 要获取的 cron 触发器 ID。, _required_

返回：

Type, Description

`Object`, 请求的 cron 工作流实例。

抛出：

Type, Description

`HatchetSdkRest::ApiError`, 如果 API 请求失败。
