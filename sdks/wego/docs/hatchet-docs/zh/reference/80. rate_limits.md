# Rate Limits Client

用于管理 Hatchet 中速率限制的 rate limits 客户端。

此类为使用 gRPC Admin 客户端创建和更新速率限制提供了高层接口。

```ruby
hatchet.rate_limits.put(key: "api-calls", limit: 100, duration: :SECOND)
```

它在主客户端上以 `hatchet.rate_limits` 的形式提供。

方法：

Name, Description

`put`, 为给定的键设置速率限制。

### Functions

#### `put`

为给定的键设置速率限制。

```ruby
hatchet.rate_limits.put(key: "api-calls", limit: 100, duration: :SECOND)
```

参数：

| Name | Type | Description | Default |
| --- | --- | --- | --- |
| `key` | `String` | 要设置速率限制的键。 | _required_ |
| `limit` | `Integer` | 要设置的速率限制。 | _required_ |
| `duration` | `Symbol` | 速率限制的时长（:SECOND、:MINUTE、:HOUR） | `:SECOND` |

抛出：

Type, Description

`GRPC::BadStatus`, 如果 gRPC 请求失败。
