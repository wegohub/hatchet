### CEL Client

用于调试 CEL 表达式的客户端。

#### 方法：

<a id="debug"></a>

##### `debug()`

使用提供的输入、过滤载荷和可选元数据来调试 CEL 表达式。可用于测试和验证 CEL 表达式，以及排查生产环境中的问题。

参数：

参数, 类型, 描述

`input`, `DebugCELInput`, 用于对 CEL 表达式求值的输入数据。

返回值：

`Promise`\<`CELEvaluationResult`\>

一个 Promise，解析为求值结果，结果可以是包含输出的成功，也可以是包含错误消息的失败。

抛出：

如果输入无效或 API 调用失败，将抛出错误。
