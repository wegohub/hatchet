# Runs 客户端

通过 [Hatchet 客户端](<55. client.md>)上的 `client.Runs()` 访问。

## RunsClient

RunsClient 提供与工作流运行交互的方法

方法：

| 名称 | 描述 |
| --- | --- |
| `BranchDurableTask` | BranchDurableTask 在指定节点从持久化任务创建分支。 |
| `Cancel` | Cancel 请求取消工作流运行中的特定任务。 |
| `Get` | Get 根据 ID 获取工作流运行。 |
| `GetDetails` | GetDetails 通过 gRPC 获取工作流运行的详细信息，包括任务级别的输出、错误和状态。 |
| `GetStatus` | GetStatus 根据 ID 获取工作流运行的状态。 |
| `List` | List 根据提供的参数获取工作流运行的集合。 |
| `Replay` | Replay 请求在工作流运行中重放某个任务。 |
| `Restore` | Restore 重新入队已被驱逐的任务，使其可以恢复执行。 |
| `SubscribeToStream` | SubscribeToStream 订阅特定工作流运行的流式事件。 |

| --- | --- |
