# Hatchet TypeScript SDK 参考

这是 TypeScript SDK 参考文档，介绍了与 Hatchet 资源交互的可用方法。
请查看[用户指南](https://docs.hatchet.run/v1)了解如何运行你的首批任务。

<a id="hatchetclient"></a>

### HatchetClient

HatchetV1 实现了与 Hatchet 工作流引擎交互的主客户端接口。
它提供了创建和执行工作流以及管理 worker 的方法。

#### 方法

<a id="batchtask"></a>

##### `batchTask()`

batchTask 方法的实现。

创建一个新的批处理任务工作流。批处理任务会缓冲并发运行，直到 Hatchet
刷新该批次（达到大小上限或刷新间隔），然后以所有缓冲输入为参数调用一次处理函数，
输入以每个运行的任务运行外部 ID 为键。处理函数必须返回一个将每个 ID 映射到其输出的
Record，或者设置 `batch.broadcastOutput` 以向所有调用方返回相同结果。
批处理任务的 retries 始终被强制为 0。

预览：批处理任务目前处于 beta 阶段，在未来版本中可能发生变化。

参数

Parameter, Type, Description

`options`, [`CreateBatchTaskWorkflowOpts`](<40. runnables.md#createbatchtaskworkflowopts>)\<`I` & `Resolved`\<`GlobalInput`, `MiddlewareBefore`\>, `MergeIfNonEmpty`\<`O`, `GlobalOutput`\>\>, 批处理任务配置选项

返回值

[`TaskWorkflowDeclaration`](<40. runnables.md#taskworkflowdeclaration>)\<`I`, `O`, `GlobalInput`, `GlobalOutput`, `MiddlewareBefore`, `MiddlewareAfter`\>

一个 TaskWorkflowDeclaration 实例

创建一个新的批处理任务工作流，其类型从函数参数推断。

参数

Parameter, Type, Description

`options`, `object` & `Omit`\<[`CreateBatchTaskWorkflowOpts`](<40. runnables.md#createbatchtaskworkflowopts>)\<`I`, `O`\>, `"batch"` \, `"fn"`\>, 批处理任务配置选项，包含定义类型的函数

返回值

[`TaskWorkflowDeclaration`](<40. runnables.md#taskworkflowdeclaration>)\<`I`, `O`, `GlobalInput`, `GlobalOutput`, `MiddlewareBefore`, `MiddlewareAfter`\>

一个带推断类型的 TaskWorkflowDeclaration 实例

<a id="run"></a>

##### `run()`

触发一个工作流运行并等待结果。

参数

| Parameter | Type | Description |
| --- | --- | --- |
| `workflow` | `string` \| `Workflow` \| `BaseWorkflowDeclaration`\<`I`, `O`\> | 要运行的工作流，可以是 Workflow 实例或工作流名称 |
| `input` | `I` | 工作流的输入数据 |
| `options` | `RunOpts` | 工作流运行的配置选项 |

返回值

`Promise`\<`O`\>

一个以工作流结果 resolve 的 Promise
