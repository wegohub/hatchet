# 触发工作流

你可以使用 `hatchet trigger` 命令在本地触发工作流，用于测试和开发。此命令允许你在 `hatchet.yaml` 文件中设置触发器，定义如何运行特定的工作流。

## 示例

在 `hatchet.yaml` 文件中，你可以为简单的工作流定义如下的触发器：

```yaml
triggers:
  - name: "simple"
    command: "poetry run python src/run.py"
    description: "Trigger a simple workflow"
```

然后，在运行 `hatchet trigger` 命令时选择此触发器：

```sh
hatchet trigger simple
```

或者直接运行 `hatchet trigger`，它会提示你交互式地选择一个触发器。
