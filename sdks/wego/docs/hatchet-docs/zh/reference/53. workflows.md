### Workflows Client

Workflows 客户端用于在 Hatchet 中以编程方式管理工作流。

注意：工作流指的是声明，而非单个运行。如果你要查找运行，请改用 RunsClient。

#### 方法：

<a id="delete"></a>

##### `delete()`

根据名称、ID 或对象删除一个工作流。

参数：

参数, 类型, 描述

`workflow`, `string` \, `BaseWorkflowDeclaration`\<`any`, `any`\> \, `Workflow`, 工作流名称、ID 或对象。

返回值：

`Promise`\<`void`\>

一个 Promise，解析为被删除的工作流。

<a id="get"></a>

##### `get()`

根据名称、ID 或对象获取一个工作流。

参数：

参数, 类型, 描述

`workflow`, `string` \, `BaseWorkflowDeclaration`\<`any`, `any`\> \, `Workflow`, 工作流名称、ID 或对象。

返回值：

`Promise`\<`Workflow`\>

一个 Promise，解析为该工作流。

<a id="getworkflowidfromname"></a>

##### `getWorkflowIdFromName()`

根据工作流名称、ID 或对象获取工作流 ID。
如果输入不是有效的 UUID，则会按名称查找该工作流。

参数：

参数, 类型, 描述

`workflow`, \, `string` \, `WorkflowDefinition` \, `BaseWorkflowDeclaration`\<`any`, `any`\> \, `Workflow`, 工作流名称、ID 或对象。

返回值：

`Promise`\<`string`\>

字符串形式的工作流 ID。

<a id="list"></a>

##### `list()`

列出租户中的所有工作流。

参数：

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| `opts?` | \{ `limit?`: `number`; `name?`: `string`; `offset?`: `number`; \} | 列表操作的选项。 |
| `opts.limit?` | `number` | 限制的数量 **Format** int **Default** `50` |
| `opts.name?` | `string` | 按名称搜索 |
| `opts.offset?` | `number` | 跳过的数量 **Format** int **Default** `0` |

返回值：

`Promise`\<`WorkflowList`\>

一个 Promise，解析为工作流列表。
