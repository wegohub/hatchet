# Rate Limits Client

继承自：`BaseRestClient`

rate limits 客户端是对 Hatchet gRPC API 的封装，让在 Hatchet 中使用速率限制更方便。

方法：

| 名称 | 描述 |
| --- | --- |
| `aio_list` | 列出租户的所有速率限制。 |
| `aio_put` | 为给定键设置速率限制。 |
| `list` | 列出租户的所有速率限制。 |
| `put` | 为给定键设置速率限制。 |

### Functions

#### `aio_list`

列出租户的所有速率限制。

参数：

| 名称 | 类型 | 描述 | 默认值 |
| --- | --- | --- | --- |
| `offset` | `int \| None` | 跳过的结果数量。 | `None` |
| `limit` | `int \| None` | 返回结果的最大数量。 | `None` |
| `search` | `str \| None` | 按键过滤速率限制的搜索查询。 | `None` |
| `order_by_field` | `RateLimitOrderByField \| None` | 结果排序所依据的字段。 | `None` |
| `order_by_direction` | `RateLimitOrderByDirection \| None` | 结果排序方向。 | `None` |

返回：

类型, 描述

`RateLimitList`, 速率限制列表。

#### `aio_put`

为给定键设置速率限制。

参数：

| 名称 | 类型 | 描述 | 默认值 |
| --- | --- | --- | --- |
| `key` | `str` | 要设置速率限制的键。 | _必填_ |
| `limit` | `int` | 要设置的速率限制值。 | _必填_ |
| `duration` | `RateLimitDuration` | 速率限制的持续时间。 | `SECOND` |

返回：

类型, 描述

`None`, None
