# 使用 `asyncio`

Hatchet 的 Python SDK 与 FastAPI、Langchain 等其他流行库类似，大量使用 `asyncio`，也建议你这样做！


  要学习 `asyncio` 的基础知识，可以参阅 [FastAPI 的这篇入门介绍](https://fastapi.tiangolo.com/async/)。


不过，与 FastAPI 中的情况一样，在 Hatchet 中使用 `asyncio` 时，你需要小心避免在定义为任务的函数中包含任何阻塞式逻辑，否则会阻塞 asyncio 事件循环，在阻塞操作完成之前无法执行其他工作。

例如，下面这个写法是 async 安全的：

```python
async def async_safe() -> int:
    await asyncio.sleep(5)

    return 42
```

但下面这个不是：

```python
async def blocking() -> int:
    time.sleep(5)

    return 42
```

在第二种情况下，在五秒的 sleep 结束之前，你的 worker 将无法处理任何其他定义为 async 的工作。

### 使用 `asyncio.to_thread` 和 `loop.run_in_executor`

为避免阻塞代码带来的问题，你可以使用 `asyncio.to_thread` 或更繁琐一些的 `loop.run_in_executor` 把阻塞代码放到 executor 中运行。下面两个示例都是 async 安全的，不会再阻塞事件循环。

```python
async def to_thread() -> int:
    await asyncio.to_thread(time.sleep, 5)

    return 42
```

```python
async def run_in_executor() -> int:
    loop = asyncio.get_event_loop()

    await loop.run_in_executor(None, time.sleep, 5)

    return 42
```
