# CEL Client

继承自：`BaseRestClient`

CEL 客户端用于在 Hatchet 中调试 CEL 表达式。

方法：

名称, 描述

`aio_debug`, 使用提供的输入、filter payload 和可选元数据调试 CEL 表达式。适用于测试和验证 CEL 表达式，以及排查生产环境中的问题。
`debug`, 使用提供的输入、filter payload 和可选元数据调试 CEL 表达式。适用于测试和验证 CEL 表达式，以及排查生产环境中的问题。

### Functions

#### `aio_debug`

使用提供的输入、filter payload 和可选元数据调试 CEL 表达式。适用于测试和验证 CEL 表达式，以及排查生产环境中的问题。

参数：

| 名称 | 类型 | 描述 | 默认值 |
| --- | --- | --- | --- |
| `expression` | `str` | 要调试的 CEL 表达式。 | _必填_ |
| `input` | `JSONSerializableMapping` | 输入，用于模拟工作流运行的输入。 | _必填_ |
| `additional_metadata` | `JSONSerializableMapping \| None` | 附加元数据，用于模拟可能随事件或工作流运行发送的元数据。 | `None` |
| `filter_payload` | `JSONSerializableMapping \| None` | filter payload，用于模拟在先前创建的过滤器上设置的 payload。 | `None` |

返回：

类型, 描述

`CELEvaluationResult`, 一个 V1CELDebugErrorResponse 或 V1CELDebugSuccessResponse，包含调试操作的结果。

#### `debug`

使用提供的输入、filter payload 和可选元数据调试 CEL 表达式。适用于测试和验证 CEL 表达式，以及排查生产环境中的问题。

参数：

| 名称 | 类型 | 描述 | 默认值 |
| --- | --- | --- | --- |
| `expression` | `str` | 要调试的 CEL 表达式。 | _必填_ |
| `input` | `JSONSerializableMapping` | 输入，用于模拟工作流运行的输入。 | _必填_ |
| `additional_metadata` | `JSONSerializableMapping \| None` | 附加元数据，用于模拟可能随事件或工作流运行发送的元数据。 | `None` |
