# Runnables

Hatchet Go SDK 中的 Runnables 是可以运行的对象，即任务和工作流。你会遇到的两种主要类型是：

- `Workflow`，可以通过 `NewTask` 声明任务并调用 run 系列方法
- `StandaloneTask`，由 `client.NewStandaloneTask`（或其持久化/批处理变体）返回的单个任务，支持相同的 run 系列方法

两者都实现了 `WorkflowBase` 接口，可以通过 `hatchet.WithWorkflows` 注册到 worker 上。构造函数请参见 [Client 页面](<55. client.md>)。

## Workflow

Workflow 定义一个 Hatchet 工作流，随后可以在其上声明任务，并进行运行、调度等操作。

方法：

| 名称 | 描述 |
| --- | --- |
| `GetName` | GetName 返回解析后的工作流名称（如适用则包含命名空间）。 |
| `NewBatchTask` | NewBatchTask 将一个函数转换为作为工作流一部分运行的 Hatchet 批处理任务。 |
| `NewDurableTask` | NewDurableTask 将一个函数转换为作为工作流一部分运行的持久化 Hatchet 任务。 |
| `NewTask` | NewTask 将一个函数转换为作为工作流一部分运行的 Hatchet 任务。 |
| `OnFailure` | OnFailure 为工作流设置失败处理器。 |
| `Run` | Run 使用给定输入执行工作流并等待完成。 |
| `RunMany` | RunMany 使用不同输入执行多个工作流实例。 |
| `RunNoWait` | RunNoWait 使用给定输入执行工作流，但不等待完成。 |

### 函数

#### `GetName`

GetName 返回解析后的工作流名称（如适用则包含命名空间）。

```go
func (w *Workflow) GetName() string
```

返回值：

类型

`string`

#### `NewBatchTask`

NewBatchTask 将一个函数转换为作为工作流一部分运行的 Hatchet 批处理任务。批处理任务会缓冲并发运行，直到 Hatchet 刷新该批次（达到大小上限或刷新间隔），然后以所有缓冲输入为参数调用一次处理函数，输入以每个运行的外部 ID（BatchMemberId）为键。批处理任务的 retries 始终被强制为 0。

函数参数必须具有以下签名：

```go
func(ctx hatchet.Context, input map[string]T) (map[string]R, error)
```

或者，当 batch.BroadcastOutput 为 true 时（相同结果返回给每个调用方）：

```go
func(ctx hatchet.Context, input map[string]T) (R, error)
```

函数签名会在运行时通过反射进行校验。批处理任务不能是持久化任务。

预览：批处理任务目前处于 beta 阶段，在未来版本中可能发生变化。

```go
func (w *Workflow) NewBatchTask(name string, fn any, batch BatchConfig, options ...TaskOption) *Task
```

参数：

| 名称 | 类型 |
| --- | --- |
| `name` | `string` |
| `fn` | `any` |
| `batch` | `BatchConfig` |
| `options` | `...TaskOption` |

返回值：

类型

`*Task`

#### `NewDurableTask`

函数参数必须具有以下签名：

## WorkflowResult

WorkflowResult 封装工作流执行结果，并提供类型安全的转换方法。

字段：

名称, 类型, 描述

`RunId`, `string`

方法：

名称, 描述

`Raw`, Raw 返回原始的、未解码的工作流结果。
`TaskOutput`, TaskOutput 从工作流结果中提取特定任务的输出。

### 函数

#### `Raw`

Raw 返回原始的、未解码的工作流结果。

```go
func (wr *WorkflowResult) Raw() any
```

返回值：

类型

`any`

#### `TaskOutput`

TaskOutput 从工作流结果中提取特定任务的输出。返回一个 TaskResult，可用于将任务输出转换为所需类型。

示例用法：

```go
taskResult := workflowResult.TaskOutput("myTask")
var output MyOutputType
err := taskResult.Into(&output)
```

```go
func (wr *WorkflowResult) TaskOutput(taskName string) *TaskResult
```

参数：

名称, 类型

`taskName`, `string`

返回值：

类型

`*TaskResult`

## 其他类型

### BatchConfig

BatchConfig 用于配置批处理任务的批处理行为。参见 Workflow.NewBatchTask。

### BatchMemberId

BatchMemberId 标识批处理任务输入/输出 map 中的单个条目。其值为缓冲条目所对应任务运行的外部 ID。

BulkPushOpFunc 用于通过 EventClient.BulkPush 配置批量事件推送。

### IdempotencyConfig
