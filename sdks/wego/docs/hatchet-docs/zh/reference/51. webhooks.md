### Webhooks Client

用于管理 Hatchet 中传入 Webhook 的客户端。

Webhook 允许外部系统通过向专用端点发送 HTTP 请求来触发 Hatchet
工作流。这使其能够与 GitHub、Stripe、Slack 等第三方服务或任何
能发送 webhook 事件的系统进行实时集成。

#### 方法：

<a id="create"></a>

##### `create()`

创建一个新的 webhook。

参数：

参数, 类型, 描述

`request`, `CreateWebhookOptions`, 创建操作的请求选项。

返回值：

`Promise`\<`V1Webhook`\>

一个 Promise，解析为创建的 webhook。

<a id="delete"></a>

##### `delete()`

根据名称删除一个 webhook。

参数：

参数, 类型, 描述

`webhookName`, `string`, 要删除的 webhook 名称。

返回值：

`Promise`\<`V1Webhook`\>

一个 Promise，解析为被删除的 webhook。

<a id="get"></a>

##### `get()`

根据名称获取一个 webhook。

参数：

参数, 类型, 描述

`webhookName`, `string`, 要获取的 webhook 名称。

返回值：

`Promise`\<`V1Webhook`\>

一个 Promise，解析为该 webhook。

<a id="list"></a>

##### `list()`

列出当前租户的所有 webhook。

参数：

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| `options?` | \{ `limit?`: `number`; `offset?`: `number`; `sourceNames?`: ...[]; `webhookNames?`: ...[]; \} | 列表操作的选项。 |
| `options.limit?` | `number` | - |
| `options.offset?` | `number` | - |
| `options.sourceNames?` | ...[] | - |
| `options.webhookNames?` | ...[] | - |

返回值：

`Promise`\<`V1WebhookList`\>

一个 Promise，解析为 webhook 列表。

<a id="update"></a>

##### `update()`

根据名称更新一个 webhook。

参数：

参数, 类型, 描述

`webhookName`, `string`, 要更新的 webhook 名称。
`options`, `Partial`\<`V1UpdateWebhookRequest`\>, 更新操作的选项。

返回值：

`Promise`\<`V1Webhook`\>

一个 Promise，解析为更新后的 webhook。
