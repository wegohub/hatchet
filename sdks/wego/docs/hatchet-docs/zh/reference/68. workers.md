# Workers 客户端

通过 [Hatchet 客户端](<55. client.md>)上的 `client.Workers()` 访问。

## WorkersClient

WorkersClient 提供与 worker 交互的方法

方法：

| 名称 | 描述 |
| --- | --- |
| `Get` | Get 根据 ID 获取 worker。 |
| `List` | List 获取租户的所有 worker。 |
| `Pause` | Pause 暂停 worker。 |
| `Unpause` | Unpause 取消暂停 worker。 |

### 函数

#### `Get`

Get 根据 ID 获取 worker。

```go
func (w *WorkersClient) Get(ctx context.Context, workerId string) (*rest.Worker, error)
```
