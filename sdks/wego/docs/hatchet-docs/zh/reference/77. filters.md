# Filters Client

用于与 Hatchet 过滤器 API 交互的 filters 客户端。

此类为在 Hatchet 系统中创建、获取、列出、更新和删除过滤器提供了高层接口。

```ruby
filters = hatchet.filters.list(limit: 10, workflow_ids: ["wf-1"])
```

```ruby
filter = hatchet.filters.create(
  workflow_id: "wf-1",
  expression: 'input.priority > 5',
  scope: "high-priority"
)
```

它在主客户端上以 `hatchet.filters` 的形式提供。

方法：

| Name | Description |
| --- | --- |
| `list` | 列出当前租户的过滤器。 |
| `get` | 按 ID 获取过滤器。 |
| `create` | 创建一个新的过滤器。 |
| `delete` | 按 ID 删除过滤器。 |
| `update` | 按 ID 更新过滤器。 |

### Functions

#### `list`

列出当前租户的过滤器。

```ruby
filters = hatchet.filters.list(limit: 10, workflow_ids: ["wf-1"])
```

参数：

| Name | Type | Description | Default |
| --- | --- | --- | --- |
| `limit` | `Integer \| nil` | 返回的最大过滤器数量。 | `nil` |
| `offset` | `Integer \| nil` | 要跳过的过滤器数量。 | `nil` |
| `workflow_ids` | `Array \| nil` | 用于过滤的工作流 ID 列表。 | `nil` |
| `scopes` | `Array \| nil` | 用于过滤的范围列表。 | `nil` |

返回：

Type, Description

`Object`, 符合指定条件的过滤器列表。

抛出：

Type, Description

`HatchetSdkRest::ApiError`, 如果 API 请求失败。

#### `get`

按 ID 获取过滤器。

```ruby
filter = hatchet.filters.get("filter-123")
```

参数：

Name, Type, Description, Default

`filter_id`, `String`, 要获取的过滤器的 ID。, _required_

返回：

Type, Description

`Object`, 过滤器详细信息。

抛出：

Type, Description

`HatchetSdkRest::ApiError`, 如果 API 请求失败。

#### `create`

创建一个新的过滤器。

```ruby
filter = hatchet.filters.create(
  workflow_id: "wf-1",
  expression: 'input.value > 10',
  scope: "my-scope",
  payload: { threshold: 10 }
)
```

参数：

| Name | Type | Description | Default |
| --- | --- | --- | --- |
| `workflow_id` | `String` | 与过滤器关联的工作流的 ID。 | _required_ |
| `expression` | `String` | 过滤器要求值的 CEL 表达式。 | _required_ |
| `scope` | `String` | 过滤器的范围。 | _required_ |
| `payload` | `Hash \| nil` | 随过滤器发送的载荷。 | `nil` |

返回：

Type, Description

`Object`, 创建的过滤器。

抛出：

Type, Description

`HatchetSdkRest::ApiError`, 如果 API 请求失败。

#### `delete`

按 ID 删除过滤器。

```ruby
hatchet.filters.delete("filter-123")
```

参数：

Name, Type, Description, Default

`filter_id`, `String`, 要删除的过滤器的 ID。, _required_

返回：

Type, Description

`Object`, 被删除的过滤器。

抛出：

Type, Description

`HatchetSdkRest::ApiError`, 如果 API 请求失败。

#### `update`

按 ID 更新过滤器。

```ruby
hatchet.filters.update("filter-123", { expression: 'input.value > 20' })
```

参数：

Name, Type, Description, Default

`filter_id`, `String`, 要更新的过滤器的 ID。, _required_
`updates`, `Hash`, 要应用到过滤器的更新。, _required_

返回：

Type, Description

`Object`, 更新后的过滤器。

抛出：

Type, Description

`HatchetSdkRest::ApiError`, 如果 API 请求失败。
