# Logs Client

继承自：`BaseRestClient`

logs 客户端用于与 Hatchet 的日志 API 交互。

方法：

名称, 描述

`aio_list`, 列出给定任务运行的日志行。
`list`, 列出给定任务运行的日志行。

### Functions

#### `aio_list`

列出给定任务运行的日志行。

参数：

| 名称 | 类型 | 描述 | 默认值 |
| --- | --- | --- | --- |
| `task_run_id` | `str` | 要列出日志的任务运行 ID。 | _必填_ |
| `limit` | `int` | 返回日志行的最大数量（默认：1000）。 | `1000` |
| `since` | `datetime \| None` | 获取日志的起始时间。 | `None` |
| `until` | `datetime \| None` | 获取日志的结束时间。 | `None` |

返回：

类型, 描述

`V1LogLineList`, 指定任务运行的日志行列表。

#### `list`

列出给定任务运行的日志行。

参数：

| 名称 | 类型 | 描述 | 默认值 |
| --- | --- | --- | --- |
| `task_run_id` | `str` | 要列出日志的任务运行 ID。 | _必填_ |
| `limit` | `int` | 返回日志行的最大数量（默认：1000）。 | `1000` |
| `since` | `datetime \| None` | 获取日志的起始时间。 | `None` |
| `until` | `datetime \| None` | 获取日志的结束时间。 | `None` |

返回：

类型, 描述

`V1LogLineList`, 指定任务运行的日志行列表。
