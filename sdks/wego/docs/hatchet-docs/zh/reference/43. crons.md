### Cron Client

Cron 客户端用于管理 Hatchet 中的 cron 工作流。

#### 方法：

<a id="create"></a>

##### `create()`

创建一个新的 Cron 工作流。

参数：

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| `workflow` | `string` \| `BaseWorkflowDeclaration`\<`any`, `any`\> \| `Workflow` | 工作流标识符或 Workflow 对象。 |
| `cron` | \{ `additionalMetadata?`: `Record`\<`string`, `string`\>; `expression`: `string`; `input?`: `Record`\<`any`, `any`\>; `name`: `string`; `priority?`: `number`; \} | 创建 Cron 触发器的输入数据。 |
| `cron.additionalMetadata?` | `Record`\<`string`, `string`\> | - |
| `cron.expression` | `string` | - |
| `cron.input?` | `Record`\<`any`, `any`\> | - |
| `cron.name` | `string` | - |
| `cron.priority?` | `number` | - |

返回值：

`Promise`\<`CronWorkflows`\>

一个 Promise，解析为创建的 CronWorkflows 对象。

抛出：

如果输入无效或 API 调用失败，将抛出错误。

<a id="delete"></a>

##### `delete()`

删除一个已有的 Cron 触发器。

参数：

参数, 类型, 描述

`cron`, `string` \, `CronWorkflows`, Cron 触发器 ID（字符串）或 CronWorkflows 对象。

返回值：

`Promise`\<`void`\>

Cron 触发器删除完成后解析的 Promise。

<a id="get"></a>

##### `get()`

根据 ID 获取指定的 Cron 触发器。

参数：

参数, 类型, 描述

`cron`, `string` \, `CronWorkflows`, Cron 触发器 ID（字符串）或 CronWorkflows 对象。

返回值：

`Promise`\<`CronWorkflows`\>

一个 Promise，解析为 CronWorkflows 对象。

<a id="list"></a>

##### `list()`

根据提供的查询参数列出所有 Cron 触发器。

参数：

参数, 类型, 描述

`query`, `object` & `object`, 列出 Cron 触发器的查询参数。

返回值：

`Promise`\<`CronWorkflowsList`\>

一个 Promise，解析为 CronWorkflowsList 对象。
