# Cron Client

继承自：`BaseRestClient`

cron 客户端用于在 Hatchet 中管理 cron 工作流。

方法：

| 名称 | 描述 |
| --- | --- |
| `aio_create` | 创建一个新的工作流 cron 触发器。 |
| `aio_delete` | 删除一个工作流 cron 触发器。 |
| `aio_get` | 按 ID 获取特定的工作流 cron 触发器。 |
| `aio_list` | 获取与条件匹配的所有工作流 cron 触发器列表。 |
| `create` | 创建一个新的工作流 cron 触发器。 |
| `delete` | 删除一个工作流 cron 触发器。 |
| `get` | 按 ID 获取特定的工作流 cron 触发器。 |
| `list` | 获取与条件匹配的所有工作流 cron 触发器列表。 |

### Functions

#### `aio_create`

创建一个新的工作流 cron 触发器。

参数：

| 名称 | 类型 | 描述 | 默认值 |
| --- | --- | --- | --- |
| `workflow_name` | `str` | 要触发的工作流名称。 | _必填_ |
| `cron_name` | `str` | cron 触发器的名称。 | _必填_ |
| `expression` | `str` | 定义计划的 cron 表达式。 | _必填_ |
| `input` | `JSONSerializableMapping` | cron 工作流的输入数据。 | _必填_ |
| `additional_metadata` | `JSONSerializableMapping` | 与 cron 触发器关联的附加元数据。 | _必填_ |
| `priority` | `int \| Priority \| None` | cron 工作流触发器的优先级。 | `None` |

返回：

类型, 描述

`CronWorkflows`, 创建的 cron 工作流实例。

#### `aio_delete`

删除一个工作流 cron 触发器。

参数：

名称, 类型, 描述, 默认值

`cron_id`, `str`, 要删除的 cron 触发器 ID。, _必填_

返回：

类型, 描述

`None`, None

#### `aio_get`

按 ID 获取特定的工作流 cron 触发器。

参数：

名称, 类型, 描述, 默认值

`cron_id`, `str`, 要获取的 cron 触发器 ID 或 CronWorkflows 实例。, _必填_

返回：

类型, 描述

`CronWorkflows`, 所请求的 cron 工作流实例。

#### `aio_list`

获取与条件匹配的所有工作流 cron 触发器列表。

参数：

| 名称 | 类型 | 描述 | 默认值 |
| --- | --- | --- | --- |
| `offset` | `int \| None` | 列表的起始偏移量。 | `None` |
| `limit` | `int \| None` | 返回的最大条目数。 | `None` |
| `workflow_id` | `str \| None` | 用于过滤的工作流 ID。 | `None` |
| `additional_metadata` | `JSONSerializableMapping \| None` | 按附加元数据键过滤。 | `None` |
| `order_by_field` | `CronWorkflowsOrderByField \| None` | 列表排序所依据的字段。 | `None` |
| `order_by_direction` | `WorkflowRunOrderByDirection \| None` | 列表排序方向。 | `None` |
| `workflow_name` | `str \| None` | 用于过滤的工作流名称。 | `None` |
| `cron_name` | `str \| None` | 用于过滤的 cron 触发器名称。 | `None` |

返回：

类型, 描述

`CronWorkflowsList`, cron 工作流列表。
