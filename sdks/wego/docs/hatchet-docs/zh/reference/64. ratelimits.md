# Rate Limits 客户端

通过 [Hatchet 客户端](<55. client.md>)上的 `client.RateLimits()` 访问。

## RateLimitsClient

RateLimitsClient 提供与速率限制交互的方法

方法：

名称, 描述

`List`, List 根据提供的参数获取速率限制（可选）。
`Upsert`, Upsert 使用提供的选项创建或更新速率限制。

### 函数

#### `List`

List 根据提供的参数获取速率限制（可选）。

```go
func (c *RateLimitsClient) List(ctx context.Context, opts *rest.RateLimitListParams) (*rest.RateLimitList, error)
```

参数：

名称, 类型

`ctx`, `context.Context`
`opts`, `*rest.RateLimitListParams`

返回值：

类型

`*rest.RateLimitList`
`error`

#### `Upsert`

Upsert 使用提供的选项创建或更新速率限制。

```go
func (c *RateLimitsClient) Upsert(opts CreateRatelimitOpts) error
```

参数：

名称, 类型

`opts`, `CreateRatelimitOpts`

返回值：

类型

`error`

## 相关类型

### CreateRatelimitOpts

CreateRatelimitOpts 包含创建或更新速率限制的选项。

字段：

| 名称 | 类型 | 描述 |
| --- | --- | --- |
| `Key` | `string` | key 是速率限制的唯一标识符 |
| `Limit` | `int` | limit 是在持续时间内容许的最大请求数 |
| `Duration` | `types.RateLimitDuration` | duration 指定速率限制的时间周期 |
