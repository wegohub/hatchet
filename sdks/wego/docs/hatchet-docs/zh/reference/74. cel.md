# CEL Client

用于在 Hatchet 中调试 CEL 表达式的 CEL 客户端。

此类为测试和调试过滤器和条件中使用的 CEL（Common Expression Language）表达式提供了高层接口。

```ruby
result = hatchet.cel.debug(
  expression: 'input.value > 10',
  input: { value: 15 }
)
if result.result.status == 'success'
  puts "Output: #{result.result.output}"
else
  puts "Error: #{result.result.error}"
end
```

它在主客户端上以 `hatchet.cel` 的形式提供。

方法：

Name, Description

`debug`, 使用给定的输入和可选元数据调试 CEL 表达式。

### Functions

#### `debug`

使用给定的输入和可选元数据调试 CEL 表达式。

适用于测试和验证 CEL 表达式，以及排查生产环境中的问题。

```ruby
result = hatchet.cel.debug(
  expression: 'input.count > 5 && metadata.env == "prod"',
  input: { count: 10 },
  additional_metadata: { env: 'prod' }
)
```

参数：

| Name | Type | Description | Default |
| --- | --- | --- | --- |
| `expression` | `String` | 要调试的 CEL 表达式。 | _required_ |
| `input` | `Hash` | 输入，用于模拟工作流运行输入。 | _required_ |
| `additional_metadata` | `Hash \| nil` | 额外元数据，模拟随事件或工作流运行发送的元数据。 | `nil` |
| `filter_payload` | `Hash \| nil` | 过滤器载荷，模拟先前创建的过滤器上设置的载荷。 | `nil` |

返回：

Type, Description

`CELEvaluationResult`, 包含 CELSuccess 或 CELFailure 的结果。

抛出：

Type, Description

`RuntimeError`, 如果没有从 CEL 调试 API 收到响应。
`HatchetSdkRest::ApiError`, 如果 API 请求失败。
