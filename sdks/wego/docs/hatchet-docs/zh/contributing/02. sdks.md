# SDK

本文档跟踪各 SDK 的功能支持情况，并旨在统一环境变量和配置加载的预期行为。

## 环境变量

每个 SDK 都应支持以下环境变量：

变量，说明，必需，默认值

`HATCHET_CLIENT_TOKEN`，要使用的租户级 API token。，是，N/A
`HATCHET_CLIENT_HOST_PORT`，要连接的 Hatchet 服务器的主机和端口，格式为 `host:port`。SDK 应能处理 scheme 和尾部斜杠，即 `https://host:port，否，新 token 中自动检测。
`HATCHET_CLIENT_TLS_STRATEGY`，要使用的 TLS 策略。有效值为 `none`、`tls` 和 `mtls`。，否，`tls`
`HATCHET_CLIENT_TLS_CERT_FILE`，要使用的 TLS 客户端证书文件路径。，仅当策略设为 `mtls` 时，N/A
`HATCHET_CLIENT_TLS_CERT`，要使用的 TLS 客户端密钥文件。，仅当策略设为 `mtls` 时，N/A
`HATCHET_CLIENT_TLS_KEY_FILE`，要使用的 TLS 客户端密钥文件路径。，仅当策略设为 `mtls` 时，N/A
`HATCHET_CLIENT_TLS_KEY`，要使用的 TLS 客户端密钥。，仅当策略设为 `mtls` 时，N/A
`HATCHET_CLIENT_TLS_ROOT_CA_FILE`，要使用的 TLS 根 CA 文件路径。，仅当服务器证书不是由环境可用的公共 CA 签发时，N/A
`HATCHET_CLIENT_TLS_ROOT_CA`，要使用的 TLS 根 CA。，仅当服务器证书不是由环境可用的公共 CA 签发时，N/A
`HATCHET_CLIENT_TLS_SERVER_NAME`，要使用的 TLS 服务器名称。，否，默认为 `host:port` 中的 `host`
`HATCHET_CLIENT_TLS_MIN_VERSION`，最低 TLS 版本。有效值为 `1.2` 和 `1.3`。，否，`1.3`

以下环境变量已弃用：

变量，说明，解释

`HATCHET_CLIENT_TENANT_ID`，要使用的租户 ID。，现在已是 token 的一部分。
