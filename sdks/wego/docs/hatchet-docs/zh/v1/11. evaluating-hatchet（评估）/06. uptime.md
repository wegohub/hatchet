# 正常运行时间与状态

关于 Hatchet Cloud 的可用性和事件更新，请使用状态页。对于自托管部署，可用性取决于你自己的基础设施。

## Hatchet Cloud 状态页

使用 **[status.hatchet.run](https://status.hatchet.run/)** 查看 Hatchet Cloud 及相关服务的实时状态和历史事件：

- **API**：Hatchet API 的可用性
- **Hatchet Cloud**：`cloud.hatchet.run`
- **Website**：`hatchet.run` 及文档站点

你还可以直接在状态页上订阅更新（邮件/短信等）。
