# 审计日志（Audit Logs）

Hatchet 会记录组织内执行的关键操作的审计日志，让你清楚地了解谁在什么时间、从哪里做了什么。

> **Info:** 审计日志在 **Business** 计划及以上版本中可用。如果你使用的是开源版本并需要
>   审计日志，请[联系我们](mailto:support@hatchet.run)了解升级详情。

## 记录内容

每条审计日志记录包含以下内容：

| 字段 | 说明 |
| --- | --- |
| **Actor（操作者）** | 执行操作的用户或 API 密钥 |
| **Action（操作）** | 执行的操作（例如 `ApiTokenCreate`、`TenantMemberDelete`） |
| **Resource type（资源类型）** | 被操作的资源类型（例如 `workflow-run`、`api-token`） |
| **Resource ID（资源 ID）** | 受影响的具体资源 |
| **IP address（IP 地址）** | 操作者的 IP 地址（仅限 HTTP 请求） |
| **User agent（用户代理）** | 请求的 user agent 字符串（仅限 HTTP 请求） |
| **Timestamp（时间戳）** | 操作发生的时间 |
| **Correlation ID（关联 ID）** | 用于将相关操作分组的可选 ID（gRPC 请求） |

## 被审计的操作

以下操作目前会被记录为审计日志条目：

| 操作 | 资源类型 | 说明 |
| --- | --- | --- |
| `TenantInviteAccept` | `tenant-invite` | 用户接受租户邀请 |
| `TenantMemberDelete` | `tenant-member` | 移除租户成员 |
| `ApiTokenCreate` | `api-token` | 创建新的 API token |
| `ApiTokenUpdateRevoke` | `api-token` | 吊销 API token |
| `V1WorkflowRunCreate` | `workflow-run` | 通过 API 触发 workflow 运行 |
| `ScheduledWorkflowRunCreate` | `scheduled-workflow` | 创建计划 workflow 运行 |

## 操作者类型

审计日志条目区分两类操作者：

- **用户（User）** —— 已登录用户通过仪表板或 API 执行的操作。这些条目包含操作者的 IP 地址和 user agent。
- **API 密钥（API key）** —— 通过 API 密钥以编程方式执行的操作（例如通过 gRPC 触发 workflow 运行）。这些条目可能包含用于将相关操作分组的关联 ID。

## 保留期

审计日志条目保留 **30 天**。超过 30 天的条目会被自动删除。

## 查看审计日志

组织管理员可以在 Hatchet 仪表板的组织设置中查看审计日志。日志可按租户和时间范围筛选。

## API 访问

也可以通过 Management API 以编程方式获取审计日志：

```
GET /api/v1/management/organizations/{organization}/audit-logs
```

查询参数：

| 参数 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `tenant` | UUID | 组织内所有活跃租户 | 筛选特定租户的日志 |
| `limit` | integer | `1000` | 返回的最大结果数 |
| `offset` | integer | `0` | 跳过的结果数 |
| `since` | ISO 8601 | 24 小时前 | 时间范围的起点 |
| `until` | ISO 8601 | 当前时间 | 时间范围的终点 |

结果按时间戳降序排列（最新在前）。
