# 区域可用性

Hatchet Cloud 在多个区域可用，方便你在靠近用户和数据的地方运行工作负载。

## 当前区域

**Hatchet Cloud**（[cloud.hatchet.run](https://cloud.hatchet.run)）的控制平面部署在 **aws-us-west-2**（俄勒冈）。

我们正在扩展数据平面的可用区域。已规划或已可用的区域包括：

区域, 位置, 状态

| aws-us-west-2 | 俄勒冈（美国） | **Live** |
| --- | --- | --- |
| aws-us-east-1 | 北弗吉尼亚（美国） | **Live** |
| aws-eu-west-1 | 爱尔兰 | **Live** |
| aws-ap-southeast-2 | 悉尼 | 私测（Private Beta） |

## 申请区域

我们始终愿意根据需求推出新区域。如果你出于延迟或合规原因需要特定区域，请[联系我们](mailto:support@hatchet.run)，我们可以讨论可用性。
