# Hatchet Cloud 快速入门

完成本指南后，你将拥有一个在本地运行的 worker，它执行一个由 CLI 触发的简单 task。

> **Info:** 本指南带你完成 Hatchet Cloud 的设置。如果你希望自托管 Hatchet，
>   请参阅[自托管快速入门](<01. index.md>)。

> **Info:** **只是本地开发？** 你可以在自己的机器上运行 Hatchet，无需注册账号，
>   某些模式下甚至无需 Docker。可选项请参阅
>   <a href="/v1/running-locally">在本地运行 Hatchet</a>。


### 注册

如果你还没有注册 Hatchet Cloud，请在[这里](https://cloud.hatchet.run)注册。

### 设置租户

在 Hatchet Cloud 中，你会看到一个创建首个组织和租户（tenant）的界面。租户是环境（例如 `dev`、`staging`、`production`）的逻辑隔离。每个租户都有自己的一组可访问它的用户。

创建租户后，只需按照 Hatchet Cloud 仪表板中的说明设置你的第一个快速入门项目和 workflow 即可。我们在下面的步骤中复制了这些说明。

### 安装 Hatchet CLI

#### 原生安装（推荐）

**MacOS、Linux、WSL**

```sh
    curl -fsSL https://install.hatchet.run/install.sh | bash
```

#### Homebrew

**MacOS**

```sh
    brew install hatchet-dev/hatchet/hatchet --cask
```

### 设置 Hatchet profile

你需要创建一个 Hatchet CLI profile 来连接你的 Hatchet Cloud 租户。可以使用 `hatchet profile add` 命令：

```sh
hatchet profile add
```

注意，Hatchet Cloud 仪表板会提供一个 API token，供你创建 profile 时使用。

### 运行快速入门

你可以使用 `hatchet quickstart` 命令运行 Hatchet Cloud 快速入门：

```sh
hatchet quickstart
```

### 运行你的 worker

设置好快速入门项目后，按照 quickstart 命令输出的说明，你就可以在本地运行 worker 了。这会用到 `hatchet worker dev` 命令：

```sh
hatchet worker dev
```

### 触发 workflow

最后，你可以使用 `hatchet trigger simple` 命令触发你的 workflow：

```sh
hatchet trigger simple
```

### （可选）安装 Hatchet 文档 MCP 和 Agent Skills

在 AI 编码助手（Cursor、Claude Code 等）中直接获取 Hatchet 文档：

```sh copy
hatchet docs install
```

获取常用 CLI 操作的 agent skills：

```sh copy
hatchet skills install
```

手动配置选项请参阅[完整设置指南](<03. using-coding-agents.md>)。


就是这样！你现在应该已经在 Hatchet Cloud 上建好了 Hatchet 项目，并且有一个 worker 在本地运行。
