# Task Slot 成本

每个 worker 都有固定数量的 slot，限制其一次能运行多少个 task，通过 worker 的 `slots` 选项设置，默认为 100。默认情况下，一个 task 在运行期间消耗一个 slot。slot 成本（slot cost）允许一个 task 消耗多个 slot，这样需要更多内存或 CPU 的 task 就会占用 worker 更多的容量，worker 同时运行的数量也就更少。


## 设置 slot 成本

在定义 task 时设置 slot 成本。成本为 5 表示该 task 在运行期间预留 5 个 slot。

#### Python

```python
@hatchet.task(slot_cost=5)
def omega(input: EmptyModel, ctx: Context) -> None:
    print("heavy work")


@hatchet.task(slot_cost=1)
def weenie(input: EmptyModel, ctx: Context) -> None:
    print("light work")
```

#### Typescript

```typescript
import { hatchet } from '../hatchet-client';

export const omega = hatchet.task({
  name: 'omega',
  slotCost: 5,
  fn: async () => {
    console.log('heavy work');
  },
});

export const weenie = hatchet.task({
  name: 'weenie',
  slotCost: 1,
  fn: async () => {
    console.log('light work');
  },
});
```

#### Go

```go
omega := client.NewStandaloneTask("omega", func(ctx hatchet.Context, input any) (any, error) {
	log.Println("heavy work")
	return nil, nil
}, hatchet.WithSlotCost(5))

weenie := client.NewStandaloneTask("weenie", func(ctx hatchet.Context, input any) (any, error) {
	log.Println("light work")
	return nil, nil
}, hatchet.WithSlotCost(1))
```

在一个有 100 个 slot 的 worker 上，成本为 5 的 omega task 和成本为 1 的 weenie task 从同样的 100 个 slot 中分配。该 worker 最多运行 20 个 omega task，或 100 个 weenie task，或任何成本总和为 100 的组合。

## 预留的工作方式

slot 容量是单个 worker 本地的。一个 task 的 slot 成本会记在运行它的那一个 worker 上，预留不能跨越两个 worker。成本为 5 的 task 需要一个有 5 个空闲 slot 的 worker，而不能从一个 worker 拿 3 个、另一个 worker 拿 2 个，即使整个 worker 池总体上有足够容量也不行。

请将每个 worker 的 slot 数量设置为至少等于你使用的最大 slot 成本。如果一个 task 的成本大于所有 worker 的 slot 数量，该 task 将永远无法被调度：它会在队列中等待，直到[调度超时](<../04. reliability（可靠性）/02. timeouts.md>)，然后被取消。

> **Info:** 更改 task 的 slot 成本会改变其 workflow 版本，因此下次注册会创建一个
>   新版本。不设置成本或将其设为 1，task 保持一个 slot，且不会改变版本。

## slot 成本与并发限制

slot 成本与[并发限制](<../05. flow-control（流控）/01. concurrency.md>)解决的是不同的问题。并发限制限定某个键的同时执行运行数量上限；使用静态键时，该限制作用于整个 worker 池。slot 成本不限制运行数量，它改变的是一次运行占用 worker 的多少容量。

如果你想同时最多有 5 个重型运行，请使用并发限制。如果你想让每个重型运行占用相当于轻型运行 5 倍的 worker 容量，请使用 slot 成本。两者可以组合用在同一个 task 上。
