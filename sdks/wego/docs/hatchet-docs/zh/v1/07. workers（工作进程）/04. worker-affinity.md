# Worker 亲和性分配（Worker Affinity Assignment，Beta）

> **Info:** 此功能目前处于 beta 阶段，可能会发生变化。

通常我们会希望根据某些条件（如 worker 能力、资源可用性或位置）将 workflow 分配给特定的 worker。Worker 亲和性（worker affinity）允许你基于 worker 的标签（label）状态指定将 workflow 分配给特定 worker。标签可以在 worker 上动态设置，以反映其当前状态，例如已加载到内存中的特定模型，或特定的磁盘要求。

然后，特定 task 可以指定期望的标签状态，确保 workflow 被分配给满足特定条件的 worker。如果没有 worker 满足指定条件，该 task 运行将保持 pending 状态，直到出现合适的 worker 或该 task 被取消。（参见[调度超时](<../04. reliability（可靠性）/02. timeouts.md#task-level-timeouts>)）

## 指定 Worker 标签

worker 向 Hatchet 注册时可以设置标签。标签是键值对，可用于指定 worker 的能力、资源可用性或其他可用于将 workflow 与 worker 匹配的条件。值可以是字符串或数字，且一个 worker 上可以设置多个标签。

#### Python

```python
worker = hatchet.worker(
    "affinity-worker",
    slots=10,
    labels={
        "model": "fancy-ai-model-v2",
        "memory": 512,
    },
    workflows=[affinity_worker_workflow],
)
worker.start()
```

#### Typescript

```typescript
const workflow = hatchet.workflow({
  name: 'affinity-workflow',
  description: 'test',
});

workflow.task({
  name: 'step1',
  fn: async (_, ctx) => {
    const results = [];

    for (let i = 0; i < 50; i++) {
      const result = await childWorkflow.run({});
      results.push(result);
    }
    ctx.logger.info('Spawned 50 child workflows');
    ctx.logger.info('Results', { results });

    return { step1: 'step1 results!' };
  },
});
```

## 指定 Step 的期望标签

你可以通过在 task 定义上设置 `desired_worker_labels` 属性，为 workflow 中的特定 task 指定期望的 worker 标签状态。该属性是一个对象，键为标签键，值为具有以下属性的对象：

- `value`：标签的期望值
- `comparator`（默认：`EQUAL`）：匹配标签值时使用的比较运算符。
  - `EQUAL`：标签值必须等于期望值
  - `NOT_EQUAL`：标签值必须不等于期望值
  - `GREATER_THAN`：标签值必须大于期望值
  - `GREATER_THAN_OR_EQUAL`：标签值必须大于或等于期望值
  - `LESS_THAN`：标签值必须小于期望值
  - `LESS_THAN_OR_EQUAL`：标签值必须小于或等于期望值
- `required`（默认：`true`）：该标签是否是 task 运行的必要条件。如果为 `true`，task 将保持 pending 状态，直到具有期望标签状态的 worker 可用。如果为 `false`，将根据匹配权重总和最高的 worker 优先选择。
- `weight`（可选，默认：`100`）：标签的权重。为 task 选择 worker 时，更高的权重优先于更低的权重。如果多个 worker 具有相同的最高权重，则选择权重总和最高的 worker。当 `required` 为 `true` 时忽略此项。

#### Ruby

```python
affinity_worker_workflow = hatchet.workflow(name="AffinityWorkflow")


@affinity_worker_workflow.task(
    desired_worker_labels=[
        DesiredWorkerLabel(key="model", value="fancy-ai-model-v2", weight=10),
        DesiredWorkerLabel(
            key="memory",
            value=256,
            required=True,
            comparator=WorkerLabelComparator.LESS_THAN,
        ),
    ],
)
```

### 动态 Worker 标签

还可以使用 `upsertLabels` 方法在 worker 上动态设置标签。这在 worker 状态随时间变化时很有用，例如将新模型加载到内存，或 worker 的资源可用性发生变化时。

#### Ruby

```python
async def step(input: EmptyModel, ctx: Context) -> dict[str, str | None]:
    if ctx.worker_labels.get("model") != "fancy-ai-model-v2":
        ctx.worker.upsert_labels({"model": "unset"})
        # DO WORK TO EVICT OLD MODEL / LOAD NEW MODEL
        ctx.worker.upsert_labels({"model": "fancy-ai-model-v2"})

    return {"worker": ctx.worker_id}
```

#### Tab 2

```typescript
const childWorkflow = hatchet.workflow({
```
