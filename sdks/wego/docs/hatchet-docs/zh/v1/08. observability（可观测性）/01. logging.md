# 日志（Logging）

Hatchet 内置了一个日志视图，你可以将 workflow 产生的日志推送到这里。这对于调试和监控你的 workflow 非常有用。

#### Ruby

你可以使用 Python 内置的 `logging` 包，也可以使用 `context.log` 方法，以便更精细地控制发送的日志。

## 使用内置的 `logging` 包

在初始化 `Hatchet` 类时，你可以传入一个自定义 logger。例如：

```python
import logging

from hatchet_sdk import ClientConfig, Hatchet

logging.basicConfig(level=logging.INFO)

root_logger = logging.getLogger()

hatchet = Hatchet(
    config=ClientConfig(
        logger=root_logger,
    ),
)
```

建议将根 logger 传给 `Hatchet` 类，这样可以确保所有日志都被 Hatchet logger 捕获。如果你的 workflow 定义在多个文件中，它们应当是根 logger 的子 logger。例如，对于以下文件结构：

```
workflows/
  workflow.py
client.py
worker.py
workflow.py
```

你应该在 `client.py` 中将根 logger 传给 `Hatchet` 类：

```python
import logging

from hatchet_sdk import ClientConfig, Hatchet

logging.basicConfig(level=logging.INFO)

root_logger = logging.getLogger()

hatchet = Hatchet(
    config=ClientConfig(
        logger=root_logger,
    ),
)
```

然后在 `workflows/workflow.py` 中创建一个子 logger：

```python
import logging
import time

from examples.logger.client import hatchet
from hatchet_sdk import Context, EmptyModel

logger = logging.getLogger(__name__)

logging_workflow = hatchet.workflow(
    name="LoggingWorkflow",
)


@logging_workflow.task()
def root_logger(input: EmptyModel, ctx: Context) -> dict[str, str]:
    for i in range(12):
        logger.info(f"executed step1 - {i}")
        logger.info({"step1": "step1"})

        time.sleep(0.1)

    return {"status": "success"}
```

## 使用 `context.log` 方法

你还可以使用 `context.log` 方法从 workflow 中记录日志。该方法位于传递给 workflow 中每个 task 的 `Context` 对象上。例如：

```python
@logging_workflow.task()
def context_logger(input: EmptyModel, ctx: Context) -> dict[str, str]:
    for i in range(12):
        ctx.log(f"executed step1 - {i}")
        ctx.log({"step1": "step1"})

        time.sleep(0.1)

    return {"status": "success"}
```

目前每个 task 最多允许 1000 行日志。

#### Tab 2

在 TypeScript 中，从 task 输出日志有两种方式。第一种是使用 `ctx.log()` 方法（来自 `Context`）来发送日志：

```typescript
const workflow = hatchet.workflow({
  name: 'logger-example',
  description: 'test',
  on: {
    event: 'user:create',
  },
});

workflow.task({
  name: 'logger-step1',
  fn: async (_, ctx) => {
    // log in a for loop

    for (let i = 0; i < 10; i++) {
      ctx.logger.info(`log message ${i}`);
      await sleep(200);
    }

    return { step1: 'completed step run' };
  },
});
```

这种方式的好处是开箱即用（无需任何配置！），但在灵活性和与现有日志体系的可插拔性方面有所局限。

Hatchet 也允许你在定义 workflow 时"自带" logger：

```typescript
const logger = pino();

class PinoLogger implements Logger {
  logLevel: LogLevel;
  context: string;

  constructor(context: string, logLevel: LogLevel = 'DEBUG') {
    this.logLevel = logLevel;
    this.context = context;
  }

  debug(message: string, extra?: JsonObject): void {
    logger.debug(extra, message);
  }

  info(message: string, extra?: JsonObject): void {
    logger.info(extra, message);
  }

  green(message: string, extra?: JsonObject): void {
    logger.info(extra, `%c${message}`);
  }

  warn(message: string, error?: Error, extra?: JsonObject): void {
    logger.warn(extra, `${message} ${error}`);
  }

  error(message: string, error?: Error, extra?: JsonObject): void {
    logger.error(extra, `${message} ${error}`);
  }

  // optional util method
  util(key: string, message: string, extra?: JsonObject): void {
    // for example you may want to expose a trace method
    if (key === 'trace') {
      logger.info(extra, 'trace');
    }
  }
}

const hatchet = Hatchet.init({
  log_level: 'DEBUG',
  logger: (ctx, level) => new PinoLogger(ctx, level),
});
```

在这个示例中，我们创建了一个实现 Hatchet `Logger` 接口的 Pino logger，并将其传给 Hatchet 客户端构造函数。之后就可以在 step 中使用该 logger：

```typescript
const workflow = hatchet.workflow({
  name: 'logger-example',
  description: 'test',
  on: {
    event: 'user:create',
  },
});

workflow.task({
  name: 'logger-step1',
  fn: async (_, ctx) => {
    // log in a for loop

    for (let i = 0; i < 10; i++) {
      ctx.logger.info(`log message ${i}`);
      await sleep(200);
    }

    return { step1: 'completed step run' };
  },
});
```

#### Tab 3

```ruby
require "hatchet-sdk"
require "logger"

logger = Logger.new($stdout)
logger.level = Logger::INFO

HATCHET = Hatchet::Client.new(debug: true) unless defined?(HATCHET)

LOGGING_WORKFLOW = HATCHET.workflow(name: "LoggingWorkflow")

LOGGING_WORKFLOW.task(:root_logger) do |input, ctx|
  12.times do |i|
    logger.info("executed step1 - #{i}")
    logger.info({ "step1" => "step1" }.inspect)

    sleep 0.1
  end

  { "status" => "success" }
end
```
```ruby
LOGGING_WORKFLOW.task(:context_logger) do |input, ctx|
  12.times do |i|
    ctx.log("executed step1 - #{i}")

  end

  { "status" => "success" }
end
```
