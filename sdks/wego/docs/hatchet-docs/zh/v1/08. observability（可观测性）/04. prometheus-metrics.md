# Prometheus 指标

> **Info:** 仅在 Hatchet Cloud 的 Enterprise 版本中可用，[联系我们](https://cal.com/team/hatchet/talk-to-us)以升级。

Hatchet 为你的租户导出 Prometheus 指标，可由 Grafana、DataDog 等服务抓取。

> **Info:** 完整的可用指标列表、设置说明和 PromQL 查询示例，请参阅
>   [Prometheus 指标自托管指南](/self-hosting/prometheus-metrics)。

## 租户指标

各个租户的指标可通过 REST API 端点以 Prometheus 文本格式获取。

### 端点

```
GET /api/v1/tenants/{tenantId}/prometheus-metrics
```

### 身份认证

该端点需要使用有效 API token 的 Bearer token 认证：

```
Authorization: Bearer 
```

### 响应格式

响应以标准 Prometheus 文本格式返回，包括：

- 描述每个指标的 HELP 注释
- TYPE 声明（counter、gauge 等）
- 带标签和值的指标样本

### 使用示例

```bash
curl -H "Authorization: Bearer your-api-token-here" \
  https://cloud.onhatchet.run/api/v1/tenants/707d0855-80ab-4e1f-a156-f1c4546cbf52/prometheus-metrics
```
