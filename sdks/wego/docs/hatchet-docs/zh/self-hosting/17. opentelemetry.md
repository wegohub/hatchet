# 内部 OpenTelemetry Trace

本页面介绍如何将 Hatchet 自身服务（包括 engine 和 API 服务器）发出的 trace 导出到 OpenTelemetry collector，以便观测自托管的 Hatchet 实例。这与指南中的 [OpenTelemetry](<../v1/08. observability（可观测性）/02. opentelemetry.md>) 页面不同，后者介绍的是对你运行在 worker 上的应用、task 和 workflow 代码进行追踪。内部 trace 导出默认关闭，只有设置了 collector URL 才会启用。

## 启用 trace 导出

在你想要追踪的 Hatchet 服务上设置 collector URL。导出使用基于 gRPC 的 OTLP，因此该 URL 是不带协议 scheme 的主机和端口：

```bash
SERVER_OTEL_COLLECTOR_URL=<otel-collector-host>:4317
SERVER_OTEL_SERVICE_NAME=hatchet-engine
```

连接默认使用 TLS。对于不做 TLS 终结的 collector，请设置 `SERVER_OTEL_INSECURE=true`。如果你的 collector 需要认证，请将 `SERVER_OTEL_COLLECTOR_AUTH` 设置为 Hatchet 应在 `Authorization` 头中发送的值。要只导出一部分 trace，请将 `SERVER_OTEL_TRACE_ID_RATIO` 设置为 `0` 到 `1` 之间的值。这是 OpenTelemetry 的头部采样（head sampling），与对存储在数据库中的仪表盘结果进行采样的 [Trace 采样](<15. sampling.md>)无关。

engine 和 API 服务器是独立配置的。请在要从中导出的每个服务上设置这些变量，如果要在 collector 中区分它们，请为每个服务设置不同的 `SERVER_OTEL_SERVICE_NAME`。

## Kubernetes 与 Helm

Helm chart 没有专门的 OpenTelemetry 值。请按照[配置 Helm Chart](<05. kubernetes-helm-configuration.md>) 中描述的通用环境变量透传方式设置 `SERVER_OTEL_*` 变量。对于 `hatchet-stack` 和 `hatchet-ha` chart，即 `sharedConfig.env`：

```yaml
sharedConfig:
  env:
    SERVER_OTEL_COLLECTOR_URL: "<otel-collector-host>:4317"
```

`sharedConfig.env` 下的值适用于所有后端服务，因此在这里设置的 `SERVER_OTEL_SERVICE_NAME` 会被所有服务共享。要为 engine 和 API 服务器设置不同的服务名，请改为在各个服务的 deployment 上设置 `SERVER_OTEL_SERVICE_NAME`。

## Hatchet 发出的内容

启用导出后，engine 和 API 服务器会初始化追踪并可以发出 span，包括通过 `otelpgx` 追踪的数据库查询 span。Span 都在 `hatchet.run/` 命名空间之下。每个导出服务都会设置 `service.name` 资源属性（来自 `SERVER_OTEL_SERVICE_NAME`）以及 `library.language=go`，并在设置了 `K8S_POD_NAME`、`K8S_POD_NAMESPACE` 和 `K8S_CLOUD_REGION`（或 `AWS_REGION` / `AWS_DEFAULT_REGION`）时添加 `k8s.pod.name`、`k8s.namespace.name` 和 `cloud.region`。

## 配置参考

这些变量也列在 [engine 配置选项](<07. configuration-options.md>)页面上，括号中为配置文件键。相关设置 `SERVER_OTEL_METRICS_ENABLED`（`otel.metricsEnabled`）可通过同一 collector URL 启用 OpenTelemetry 指标导出。

变量（配置键），说明，默认值

`SERVER_OTEL_COLLECTOR_URL`（`otel.collectorURL`），OTLP gRPC collector 端点，格式为 `host:port`。为空时禁用导出。，空
`SERVER_OTEL_SERVICE_NAME`（`otel.serviceName`），`service.name` 资源属性的值。，`server`
`SERVER_OTEL_TRACE_ID_RATIO`（`otel.traceIdRatio`），0 到 1 之间的头部采样比率。，`1`
`SERVER_OTEL_INSECURE`（`otel.insecure`），使用明文连接代替 TLS。，`false`
`SERVER_OTEL_COLLECTOR_AUTH`（`otel.collectorAuth`），发送给 collector 的 `Authorization` 头的值。，空
