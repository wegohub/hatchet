# Trace 采样

对于流量非常大的部署，可能需要对仪表盘的结果进行采样，以限制 Hatchet 数据库中存储的数据量。**这不会影响 Hatchet engine 的行为，所有 task 仍会被处理。**可以通过设置以下环境变量来实现：

```bash
SERVER_SAMPLING_ENABLED=t
SERVER_SAMPLING_RATE=0.1 # only 10% of results will be sampled
```

采样在 workflow run 级别进行，因此同一 workflow 中的所有 task 及其所有事件都会一起被采样。采样有以下限制：

- 派生子 task 的父 task 不保证与子 task 一起被采样。这意味着子 task 可能会显示在仪表盘中而没有对应的父 task，反之亦然。
- 无法通过配置采样来确保失败事件被采样。
- 只有被采样的 task 才能通过 REST API 取消或重放：如果你依赖程序化的取消和重放，请不要使用此功能。
