# Kubernetes 快速开始

## 前置条件

- 一个 Kubernetes 集群，且已设置为 `kubectl` 的当前上下文
- 已安装 `kubectl` 和 `helm`

## 快速开始


### 启动 Hatchet

要部署 `hatchet-stack`，请运行以下命令：

```sh
helm repo add hatchet https://hatchet-dev.github.io/hatchet-charts
helm install hatchet-stack hatchet/hatchet-stack --set caddy.enabled=true
```

此默认安装会将 Hatchet 服务器作为集群内的内部服务运行，并通过 `Caddy` 启动一个反向代理以获得本地访问。

加密密钥和密钥会在首次安装时由 quickstart job 自动生成，该 job 默认启用（`api.quickstartJob.enabled=true`）。详情请参阅[凭据与密钥生成](<05. kubernetes-helm-configuration.md>)。

要查看 Hatchet 服务器，请运行以下命令：

```sh
export NAMESPACE=default # TODO: replace with your namespace
export POD_NAME=$(kubectl get pods --namespace $NAMESPACE -l "app=caddy" -o jsonpath="{.items[0].metadata.name}")
export CONTAINER_PORT=$(kubectl get pod --namespace $NAMESPACE $POD_NAME -o jsonpath="{.spec.containers[0].ports[0].containerPort}")
kubectl --namespace $NAMESPACE port-forward $POD_NAME 8080:$CONTAINER_PORT
```

然后访问 `http://localhost:8080` 即可看到运行中的 Hatchet 前端。你可以使用以下凭据登录 Hatchet：

```
Email: admin@example.com
Password: Admin123!!
```

### 端口转发到 Hatchet engine

```sh
export NAMESPACE=default # TODO: replace with your namespace
export POD_NAME=$(kubectl get pods --namespace $NAMESPACE -l "app.kubernetes.io/name=engine" -o jsonpath="{.items[0].metadata.name}")
export CONTAINER_PORT=$(kubectl get pod --namespace $NAMESPACE $POD_NAME -o jsonpath="{.spec.containers[0].ports[0].containerPort}")
kubectl --namespace $NAMESPACE port-forward $POD_NAME 7070:$CONTAINER_PORT
```

这会在 `localhost:7070` 上启动 Hatchet engine 服务，你可以从示例中连接到它。

### 生成 API token

要生成 API token，请导航到 Hatchet 前端的 `Settings` 标签页并点击 `API Tokens` 标签页。点击 `Generate API Token` 按钮创建新 token。请将该 token 妥善保存。

### 运行你的第一个 worker

现在你已经有了一个 API token，请参阅[此处](https://docs.hatchet.run/home/setup)的指南了解如何运行你的第一个 task。
