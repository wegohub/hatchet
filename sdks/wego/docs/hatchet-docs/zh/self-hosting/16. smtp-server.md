# SMTP 服务器

使用任意标准 SMTP 提供商（Gmail、SendGrid、AWS SES 等）为租户邀请和 Hatchet 告警配置邮件投递。

## 前置条件

- 一个支持带用户名和密码的 [PLAIN](https://datatracker.ietf.org/doc/html/rfc4616/) 认证的 SMTP 提供商。

## 配置

设置以下环境变量：

```bash
# Enable SMTP
export SERVER_EMAIL_KIND=smtp
export SERVER_EMAIL_SMTP_ENABLED=true

# Connection Settings
export SERVER_EMAIL_SMTP_SERVER_ADDR=smtp.gmail.com:587            # Host and port
export SERVER_EMAIL_SMTP_AUTH_USERNAME=your-email@yourdomain.com   # Username or API Key ID
export SERVER_EMAIL_SMTP_AUTH_PASSWORD=your-password               # Password or API Secret Key

# Sender Identity
export SERVER_EMAIL_SMTP_FROM_EMAIL=noreply@yourdomain.com         # Sender email address
export SERVER_EMAIL_SMTP_SUPPORT_EMAIL=support@yourdomain.com      # Support contact email
export SERVER_EMAIL_SMTP_FROM_NAME="Hatchet"                       # (Optional) Display name
```

## 提供商参考

主流提供商的常用配置值：

提供商，服务器地址，用户名，密码

**[Gmail](https://support.google.com/mail/answer/185833?hl=en)**，`smtp.gmail.com:587`，你的邮箱，[应用密码](https://myaccount.google.com/apppasswords)
**[SendGrid](https://docs.sendgrid.com/for-developers/sending-email/integrating-with-the-smtp-api)**，`smtp.sendgrid.net:587`，`apikey`，你的 API Key
**[AWS SES](https://docs.aws.amazon.com/ses/latest/dg/send-email-smtp.html)**，`email-smtp.us-east-1.amazonaws.com:587`，IAM 用户名，IAM 密钥
**[Outlook](https://support.microsoft.com/en-us/office/pop-imap-and-smtp-settings-8361e398-8af4-4e97-b147-6c6c4ac95353)**，`smtp.office365.com:587`，你的邮箱，你的密码
