# Worker 配置选项

Hatchet worker 可以通过环境变量和编程式选项进行配置。本文档包含所有可用选项的列表。

## 基础配置

变量，说明，默认值

`HATCHET_CLIENT_TOKEN`，worker 的认证 token
`HATCHET_CLIENT_HOST_PORT`，GRPC 服务器主机和端口，\* 继承自 token
`HATCHET_CLIENT_API_URL`（TypeScript SDK），API 服务器主机和端口，\* 继承自 token
`HATCHET_CLIENT_SERVER_URL`（Go SDK），API 服务器主机和端口，\* 继承自 token
`HATCHET_CLIENT_NAMESPACE`，worker 的命名空间前缀，\* 继承自 token

## Worker 运行时配置

变量，说明，默认值

`name`，worker 的友好名称
`slots`，最大并发 run 数，`100`
`durable_slots`，最大并发持久 task 数，`1000`

## Worker 健康检查服务器（Python SDK）

这些变量启用一个本地 HTTP 服务器，为运行中的 worker 暴露 `/health` 和 `/metrics`。

变量，说明，默认值

`HATCHET_CLIENT_WORKER_HEALTHCHECK_ENABLED`，启用本地 worker 健康检查服务器，`false`
`HATCHET_CLIENT_WORKER_HEALTHCHECK_PORT`，本地 worker 健康检查服务器的端口，`8001`
`HATCHET_CLIENT_WORKER_HEALTHCHECK_EVENT_LOOP_BLOCK_THRESHOLD_SECONDS`，如果 worker 监听进程的事件循环阻塞超过该阈值，`/health` 返回 503，`5.0`

## TLS 配置

变量，说明，默认值

`HATCHET_CLIENT_TLS_STRATEGY`，TLS 策略（tls、mtls、none），`tls`
`HATCHET_CLIENT_TLS_CERT_FILE`，TLS 证书文件路径
`HATCHET_CLIENT_TLS_KEY_FILE`，TLS 密钥文件路径
`HATCHET_CLIENT_TLS_ROOT_CA_FILE`，TLS 根 CA 文件路径
`HATCHET_CLIENT_TLS_SERVER_NAME`，TLS 服务器名称
`HATCHET_CLIENT_TLS_MIN_VERSION`，最低 TLS 版本（1.2、1.3），`1.3`

## 日志配置

变量，说明，默认值

`HATCHET_CLIENT_LOG_LEVEL`，worker 客户端的日志级别，`WARN`
`HATCHET_CLIENT_LOG_FORMAT`，worker 客户端的日志格式，`console`
`HATCHET_CLIENT_GRPC_MAX_RECV_MESSAGE_LENGTH`，gRPC 最大消息接收大小（仅 Python SDK），`4MB`
`HATCHET_CLIENT_GRPC_MAX_SEND_MESSAGE_LENGTH`，gRPC 最大消息发送大小（仅 Python SDK），`4MB`
