# wego SDK v0.2.0 交付与复审报告

完成时间：`2026-10-09T04:01:44.757006+00:00`。SDK **0.2.0**，协议 **4**，官方依赖与镜像 **v0.110.5**，PostgreSQL MQ。本报告可作为 Claude 再次评审的完成情况输入。

## 实现结果

- 每个 RPC 对应一个 StandaloneTask，删除 START/SESSION、输入会话、控制 workflow 和控制 Worker。client/bidi 在 CloseSend 一次提交请求数组，Worker 用有界 channel 适配 Recv。
- 业务输入采用 ProtoJSON；routing 按调用提供并支持方法默认值，CEL 读取 input.routing。所有输出与控制帧统一经过有界 codec，发布响应不明确时复用 producer、序号和冻结字节。
- 默认 Reliable 使用官方持久流协议；规范 CLAIM 确认前不启动业务或报告 START，同代次落选者不报告终态，旧代次取消/完成不影响新执行。
- 公开消费 checkpoint、ResumeStream 和有限 handler checkpoint 已实现；恢复核对运行身份，预取不推进断点，已有历史须读到 EOF 后继续发布。成功 EOF 核对引擎权威终态、结束清单及完整交付。
- worker_key 按 SDK 实例生成，重连保持、重启变化；展示名称独立且可覆盖。RPC workflow 无固定前缀或摘要后缀，多副本复用定义与版本。
- 定向/广播 Worker 事件使用两个持久订阅和 JOIN 屏障，不占任务 slots；内部取消与业务回调队列独立，故障恢复有预算，正常空闲不会超时。
- 完整后端请求/结果计费，超大结果明确失败而非无限上报；批量结果按实际 protobuf 尺寸拆分，只移除已确认的 pending 身份。补齐方向独立的 gRPC 消息上限、输入超限不提交前缀、并发 EOF 和关闭边界。
- 增加实例协议指标及执行身份 trace；provider/registry 不使用全局状态，metrics 默认关闭。中文注释说明身份、锁、顺序、恢复和预算约束。

## 当前明确的边界

- Worker bidi 是整批输入、流式输出；交互式双向使用网络 gRPC。
- Worker 通知也依赖 Durable Streams entitlement，仅 unary 的 Worker 也需部署启用；SDK 不直接修改业务数据库。
- Reliable 过滤有效输出，不阻止旧 Worker 物理晚写，不保证业务外部副作用 exactly-once；业务消费后保存 checkpoint 前的崩溃窗口需要自行幂等。
- 缺 epoch=0 历史起点、过期 cursor 或失效 producer 水位明确失败，不把剩余历史当作首次执行。输出订阅不可达在对账预算后返回 Unavailable，不凭等待超时宣称持久数据损坏。
- PutStream 实时路径不提供持久恢复或订阅就绪 ACK；能力不足不降级，实时输出禁止应用重试补帧。
- JOIN 扫描保留历史受十万帧/64 MiB/30 秒默认预算约束；历史 codec profile、密钥和卸载对象需覆盖 topic 实际保留期，不能只按事件 TTL 回收。
- 通知发布成功仅表示持久存储，业务队列满会拒绝，不承诺至少一次处理；不响应 context 的业务 goroutine 无法被 Go 强制终止，SDK 不无限等待。
- 协议 3 的历史运行不转换；升级前排空旧任务，协调客户端/Worker 并迁移 workflow 和触发器引用。官方 Go Streams 更新仍需复核稳定 producer/seq、错误、cursor 及连接所有权契约。

## 工程边界与清理

所有改动只在 `sdks/wego/**`，Hatchet 源码、根依赖和官方模块缓存未作为实现补丁修改。公开类型及动态错误隔离门禁通过，只有 backend 导入 Hatchet 实现。没有创建控制 Worker，没有添加 RabbitMQ，没有更换全局 OTel provider。

业务测试定义与触发器按唯一 namespace 清理，embedded 数据库已删除。运行历史、引擎 Worker 记录、持久 topic 及明确保留的协议探针定义保留；不伪造清理完成。报告不记录凭证。

CI 模板和 Compose 配置已在本机验证，启动点显式设置 SERVER_SECURITY_CHECK_ENABLED=false。托管 CI 未运行，仓库未注册新的 CI 工作流。
