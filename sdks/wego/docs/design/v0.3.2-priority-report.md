# wego 0.3.2：触发优先级简化与检查

验收日期：2026-10-11。SDK `0.3.2`，协议 `5`；依赖和本机引擎为未经修改的官方 Hatchet `v0.110.5`，MQ 使用 PostgreSQL。

## API 与行为

`model.CreateCronTrigger.Priority` 和 `model.CreateScheduledRunTrigger.Priority` 均改为 `int32`：

- `0` 表示未指定，JSON 不发送 `priority`，本机服务端保存为默认值 `1`。
- `1–3` 分别为低、中、高优先级，可直接写 `Priority: 3`。
- 负数及大于 `3` 的值在目标查询、codec 上传和创建请求之前报错；包含 int32 边界测试。

这是源码 API 变更，调用方移除取地址；协议保持 `5`。示例、当前使用文档、版本和验收 manifest 已同步。

Cron 创建使用 backend 内的官方 REST 适配，显式传递优先级。当前依赖中的官方 Go SDK 高层 Cron 创建方法没有把 DTO 的 Priority 写入请求；本次不修改官方源码，查询和删除仍复用官方客户端。

## 可选指针检查

本轮检查公开模型及配置、管理入口，没有批量把所有指针替换为零值：

| 字段或入口 | 结论 |
|---|---|
| 两个触发器 `Priority` | 使用 `0` 缺省契约，已改为值类型。 |
| `RunOptions.Priority` | 保留：省略不覆盖优先级；显式 `WithRunPriority(0)` 需要报错。同步修正了字段注释。 |
| `RunOptions.Sticky`、Webhook 的 `ReturnEventAsResponsePayload` | 保留：未配置与显式 `false` 需要区分。 |
| 并发、限流的固定值与 CEL 表达式 | 保留：字段存在性用于表达静态或动态配置，显式零值/空表达式不能等同未配置。 |
| Batch 的可选时间窗口、分组与分组容量 | 保留现有存在性契约，本轮没有重新定义零值的含义。 |
| `EventWait.Scope`、历史时间、父运行身份和流结束信息 | 保留：无条件/无身份与显式空值或具体信息需要区分。 |
| `CreateWebhookOpts.StaticPayload` 的 `*map`、`CELClient.Debug` 的两个 `*map` 参数 | **可进一步简化的候选**：map 自身可用 nil 表示未提供，空 map 表示空对象。当前仍沿用官方可选 DTO；本次未扩大 Webhook/CEL API 的变更范围。 |

## 验证

以下检查通过，普通单元范围排除需要手动启动 Worker 的 feature client；该入口单独编译验证：

- `GOWORK=off go build ./...`
- `GOWORK=off python3 scripts/unit.py`
- `GOWORK=off python3 scripts/unit.py -race`
- `GOWORK=off go vet ./...`
- `GOWORK=off go test ./tests/feature/client -run '^$'`
- `GOWORK=off go test -tags=wego_embedded ./internal/backend -run '^$'`：只验证可选 embedded 构建，本次未重跑嵌入引擎运行验收。
- 单元入口中的生成一致性、manifest、中文声明注释和 API/依赖边界门禁通过。

HTTP 测试覆盖两种触发器的 `0–3`，检查请求体中 priority 的存在性和原值。非法值测试确认没有目标查询、编码或提交；测试不依赖本机服务。

真实引擎命令：

```bash
python3 sdks/wego/scripts/local-test.py env GOWORK=off GOFLAGS=-mod=readonly \
  WEGO_REPORT_PATH=/tmp/wego-v032-trigger-evidence.json \
  go -C sdks/wego test -json -count=1 -tags=e2e ./tests/e2e \
  -run 'TestExamples/cron$|^TestTriggerPriorityPresence$' -timeout 5m
```

耗时约 59 秒，通过两种触发器各四个优先级的持久配置断言，以及分钟级 Cron、一次性 Schedule 的真实 protobuf 执行。结构化证据、RunID 与本轮 namespace 见 [验收数据](v0.3.2-priority-report.json)。本次没有重新运行 0.3.0 的全部功能矩阵。

只清理本轮两个唯一 namespace：删除 6 份 workflow 定义及关联触发器、2 条任务运行和对应查询记录；清理后所属 workflow、任务和运行查询记录均为 0。其他业务资源保留。所有源码及版本改动限于 `sdks/wego/**`。
