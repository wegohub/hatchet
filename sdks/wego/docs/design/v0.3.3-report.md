# v0.3.3 事件与 CodecID 验收报告

已完成本轮实施及验收，SDK **0.3.3**，协议 **5**。仅修改 `sdks/wego/**`；Hatchet 源码、根依赖和官方文档镜像未修改。原有暂存改动与手动 feature client 的用户改动保留。

## 交付

- 四种启用 RPC 默认注册完整方法名事件，合并自定义事件后按最终 namespace key 稳定去重。禁用方法、纯网络模式保持任务注册边界。
- `internal/spec` 准备实例只读 CodecID 注册表及有序发送链；`runtime.WithEncodingCodecs` 支持最后配置覆盖、显式空链和重复执行步骤。接收端只按持久消息 ID 逆序解码。
- 任务、结果、父输出、事件等待、Filter、流协议帧和 Worker 通知全部接入共同编解码入口。结果读取通过注册表判断 I/O 能力，不逐次扫描中间件。
- ProtoJSON 数组逐项编码，包含 `[]any` 中的 protobuf；拒绝 nil、混合类型和超限。可靠事件先确认 CLAIM 所有权，再由获胜者解码并报告输入错误；一对多事件按接收方法隔离幂等身份。
- 静态 Cron／Filter 摘要使用消息实际编码链，保留密文复用。示例使用稳定 ID 常量，文档说明注册、发送与历史解码的区别。

## 证据与清理

[机器可读报告](v0.3.3-report.json) 保存每个源文件状态、全部示例断言及 RunID／WorkerID／traceID、专项运行身份、执行命令、服务身份、embedded 清理结果和本机日志 SHA256。不包含 token、AES 密钥或 S3 凭证。

所有运行使用独立测试 namespace，仅删除对应 workflow／触发器并关闭 SDK 实例。**运行、topic 历史及其引用的 S3 对象保留**，保证回放所需数据仍存在；独立 embedded 数据库已删除。Realtime 没有历史回放保证，测试用实际收到 DATA 的屏障确认实时输出，没有用固定等待假设订阅就绪。

启用不同发送链前升级两端；旧接收端仍要求相同顺序。保留历史所需的组件、密钥和对象。wego 继续只接受自身封包，未添加原生／Console 裸 JSON 兼容分支。
