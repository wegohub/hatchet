# wego 0.3.1：枚举配置简化与验证

验收日期：2026-10-10。SDK `0.3.1`，协议 `5`；依赖和本机引擎均为未经修改的官方 Hatchet `v0.110.5`，MQ 使用 PostgreSQL。

## API 与默认值

| 字段 | 类型 | 省略时的行为 |
|---|---|---|
| `DesiredWorkerLabel.Comparator` | `WorkerLabelComparator` | 零值 `LabelEqual`；backend 显式发送官方 `EQUAL`。 |
| `Concurrency.LimitStrategy` | `ConcurrencyLimitStrategy` | 空值不发送策略，使用服务端默认规则。 |
| `RateLimit.Duration` | `RateLimitDuration` | 空值不发送周期，沿用后端的周期处理。 |

直接配置 `Comparator: model.LabelEqual`、`LimitStrategy: model.GroupRoundRobin`、`Duration: model.Minute`，无需临时变量、取地址或指针辅助函数。未知枚举仍报错；需要区分未指定与显式零值的数值、布尔及其他可选字段继续保留指针或 Option。这属于源码 API 变更；协议和服务端传输字段保持不变。

## 本轮检查

以下命令在 wego 独立模块执行，均通过；普通测试不运行需要另行启动 Worker 的手动 feature client，其编译和真实调用分别验证。

- `GOWORK=off go build ./...`
- `GOWORK=off python3 scripts/unit.py`
- `GOWORK=off python3 scripts/unit.py -race`
- `GOWORK=off go vet ./...`
- `GOWORK=off go test ./tests/feature/client -run '^$'`

单元门禁包含生成一致性、中文注释、公开 API 隔离和包边界。新增测试覆盖全部合法比较器、并发策略和限流周期，以及空值协议缺省、非法枚举、显式 EQUAL 的协议 presence 和标签快照隔离。官方发行依赖检查、SDK 外源码边界、gofmt 及 diff 空白检查也通过。

本机真实验收入口（令牌仅通过私有配置注入）：

```bash
python3 sdks/wego/scripts/local-test.py env GOWORK=off GOFLAGS=-mod=readonly \
  WEGO_REPORT_PATH=/tmp/wego-v031-policy-evidence.json \
  go -C sdks/wego test -json -count=1 -tags=e2e ./tests/e2e \
  -run 'TestExamples/(concurrency|rate-limiting|runtime-affinity)$|^TestUnifiedCallOptions$' \
  -timeout 10m
```

并发组、静态/动态限流、两个 Worker 间的硬亲和全部通过，共记录 74 条场景断言；这不是 0.3.0 全量验收的 74 个源文件构造片段。生成客户端的默认相等比较器、运行选项、headers/trailers、消息大小限制和 OnFinish 另行通过。本轮为针对枚举变更的回归；完整统一消息验收的历史证据见 [0.3.0 报告](v0.3.0-acceptance-report.md)。

## 清理与边界

本轮使用 11 个独立 namespace，清理了 33 个 workflow 定义及版本、触发器、66 条任务和对应运行查询记录、日志与测试限流资源，确认本轮定义、任务和运行记录残留为 0。其他 namespace 的业务资源、租户、用户和凭证保留。未修改 Hatchet 源码、根模块依赖或官方文档镜像；历史报告保持对应版本的事实。
