# wego 0.2.7 日志重设计验收

SDK `0.2.7`，协议 `4`，未经修改的官方依赖与本机服务 `v0.110.5`，PostgreSQL MQ。

## 交付

- `runtime.WithLogger` 原子设置 wego log 包共享输出；普通 context、网络请求、任务和 R 系列统一使用。未配置回退到 slog.Default，不调用 slog.SetDefault。
- `With`、`Handler`、`FromContext`、`Enabled`、`Log`、`LogAttrs` 支持不可变属性、分组层级去重、动态值及业务 source。真实任务与有效 trace 字段最终补充。
- R 系列先按等级打印，再同步上报原始 message、metadata、时间、等级和 retry。能力缺失、关闭上报、编码/超限/传输与两个出口失败明确返回；默认预算 5 秒并受调用 deadline 限制，I/O 纳入实例关闭登记。
- Server 使用 `Serve` / `Stop` / `GracefulStop`。不提供 Server.StartBlocking 或 utils 包；feature Worker 由应用通过标准库接收信号并调用 Stop。原生 Worker 的既有生命周期 API 保留。
- 示例、完整 option 文档、版本和验收 manifest 已同步；修改范围仅为 `sdks/wego/**`。

完整命令：

```sh
GOWORK=off python3 sdks/wego/scripts/unit.py -race
GOWORK=off go -C sdks/wego vet ./...
python3 sdks/wego/scripts/local-test.py go -C sdks/wego test -race -tags=e2e ./tests/e2e -run '^(TestLoggingShutdown|TestExamples)$/^(logs|grpc-streams|dual-entry|shutdown|durable-sleep)$' -count=1 -timeout=8m
python3 sdks/wego/scripts/local-test.py go -C sdks/wego test -tags=e2e,wego_embedded ./tests/e2e -run '^TestEmbedded$' -count=1 -timeout=10m
```

日志、Handler 错误、过滤、取消与 deadline 上报、属性编码/超限、并发替换、源位置和资源登记还通过受控协议及单元验证。本轮真实回归范围为上述五个场景与专项关闭/embedded；28 个官方源文件的历史全量验收保留在既有报告中。
