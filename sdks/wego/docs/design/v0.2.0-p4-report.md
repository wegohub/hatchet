# v0.2.0 P4 通知、取消与关闭验收记录

SDK `0.2.0`，协议 `4`；官方 Hatchet `v0.110.5`，PostgreSQL MQ。实现不创建控制 Worker/workflow，也不占用通知 slots。

| 场景 | 实际断言 |
|---|---|
| 两个 Worker 的 slots 全满 | namespace 广播到达两个随机 worker_key；定向通知只到指定实例 |
| 启动边界 | 新 Worker 不处理自身 JOIN 之前的旧广播 |
| 重复事件 | 同 ID 使用稳定 producer，实际只交付一条；后续尾部屏障仍正常到达 |
| 实际订阅重连 | 官方传输路径注入一次 Unavailable，恢复后继续实际通知；worker_key 与注册 WorkerID 保持不变 |
| 慢回调/队列 | 有限数量、字节、有效期和去重缓存；内部取消独立处理，不等待业务回调消费 |
| 旧执行取消 | TaskRunID、旧 epoch、旧 writer 与当前实例完整匹配；迟到或错误身份通知不能取消新执行 |
| Result 取消 | 异步提交已脱离提交 context；Result 等待超时请求取消共享 Run，第二次观察得到权威 Canceled |
| 生命周期 | 启动失败、并发关闭、预算超时、强制中断排空、在途流和 batch 上报均有单元及真实引擎断言 |
