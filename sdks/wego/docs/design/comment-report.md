# wego 0.1.4 中文注释验收

本版覆盖 168 个 Go 文件，包括 19 个测试文件与 3 个生成文件；另补齐 2 个 proto 文件及生成、工具安装、本机验收脚本的中文说明。SDK 版本 `0.1.4`，wire 协议仍为 `1`。

## 覆盖与说明

| 声明或逻辑类别 | 语法节点数 | 检查方式 |
| --- | ---: | --- |
| 函数和方法 | 756 | 公开与私有 FuncDecl 均检查中文说明 |
| 类型 | 190 | 结构体、枚举类型、函数类型、别名均检查 |
| 结构体字段 | 616 | 包含私有字段和匿名嵌入 |
| 接口方法及约束 | 87 | 包含私有兼容性接口 |
| 变量与常量声明组 | 234 | 包含包级与局部 var / const |
| 局部短声明 | 1640 | 包含 if、switch 和 select 分支中的声明 |
| range 循环 | 179 | 键和值声明由同一逻辑块说明解释 |

声明覆盖门禁是 `TestDeclarationsHaveChineseComments`，遗漏会定位到文件及行号。逻辑说明覆盖配置合并、协议状态、失败分支、durable 等待、任务结果、观测及资源清理；测试说明解释受控输入、注入位置和预期断言。不是逐行翻译：简单错误检查与前一操作属于同一逻辑块，共用说明。

实际数据例子包括：

- `Request{Message:"hello", GroupKey:"group-a"}` 编码为 protobuf 业务载荷，显式投影得到 `routing.group="group-a"`。
- 输入先到序号 2 再到 1，缓存后仍按 1、2 交付；`ACK=3` 同时归还序号 1～3 的消息数和字节预算。
- `END=2` 等待输入 1、2 消费后产生输入 EOF，输出方向仍开放；终态声明输出 3 而缺少 2 时必须明确失败。
- `Some(0)` 的 `Set=true` 覆盖默认值；4 个业务槽、单次成本 2 时最多并发两次。
- 稳定 child key `step-1` 在 durable 重放时关联同一子调用；网络 handler 没有任务身份。

## 验证结果

单元测试、全 SDK race、vet、API 隔离、生成及 manifest 复现、声明注释门禁通过。普通 e2e、两个 embedded 独立模块以对应 build tag 编译通过；Python 与 shell 脚本语法检查通过。具体命令见 [机器可读记录](comment-report.json)。

对修改前后 167 个现有 Go 文件执行去注释语法树比对：166 个完全相同，唯一差异是 SDK 版本常量 `0.1.3 → 0.1.4`。新增 Go 文件为注释门禁测试。生成协议的字段编号、原始描述符及执行代码没有变化；生成后处理仅插入中文注释。

本版没有重跑完整真实引擎场景；[完整引擎验收报告](acceptance-report.md) 保留实际执行版本 `0.1.3`，没有把历史运行结果改写为 `0.1.4`。本版测试不启动或更改本机数据库与 Hatchet 服务。
