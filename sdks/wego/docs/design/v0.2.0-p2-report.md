日期：2026-10-09。执行记录使用 SDK `0.2.0-dev.1` / 协议 `4`；当前开发元数据已进入 `0.2.0-dev.2`。服务端为官方 Hatchet `v0.110.5`，PostgreSQL MQ。P2 主路径已通过，消费恢复、Worker 事件和完整矩阵仍在实施。

## 当前实现

每个 RPC 仅注册一个 StandaloneTask。client/bidi 的 `Send` 保存独立请求快照，`CloseSend` 幂等地一次提交 JSON 请求数组；Worker 解包并通过有界 channel 适配标准 `Recv`。任务正常占用业务 slots，不创建 START、SESSION、控制 workflow 或控制 Worker。

server/bidi 默认 Reliable，使用完整帧 codec、规范 CLAIM 读回和权威输出清单。CLAIM、HEADERS、DATA、ATTEMPT_END 全部统一变换；DATA 不重复运行业务 codec。client stream 的唯一响应随任务结果返回。实时模式显式配置为 Realtime，使用 PutStream，不提供恢复承诺。

原文消息、codec 中间字节、整批输入、请求数量、完整 envelope、输出预取、历史扫描和每次 I/O 均有独立预算。Worker 对输入只还原一次，检查 protobuf 合法性及整批摘要。已有历史输出的接管执行需要读完 `task.Checkpoint` 后继续发布。
