日期：2026-10-09。SDK `0.2.0-dev.1`，公开协议 `4`，官方未修改发行依赖和本机镜像均为 Hatchet `v0.110.5`；MQ 使用 PostgreSQL。此记录只证明 P1，不能替代完整 v0.2.0 验收。

## 实现与断言

- RPC workflow：`<namespace>-<完整服务名>-<方法名>`；空 namespace 不添加连接符。展示名称保留大小写，内部 action 使用 namespace 和方法完整摘要，大小写不同的方法不会共用执行路由。
- Worker：每次 SDK Worker 创建生成独立 UUID key；默认展示名称为 `<namespace>-<hostname>-<key 前12位>`，`WithInstanceName` 只覆盖展示名称。
- 两个同名副本重复注册共享 workflow；停止副本后定义保留且不自动暂停。
- protobuf 采用 `protojson.UseProtoNames`。64 位整数、bytes、oneof、optional、枚举和 well-known types 均有断言。
- routing 按调用提供，默认值放在 Runtime；顶层覆盖、嵌套对象整体覆盖、独立快照和非法 JSON 拒绝均已验证。客户端与 Worker 不再使用 protobuf 字段投影。
- backend 使用显式 RPC 绑定保存 schema，原生 JSON 不因含有 `method` 字段而变成 RPC。官方执行器的 namespace 视图为空，避免已生成的内部 action 被重复添加前缀；事件和管理功能保留实例 namespace。
